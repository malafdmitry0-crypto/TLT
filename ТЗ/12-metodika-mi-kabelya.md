# 12. Методика расчёта кабеля с минеральной изоляцией (MI)

> **Статус: проект методики для утверждения Заказчиком.**
> Первоисточник ТНП по MI-кабелям отсутствует. Методика составлена по
> общепринятой инженерной практике нагревательных кабелей с минеральной
> изоляцией: IEC 62395-1/-2 (electrical resistance trace heating systems),
> ГОСТ IEC 60079-30-1/-2 (электрообогрев во взрывоопасных средах),
> IEEE 844.1 / CSA C293.1 (skin effect and impedance heating, разделы по
> resistance trace heating), каталоги производителей MI-кабелей
> (nVent Pyrotenax MI, отечественные КНМС/КНММ). После утверждения формулы
> переносятся в контракт бизнес-логики и QA-реестр на общих основаниях.

## 12.1. Физическая модель

MI-кабель — резистивный нагревательный кабель **постоянного сопротивления**:
одна или две жилы (медь, медно-никелевый сплав, нихром) в уплотнённой
изоляции из оксида магния (MgO) в сплошной металлической оболочке (медь,
медно-никелевый сплав, нержавеющая сталь, сплав 825). Секции —
**заводской готовности**, с «холодными» концами; резка и заделка по месту не
допускаются. Ключевые отличия от полимерных резистивных кабелей:

- рабочая температура оболочки до 250 °C (медь), до 400 °C (Cu-Ni),
  до 600 °C (нержавеющая сталь / сплав 825) — единственный тип для
  высокотемпературных объектов и пропарки выше пределов ТТХ;
- мощность секции жёстко связана с её длиной: `P = U² / R(L)`;
- укладка только вдоль трубы: **навив запрещён, ниток в секции — 1**
  (правило VAL-61); компенсация мощности — выбором сопротивления жилы и
  количеством параллельных секций.

| Параметр | Обозн. | Ед. | Источник |
|---|---|---|---|

## 12.3. Электрическая модель секции

### МИ-01. Сопротивление секции

```
r_T = r20 × (1 + α_ж × (T_раб − 20))      [Ом/м]   — погонное сопротивление жилы
R_секц = r_T × L_секц × c_ж               [Ом]
```

`c_ж` — схемный множитель числа последовательных жил в секции:

| Конструкция секции | c_ж |
|---|---:|
| Одножильный кабель, возврат «холодным» питающим проводником | 1 |
| Двухжильный кабель (обе жилы последовательно, петля внутри кабеля) | 2 |
| Две одножильные нитки петлёй (туда-обратно по трубе) | 2 |

- `r20` — паспортное погонное сопротивление жилы при 20 °C, Ом/м (каталог);
- `α_ж` — температурный коэффициент сопротивления материала жилы, 1/°C
  (каталог; медь ≈ 0,0039; медно-никелевые сплавы ≈ 0,0001…0,0004; нихром
  ≈ 0,00013 — для низко-α сплавов поправка практически нулевая);
- `T_раб` — расчётная температура жилы; для проверки мощности принимается
  равной температуре поддержания (консервативно — T1).

### МИ-02. Мощность и удельная мощность секции

```
P_секц = U² / R_секц                       [Вт]
p = P_секц / L_секц = U² / (r_T × c_ж × L_секц²)   [Вт/м]
I_секц = U / R_секц = P_секц / U           [А]
```

Удельная мощность MI-секции **квадратично** падает с длиной секции — это
главное проектное ограничение.

## 12.4. Алгоритм подбора (детерминированный)

```
Вход: q_треб, L_об, U, T1, T2, каталог
1. Отфильтровать каталог по температурам:
     T_max_оболочки ≥ max(T1, T2)
     T_min_монтажа ≤ T_ос
     U ≤ U_max_кабеля
2. Для каждой марки (r20, α_ж, c_ж, I_max, p_max):
     r_T = r20 × (1 + α_ж × (T1 − 20))
     L_q    = U / √(r_T × c_ж × q_треб)     — длина, при которой p = q_треб (максимум)
     L_imax = U / (r_T × c_ж × I_max)       — минимум по току
     L_pmax = U / √(r_T × c_ж × p_max)      — минимум по перегреву оболочки
     L_min = max(L_imax, L_pmax);  L_max = L_q
     если L_min > L_max → марка непригодна
3. Число секций: M = ceil(L_об / L_max);  L_секц = L_об / M
     если L_секц < L_min → увеличить M нельзя: марка непригодна
4. Проверка факта: p_факт = U² / (r_T × c_ж × L_секц²)
     p_факт ≥ q_треб  и  p_факт ≤ p_max  и  I = p_факт×L_секц/U ≤ I_max
5. Из пригодных марок выбрать минимальную по порядку:
     (a) меньше M; (b) меньше p_факт (меньше перегрев); (c) меньше I.
6. Температура оболочки (стабилизированный метод, МИ-03) ≤ min(T_max_оболочки,
   T-класс зоны при Ex).
Выход: марка, M, L_секц, p_факт, P_общ = Σ p_факт×L_секц, I_секц, U.
```

Ручной выбор марки: алгоритм проверяет только указанную марку (шаги 2–6),
автозамена не выполняется — единообразно с ЭР-06.

### МИ-03. Проверка температуры оболочки (стабилизированный метод)

```
T_об = T_тр + p_факт × R_кт      [°C]
```

`R_кт` — тепловое сопротивление контакта кабель-труба-изоляция, м·К/Вт
(каталожная/эмпирическая величина по способу крепления; типично
0,3…1,0 для крепления лентой под изоляцией). Для зон Ex итоговая `T_об`
ограничивается температурным классом (T6…T1) по ГОСТ IEC 60079-30-1.
До получения каталожных `R_кт` допускается упрощение: использовать
паспортную таблицу «максимально допустимая удельная мощность p_max при
температуре трубы» из каталога производителя.

## 12.5. Результат расчёта (состав)

Марка, материал жилы/оболочки, M секций × L_секц, p_факт (Вт/м), P_общ (Вт),
I на секцию (А), U, T_об расчётная, признак прохождения T-класса;
`number_of_threads = 1`, `winding_step = 0` (принудительно).
