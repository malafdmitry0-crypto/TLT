# 6. Спецификация: базовый режим и полный условный BOM по ТНП

## 6.1. Базовая спецификация (все роли)

- **СП-01.** Автоматическое формирование по результатам электрорасчёта
  активного СО: позиции кабеля по маркам (суммарная длина с запасом) +
  базовый набор аксессуаров из справочника `accessories.json`:

| Категория | Позиция | Артикул | Ед. | Кол-во на объект |
|---|---|---|---|---:|
| Комплектующие | Комплект концевой заделки | КЗ-01 | шт. | 1 |
| Комплектующие | Комплект соединительный | КС-01 | шт. | 1 |
| Комплектующие | Лента крепёжная алюминиевая | ЛКА-50 | м | 2 |
| Управление | Терморегулятор электронный | ТР-220 | шт. | 1 |
| Управление | Датчик температуры NTC | ДТ-NTC | шт. | 1 |
| Защита | УЗО 30 мА | УЗО-30 | шт. | 1 |

- **СП-02.** Расширенный режим сотрудника: группировка, сортировка,
  добавление/удаление ручных позиций, выбор материалов из внешней БД.

## 6.2. Полный условный BOM по ТНП (`mode="full"`, сотрудник/админ)

Первоисточник: `ТНП/Расчет_спецификации_трубы_самрег29_05_26.xlsx`, лист
«Список материалов Самрег» (192 строки); deterministic-oracle —
`docs/audit/spec-bom-oracle.md`.

### СП-03. Область применения

- Применяется **только** к саморегулирующимся типам (`self_regulating`,
  `self_regulating_tt`); позиции остальных типов пропускаются и возвращаются
  в `skipped_objects`.
- Гостю режим `full` недоступен (403).
- Режим и опции последней генерации персистятся
  (`generation_mode`/`generation_options`) и переиспользуются фоновым
  пересчётом.

### СП-04. Входные параметры режима

| Параметр | Смысл |
|---|---|
| `Ex` | Признак взрывоопасной зоны |
| `R,гр` | Коэффициент резерва («горячий резерв») — множитель на длины и комплекты |
| `К1i`, `К2i`, `Кiu` | Условия конфигурации концевых/соединительных узлов секций |
| `L,К2i` | Пороговая длина секции для удвоения комплектов при К2i=да |
| `N,секц`, `L,секц` | Число и длина секций кабеля позиции электрорасчёта |
| `dтр` | Наружный диаметр трубы, мм |
| `T,секц` (темп-класс) | Низкотемпературный (ТТН, ТЛТ) / высокотемпературный (ТТВ, ТТХ) — упрощение, см. документ 11 |

Все суммирования `Σ(i)` ведутся по каждой позиции электрорасчёта проекта.

### СП-05. Формулы расчёта позиций (обязательные)

| Позиция | Формула |
|---|---|
| Кабель низкотемпературный (по маркам) | `L1 = Σ(i) (L,секц × N,секц × R,гр)` |
| Кабель высокотемпературный (по маркам) | `L2 = Σ(i) (L,секц × N,секц × R,гр)` |
| Комплект заделки КСН-1 (низкотемп.) | `Fl1 = Σ(i) N,секц × R,гр` |
| Комплект КСН-2 (низкотемп., доп.) | `Fl2 = Σ(i) N,секц × R,гр × 2` — только секции с `L,секц ≥ L,К2i` при К2i=да |
| Комплект КСВ-1 (высокотемп.) | `Fl3 = Σ(i) N,секц × R,гр` |
| Комплект КСВ-2 (высокотемп., доп.) | `Fl4 = Σ(i) N,секц × R,гр × 2` — условие К2i аналогично |
| Ремкомплект КСР-1 (низкотемп.) | `N1 = ceil(ΣL1 / 150)` |
| Ремкомплект КСР-2 (высокотемп.) | `N2 = ceil((ΣL2 + ΣL3) / 150)` |
| Коробки СКВ (12 вариантов) | `Nk{1..12} = Σ(i) ceil(N,секц / 3)` — вариант корзины по комбинации `dтр≷57 / Ex / К1i / К2i / Кiu / N≥3` |
| Хомут ХК | `Kr3 = Σ(i) (((dтр×3,14×1,2)+50)/1000) × 2 × (Nk1..Nk6)` |
| Лента крепёжная ЛКС | `Kr1 = Σ(i) ((3,14×dтр×2,5/1000) × (L1/0,3)) × 1,1` (шаг крепления 0,3 м, +10%) |
| Этикетка «Внимание, электрообогрев» | `MrEl1 = Σ ceil(Lтр / 3,5)` (1 этикетка на 3,5 м трубы) |

### СП-06. Корзины коробок СКВ (12 вариантов)

Каждая комбинация условий отображается в конкретную номенклатуру:

| Корзина | Артикул/код |
|---|---|
| Nk1 | СКВ 1201 (002-001-001) |
| Nk2 | СКВ 1601 (002-001-007) |
| Nk3 | СКВ 1601-С (002-001-009) |
| Nk4 | СКВ 1601-С1 (002-001-010) |
| Nk5 | СКВ 1201-С (002-001-003) |
| Nk6 | СКВ 1201-С1 (002-001-004) |
| Nk7 | СКВ 1202 (002-001-002) |
| Nk8 | СКВ 1602 (002-001-008) |
| Nk9 | СКВ 1202-С (002-001-005) |
| Nk10 | СКВ 1202-С1 (002-001-006) |

### СП-08. Упаковочные коэффициенты

Количество штучных позиций с упаковкой: `шт = ceil(формула × package_factor)`.

| Позиция | package_factor | Смысл |
|---|---:|---|
| ХК30 / ЛКС / ЛКВ | 0,0333334 | рулон 30 м (1/30) |
| ЛА | 0,02 | рулон 50 м (1/50) |
| Клей NEO | 0,14 | расход на картридж |
| Герметик ГС | 0,25 | расход на тубу |
| Z-профиль | 0,5 | профиль 2 м |

### СП-09. Приёмочные граничные тесты (обязательные)

- `ΣL1 = 150 → N1 = 1`; `ΣL1 = 151 → N1 = 2` (округление вверх);
- `N,секц = 3 → 1 коробка`; `N,секц = 4 → 2 коробки`;
- граничный `dтр = 57` — отдельный кейс на каждую корзину СКВ;
- две и более позиции электрорасчёта — проверка суммирования `Σ(i)`;
- секция с `L,секц = L,К2i` при К2i=да — попадает в удвоение.

### СП-10. Поведение UI

- Режим «базовая / полная» на странице спецификации (полная — сотрудник).
- Опции полного BOM: Ex, R,гр, К1i, К2i, Кiu, L,К2i.
- Таблица: кабель + аксессуары; сотрудник добавляет/удаляет позиции вручную;
  пропущенные объекты других типов кабеля показываются списком с причиной.
