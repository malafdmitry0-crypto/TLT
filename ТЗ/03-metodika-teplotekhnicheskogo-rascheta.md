# 3. Методика теплотехнического расчёта

Источник методики — первичные материалы ТНП Заказчика (DOCX «Блок расчёта
теплопотерь и подбора кабеля», внутренние справочники) с инженерными
уточнениями, зафиксированными в `docs/tnp/correctness-review.md`. Все формулы
обязательны к реализации в виде чистых функций, покрытых unit-тестами на
100% ветвей.

## 3.1. Трубопровод — многослойная цилиндрическая стенка

### ТР-01. Общая формула теплопотерь

```
Q = (Tж − Tос) / R_итого × (L + ΣL_доп) × K × K_разм    [Вт]

R_итого = R_стенки + Σ R_из_i + R_внеш                  [м·К/Вт на 1 м длины]
```

| Символ | Смысл | Ед. | Источник |
|---|---|---|---|
| Tж | Температура продукта (жидкости) в трубе | °C | ввод; −90…+600 |
| Tос | Температура окружающей среды | °C | ввод или климат; −70…+70 |
| L | Длина трубопровода | м | ввод; 0,5…200 000 |
| ΣL_доп | Эквивалентная длина локальных элементов (ТР-06) | м | расчёт |
| K | Коэффициент запаса (ТР-08) | — | БД коэффициентов; 1,05…1,7 |
| K_разм | Коэффициент размещения (ТР-09) | — | БД коэффициентов |

Удельные теплопотери, отображаемые в таблице:

```
q = (Tж − Tос) / R_итого    [Вт/м]
```

### ТР-02. Сопротивление цилиндрического слоя (стенка трубы, слои изоляции)

```
R_слоя = ln(d_внеш / d_внутр) / (2π × λ_слоя)
```

Развёрнутая запись ТНП для стенки трубы и n слоёв изоляции (n = 1…3):

```
R_стенки = ln(dтр / (dтр − 2·δтр)) / (2π·λтр)
R_из_i   = ln((dтр + 2·Σ_{j≤i} δиз_j) / (dтр + 2·Σ_{j≤i−1} δиз_j)) / (2π·λиз_i)
```

- `dтр` — наружный диаметр трубы, м (ввод в мм: 10,8…3000);
- `δтр` — толщина стенки трубы, мм (0,1…40), опциональна; если задана,
  обязателен материал трубы из справочника **или** ручная λтр — скрытое
  значение по умолчанию не подставляется;
- `δиз_i` — толщина i-го слоя изоляции (1…500 мм);
- слоёв изоляции 1–3; для каждого слоя — материал из справочника
  (λ = λ(tm), см. ТР-04) или «Другое» с обязательной ручной λ
  (0,001…400 Вт/(м·К)).

### ТР-03. Теплопроводность материала трубы

```
λтр(T) = A + B × (Tср + 40),     Tср = (Tж + Tос) / 2
```

| Материал | A | B | Точность |
|---|---|---|---|
| Углеродистая сталь | 60,0 | −0,10 | ±2% |
| Нержавеющая сталь AISI 304 | 14,0 | +0,01 | ±1% |
| Медь (электролитическая) | 410,0 | −0,16 | ±1,5% |
| Алюминий (чистый) | 242,0 | −0,07 | ±1% |
| Пластик (усреднённый) | 0,20 | +0,0005 | ±10% |

### ТР-04. Теплопроводность изоляции — температурная зависимость λ(tm)

Для справочных материалов λ не является константой. Сначала вычисляется
расчётная средняя температура слоя `tm`:

```
tm = Tж / 2          — размещение «открытый воздух, зимний режим»
tm = (Tж + 40) / 2   — помещение, открытый воздух летом, каналы, тоннели,
                       техподполье, чердак, подвал
```

Затем λ слоя — по формуле конкретного материала из справочника теплоизоляции
(полный перечень из 37 материалов с коэффициентами — документ 5, раздел 5.3):

```
λиз(tm) = A + B × tm        при tm ≥ 20 °C
λиз     = значение(я) колонки «≤19 °C» при tm ≤ 19 °C
```

Пример: `mineral_wool_boards_120` (плиты минераловатные прошивные, 120 кг/м³):
`λ(tm) = 0,045 + 0,00021·tm`; при Tж = 80 °C и зимнем режиме
`tm = 40 °C → λ = 0,0534 Вт/(м·К)`.

Generic-семейства («минеральная вата», «пенополиуретан» и т.п. без плотности)
**не являются расчётными материалами**: объект с таким материалом — черновик,
требующий выбора конкретного кода с плотностью.

### ТР-05. Внешнее сопротивление

**Надземно (открытый воздух):**

```
R_внеш = 1 / (π × α_внеш × d_нар_из),      d_нар_из = dтр + 2·Σδиз_i

α_внеш = 11,6 + 7 × √v       [Вт/(м²·К)]   (СНиП 41-03-2003)
```

- `v` — скорость ветра, м/с (0…20; по умолчанию 0; при выборе климатического
  города заполняется из справочника);
- при v = 0 α = 11,6; расчётное α дополнительно умножается на ветровой
  коэффициент `wind_factor` (документ 5) и **ограничивается сверху 52
  Вт/(м²·К)**;
- ручное/справочное значение α допускается в диапазоне 7…52 Вт/(м²·К).

**В помещении:** α = 9,0 Вт/(м²·К) (ветер не используется).

**Подземно (бесканальная прокладка)** — вместо воздушного сопротивления
используется сопротивление грунта:

```
R_гр = arccosh(H / r_нар_из) / (2π × λ_гр)
     = ln(x + √(x² − 1)) / (2π × λ_гр),   x = 2H / d_нар_из
```

- `H` — глубина заложения оси трубы, м (0…200; обязательна при подземном
  размещении);
- `λ_гр` — теплопроводность грунта, Вт/(м·К): из справочника грунтов
  (документ 5, раздел 5.5) или вручную. Диапазон по первоисточнику ТНП —
  0,8…3,0; принятый расширенный диапазон ввода — 0,5…3,0 (зафиксировать
  решением Заказчика, см. документ 11). Значение по умолчанию — 1,5
  (суглинок средней влажности).

### ТР-06. Локальные элементы (фланцы, арматура, опоры)

```
L_доп = Σ (l_i × n_i)
```

- `l_i` — эквивалентная длина одного локального элемента, м (0,1…6,9, из
  справочника);
- `n_i` — количество элементов (0…100).

Суммарные теплопотери считаются по эффективной длине `L_эфф = L + L_доп`.

### ТР-07. Числовой контрольный пример (обязательный приёмочный тест)

Труба Ø108 мм, изоляция 50 мм `mineral_wool_boards_120`, Tж = +80 °C,
Tос = −20 °C, открытый воздух зимой, v = 0, без стенки, L = 50 м, K = 1,1,
K_разм = 1,0:

```
tm = 80/2 = 40 °C → λиз = 0,045 + 0,00021×40 = 0,0534
R_из  = ln(0,104/0,054) / (2π×0,0534) ≈ 1,953
R_внеш = 1/(π×11,6×0,208) ≈ 0,132
q = 100 / 2,085 ≈ 47,95 Вт/м
Q = 47,95 × 50 × 1,1 × 1,0 ≈ 2 637 Вт
```

### ТР-08. Коэффициент запаса K и расчётная температура (климатический алгоритм ТНП)

При выборе климатического города K и расчётная температура определяются
алгоритмом ТНП (VSDX «Климат»):

| Условие | K | Расчётная T |
|---|---|---|
| Трубопровод, D ≥ 100 мм | 1,1 | T наиболее холодной пятидневки, обеспеченность 0,92 |
| Трубопровод, D < 100 мм | 1,12 | Абсолютная минимальная температура воздуха |
| Не трубопровод (резервуар и пр.) | 1,1 | T наиболее холодной пятидневки, обеспеченность 0,92 |

Климатическая строка выбирается по ключу `регион + город`; поиск только по
городу допустим лишь для однозначных названий. Администратор может
переопределить K в пределах 1,05…1,7.

### ТР-09. Коэффициент размещения K_разм (прикладная политика)

`location_indoor = 0,9` (помещение), `location_outdoor = 1,0` (улица) —
множители итогового Q для труб и резервуаров. В первичных ТНП DOCX/XLSX
отдельный множитель размещения не обнаружен; правило сохраняется как
**осознанная продуктовая политика** и подлежит подтверждению Заказчиком
(документ 11). Значения настраиваются администратором.

### ТР-10. Передача в электрорасчёт (запрет двойного запаса)

В электрический подбор для трубы передаётся `q` **без** уже применённого K;
коэффициент K_разм учитывается в требуемой мощности; запас по мощности
применяется электрической формулой ровно один раз (см. документ 4, ЭР-01).

## 3.2. Резервуар — плоская стенка

### ТР-11. Площадь поверхности

```
Цилиндр:         S = π·d·H + 2·π·(d/2)²     (бок + крышка + дно; в ТНП: πd²/2 + πdH)
Параллелепипед:  S = 2·(L·W + L·H + W·H)
Шар:             S = 4·π·(d/2)² = π·d²
```

### ТР-12. Удельные и полные теплопотери (надземный/в помещении)

```
q = (Tж − Tос) / (δр/λр + Σ δиз_i/λиз_i + R_внеш)    [Вт/м²]

R_внеш = 1 / α_внеш          (плоская стенка!)
α_внеш = 11,6 + 7×√v;  в помещении α = 9,0

Q = q × S × K × K_разм + Q_доп    [Вт]
```

- `δр/λр` — сопротивление стенки резервуара; если толщина стенки не задана,
  слагаемое равно 0;
- λиз — по той же температурной зависимости λ(tm), что и для труб (ТР-04);
- `Q_доп` — дополнительные теплопотери (днище, штуцера, люки и пр.), Вт;
  по умолчанию 0; **прибавляется после** умножения на K и K_разм
  (коэффициент запаса на Q_доп не распространяется).

Контрольный пример (приёмочный): цилиндр, δиз = 0,08 м,
`mineral_wool_boards_120`, Tж = +80 °C, Tос = −20 °C, зима, v = 0, без стенки:
`λиз(40) = 0,0534; r_total = 0,08/0,0534 + 1/11,6 = 1,584; q ≈ 63,1 Вт/м²`.

### ТР-13. Подземный резервуар — раздельный расчёт частей

Площадь делится по высоте подземной части `h`:

```
Цилиндр:         S_возд = πd²/4 + πd·(H − h);     S_гр = πd²/4 + πd·h
Параллелепипед:  S_возд = 2(L+B)·(H − h) + L·B;   S_гр = 2(L+B)·h + L·B

q_возд = ΔT / (δр/λр + Σδиз/λиз + R_внеш)
q_гр   = ΔT / (δр/λр + Σδиз/λиз + h/λ_гр)

Q = (q_возд × S_возд + q_гр × S_гр) × K × K_разм + Q_доп
```

### ТР-14. Передача в электрорасчёт для резервуара

`total_heat_loss` уже содержит K, поэтому сервис передаёт в подбор кабеля:

```
P_треб_на_м = (Q / K) / L_баз
```

где `L_баз` — базовая длина укладки кабеля по поверхности резервуара
(документ 4, ЭР-14).

## 3.4. Результаты расчёта (минимальный состав)

Для каждого объекта сохраняются и доступны в API/отчёте:

- `q` (Вт/м для труб; Вт/м² для резервуаров), `Q` (Вт);
- диагностические сопротивления: `wall_resistance`,
  `insulation_resistance` (по слоям), `external_resistance`,
  `thermal_resistance` (суммарное);
- применённые значения: λ каждого слоя и её источник, α, K, K_разм, tm,
  климатический город и источники температуры/ветра;
- для подземных объектов — параметры грунтовой ветки.

Воспроизводимость: рекомендуется снапшот применённых коэффициентов в
результате расчёта (см. документ 11, вопрос В-7).
