# 4. Методика электротехнического расчёта и подбора кабеля

Источники: ТНП DOCX «Блок расчёта теплопотерь и подбора кабеля», VSDX-алгоритмы
(«Выбор марки самрега», «Подбор резистивного кабеля», «Навив», «Климат»),
внутренние справочники кабелей. Все алгоритмы детерминированы и покрываются
unit-тестами и независимым оракулом (QA-registry).

## 4.1. Общие правила

### ЭР-01. Требуемая мощность (запрет двойного запаса)

Для трубы:

```
P_треб = q × K_зап      [Вт/м]
```

- `q` — удельные теплопотери **без** теплового K (документ 3, ТР-10), но с
  учётом K_разм;
- `K_зап` (`safety_factor`) — коэффициент запаса по мощности, по умолчанию
  1,1; применяется в электрической формуле ровно один раз.

Для резервуара:

```
P_треб_на_м = (Q / K) / L_баз      [Вт/м кабеля]
```

`L_баз` — базовая длина укладки кабеля (ЭР-14).

### ЭР-02. Коэффициент навива (труба)

```
k_навива = 1,                          если шаг навива = 0
k_навива = √(1 + (π·D / шаг)²),        если шаг > 0
```

- шаг навива задаётся в мм (0…500) и должен быть **строго больше** наружного
  диаметра трубы;
- допускается прямой ручной ввод коэффициента навива Kn в диапазоне
  1,0…10,0 (VAL-84) — он проходит ту же проверку ТНП-лимита по диаметру;
- значения Kn по умолчанию: ТЛТ — 1,0; ТТН/ТТВ/ТТХ — 1,1; если диаметр
  объекта неизвестен, допускается Kn ≤ 1,1;
- ТНП-ограничение максимального коэффициента навива по диаметру трубы
  (валидируется как жёсткий предел для явного и геометрического Kn):

| Диаметр трубы D, мм | Максимальный Kn |
|---:|---:|
| D < 57 | 1,0 (навив запрещён) |
| D = 57 | 1,1 |
| 57 < D ≤ 75 | 1,2 |
| 75 < D ≤ 89 | 1,3 |
| 89 < D ≤ 108 | 1,4 |
| D > 108 | 1,5 |

### ЭР-03. Нитки обогрева

- `N` — количество параллельных ниток (для ручного ввода: 1…3; автоподбор
  ТТН/ТТВ/ТТХ и резистивных схем может давать большее N по формулам ниже);
- результат расчёта различает: `requested_number_of_threads` (что ввёл
  пользователь, иначе null), `applied_number_of_threads` (что применил
  расчёт), `number_of_threads_source` ∈ {auto, manual, default,
  previous_result};
- общее условие пригодности (VAL-34): **совокупная** подведённая мощность ≥
  суммарных теплопотерь; ограничение «удельная мощность кабеля ≥ q на 1 м
  трубы» не применяется — компенсация навивом и нитками допустима.

## 4.2. Саморегулирующийся кабель ТЛТ (`self_regulating`)

### ЭР-04. Условия пригодности марки

Марка из каталога ТЛТ (документ 5, раздел 5.2.1) пригодна, если:

```
T_min(кабеля) ≤ T_ос
T_max(кабеля) ≥ T_продукта        (T_продукта обязателен)
P_кабеля × k_навива × N ≥ P_треб
```

### ЭР-05. Автоподбор (cable_mark = null)

Если нитки не заданы вручную, перебираются N = 1..3. Из всех пригодных
комбинаций выбирается минимальная по порядку:

1. меньшее количество ниток N;
2. меньшая паспортная мощность кабеля, Вт/м;
3. меньшая установленная мощность `P_кабеля × N`.

Если `number_of_threads` задан вручную — проверяется только это N, алгоритм
его не увеличивает.

### ЭР-06. Ручной выбор марки

Указанная марка ищется в активном каталоге и проверяется по условиям ЭР-04.
Замена на другую марку не выполняется; при непригодности возвращается ошибка
с причиной. Если нитки не заданы — N = 1 (источник `default`).

### ЭР-07. Результат расчёта ТЛТ

```
layout_factor = k_навива × N
L_каб = L_баз × 1,1 × layout_factor        (1,1 — монтажный запас 10%)
P_общ = P_кабеля × L_каб                   [Вт]
I     = P_общ / U_кабеля                   [А]
```

`U_кабеля` — паспортное напряжение выбранной строки каталога (встроенная
линейка — 220 В). `supply_voltage` варианта СО используется только как
fallback для кастомного каталога без паспортного напряжения.

## 4.3. Саморегулирующийся кабель ТТН/ТТВ/ТТХ (`self_regulating_tt`)

### ЭР-08. Температуры и выбор серии

Входы: `T1 = process_temperature` (температура продукта),
`T2 = vapor_temperature` (температура пропарки),
`T3 = maintain_temperature` (температура поддержания; при отсутствии
T3 = T1 — совместимость старых запросов).

Серия выбирается **только по температурам** (включительные паспортные
максимумы), мощность серию не эскалирует:

| Серия | Условие |
|---|---|
| ТТН | T1 ≤ 65 °C и T2 ≤ 85 °C |
| ТТВ | T1 ≤ 120 °C и T2 ≤ 210 °C |
| ТТХ | T1 ≤ 150 °C и T2 ≤ 250 °C |
| — | иначе: ошибка «превышение максимальной температуры, требуется альтернативный тип обогрева» |

### ЭР-09. Фактическая мощность кабеля при температуре поддержания

```
q_б(T3) = Q1 × T3 + Q2      [Вт/м]
```

Коэффициенты Q1/Q2 каждой марки (полный каталог — документ 5, раздел 5.2.2),
например: `33ТТН2: q_б = −0,491·T3 + 37,5`; `60ТТВ2: q_б = −0,25·T3 + 66`;
`95ТТХ2: q_б = −0,383·T3 + 101`.

### ЭР-10. Автоподбор номинала и ниток

1. Внутри выбранной серии ищется минимальный номинал с
   `q_б(T3) × k_навива ≥ q_треб`.
2. Если ни один номинал одной ниткой не покрывает — берётся **максимальный**
   номинал серии и:

```
N = ceil(q_треб / (q_б(T3) × k_навива))
```

Искусственного ограничения N ≤ 3 в авторежиме нет (правило полной версии по
VSDX). Серия не повышается ради уменьшения N.

При ручных нитках проверяется только заданное N:
`q_б(T3) × k_навива × N ≥ q_треб`. При ручной марке проверяются её серия,
температуры и мощность; автозамена не выполняется.

### ЭР-11. Маркировка результата

```
Марка = {номинал}{серия}2-{суффикс}
Суффикс: СР — продукт агрессивный (R = 1); СТ — иначе
Пример: 30ТТВ2-СР
```

### ЭР-12. Длина, мощность, ток

```
L_каб = L_баз × k_навива × N
P_общ = q_б(T3) × L_каб
I     = P_общ / U_кабеля        (паспортное U строки; supply_voltage — только fallback)
```

## 4.4. Укладка кабеля на резервуар

### ЭР-13. Обязательные параметры

Для резервуаров обязательны: форма укладки `cylindrical` или `rectangular`,
высота обогрева `heating_height` (h_укл) и шаг укладки `laying_step` (w);
допустимый диапазон шага укладки — **0,1…0,4 м** (VAL-83).
Сферические резервуары расчётной формулы укладки не имеют — возвращается
явная ошибка (не молчаливый расчёт «как труба»); это правило действует для
всех расчётных типов кабеля, включая резистивные.

### ЭР-14. Базовая длина укладки

```
Периметр:  П = π × d            (цилиндр)
           П = 2 × (L + B)      (параллелепипед)

L_баз = П × h_укл / w           (число горизонтальных витков h_укл/w по периметру)
```

(в нотации ТНП: `N = (П/2) × (h_укл / w)` для половины поверхности — точная
формула применяется согласно конфигурации укладки; реализация должна
соответствовать ТНП-первоисточнику и фиксироваться приёмочным тестом).

## 4.5. Резистивные кабели ТТ Р1 (`single_core`) и ТТ Р3 (`three_core`)

### ЭР-15. Температура продукта и горячее сопротивление

`process_temperature` (Tж) обязателен; при отсутствии — единая ошибка «Для
электрорасчёта требуется температура продукта».

Удельное сопротивление меди при рабочей температуре:

```
ρ_T = 0,0175 × (1 + 0,0042 × (Tж − 20))      [Ом·мм²/м]
```

**Требование полной версии:** все формулы мощности и тока резистивных кабелей
обязаны учитывать температурную поправку сопротивления
`[1 + α·(Tж − 20)]`, α = 0,0042 1/°C — как в первичных DOCX ТНП. Текущая
реализация считает P/I по холодному R20 (зафиксированное отклонение —
документ 11, вопрос В-2); требуется исправление либо подписанное решение
Заказчика.

### ЭР-16. Требуемое сечение жилы (подбор по сечению, ТТ Р1)

```
Длина кабеля:  N_каб = (L + ΣL_доп) × w     (w — коэффициент укладки/ниток)

Линия, 220 В:   Sк = (Q / U²) × ρ_T × N_каб
Петля, 220 В:   Sк = (Q / U²) × ρ_T × 2·N_каб
Звезда, 380 В:  Sк = (Q / (U/√3)²) × ρ_T × 3·N_каб
```

Условие подбора по справочнику: `Sк_б ≥ Sк` (ближайшее паспортное сечение).

Мощность выбранного кабеля (с горячим сопротивлением):

```
Линия:   P = U² / (ρ_T × N_каб) × Sк_б
Петля:   P = U² / (ρ_T × 2·N_каб) × Sк_б
Звезда:  P = (U/√3)² / (ρ_T × 3·N_каб) × Sк_б
```

### ЭР-17. Требуемое сечение и мощность (ТТ Р3, трёхжильный)

```
Линия:                Sк = (Q / U²) × ρ_T × N_каб / 3
Петля (2 каб.×3 ж.):  Sк = (Q / U²) × ρ_T × 2·N_каб / 3
Петля (1 каб.×3 ж.):  Sк = (Q / U²) × ρ_T × 3·N_каб
Звезда (3 каб.×3 ж.): Sк = (Q / (U/√3)²) × ρ_T × 3·N_каб / 3
Звезда (1 каб.×3 ж.): Sк = (Q / (U/√3)²) × ρ_T × 3·N_каб
```

Мощности — аналогично ЭР-16 с множителем ×3 для схем из трёх параллельных
жил (`линия`, `петля 2×3ж`, `звезда 3×3ж`) и без него для схем `1×3ж`.

### ЭР-18. Паспортная модель (каталог с resistance_ohm_km)

Если у строки справочника задано паспортное `resistance_ohm_km`, мощность и
ток считаются по нему (а не по ρ/S):

```
r = resistance_ohm_km / 1000          [Ом/м]
R = r × L_секц × factor_R             (factor_R — схемный множитель)
P = U² / R × factor_P
I = P / U                              (однофазно);  I = P / (U·√3) (трёхфазно)
I ≤ 65 А                               (жёсткий предел)
```

Схемные множители ТТ Р3 (паспортная модель трёх нагревательных жил),
согласованные с ручными схемами:

```
loop_2x3 (петля 2×3ж):  P = U² / (r × L × 2) × 3
star_3x3 (звезда 3×3ж): P = (U/√3)² / (r × L × 3) × 3
```

Для ТТ Р3 запрещено универсальное `per_thread_power × N` — кабель считается
как три параллельные нагревательные жилы.

Сечение и сопротивление ТТ Р3 хранятся в справочнике явно
(`conductor_section_mm2`, `resistance_ohm_km`); извлечение сечения из строки
маркировки — только fallback для legacy-каталогов. Fallback сопротивления:
`R = 17,5 / S` Ом/км.

### ЭР-19. Алгоритм автоподбора (VSDX, полная версия)

```
p1 = Q_треб / L_объекта                     — требуемая удельная мощность, Вт/м
Каталог сортируется по сопротивлению Q(i,1) по убыванию.

Для M = 1 .. max_parallel_schemes (по умолчанию ≤ 20):
  1) Петля (N=2), U = U_start (220 В), длина секции L1
  2) Петля (N=2), U = U_high (380 В)
  3) Звезда (N=3), U = U_high (380 В), длина секции L2

  Для каждого кандидата i:
    p2 = удельная мощность единицы схемы               [Вт/м]
         (для Р3 — со схемными множителями ЭР-18)
    p3 = min(Imax² × r,  max_linear_power_w_m)         [Вт/м]
    кандидат пригоден, если p2 ≤ p3  и  p2 × N × M ≥ p1  и  I ≤ Imax

  Выбирается первый пригодный кандидат.
  Шаговое снижение напряжения (если разрешено политикой):
  U := U − voltage_step, но не ниже U_min.
```

Параметры политики (из `correction_coefficients`, с fallback-значениями):

| Параметр | Fallback |
|---|---|
| Imax | 65 А |
| U_start | 220 В |
| U_high | 380 В |
| U_min (минимум при шаговом снижении) | 40 В |
| voltage_step | 5 В |
| max_parallel_schemes M | 20 |
| max_linear_power_w_m (cap p3), ТТ Р1 | 40 Вт/м (из справочника `common`) |
| max_linear_power_w_m (cap p3), ТТ Р3 | 50 Вт/м (из справочника `common`) |

Результат: марка кабеля, U, схема N (2 — петля, 3 — звезда), количество схем
M, длины секций L1/L2, p2/p3, ток `I = p2·L/U` (схемно), мощность.

### ЭР-20. Ток

```
Однофазная сеть:  I = P / U
Трёхфазная сеть:  I = P / (U × √3)
```

## 4.6. Типы с проектами методик (ожидают утверждения и каталогов)

- **ЭР-21.** `mineral` (кабель с минеральной изоляцией): проект полной
  методики — **документ 12** (модель `P = U²/R(L)`, подбор длины секции по
  q/I_max/p_max, число секций M, проверка температуры оболочки). Навив
  запрещён (шаг = 0, N = 1, VAL-61). До утверждения методики Заказчиком и
  поставки каталога (раздел 12.6) тип отображается как «не поддержано».
- **ЭР-22.** `skin` (скин-системы): проект полной методики — **документ 13**
  (погонные R/X, `I = √(q/R_лин)`, `U = I·Z·L_цепи`, число трубок и цепей,
  трансформаторная мощность). До утверждения и поставки каталога (раздел
  13.6) тип отображается как «не поддержано».

## 4.7. Сообщения об ошибках расчёта (минимум)

| Ситуация | Требуемое поведение |
|---|---|
| Не задан `process_temperature` (ТЛТ, ТТ, Р1/Р3) | Ошибка «Для электрорасчёта требуется температура продукта» |
| Ни одна марка не проходит по температурам | Ошибка с указанием превышенного предела и серии/линейки |
| Совокупная мощность < теплопотерь (VAL-34) | Статус «Ошибка» + рекомендация: больше ниток / меньше шаг навива / марка мощнее |
| Сферический резервуар в подборе самрега | Явная ошибка «форма укладки не поддерживается» |
| Ток > 65 А (резистивные) | Кандидат отклоняется; если решения нет — ошибка с причиной |
| Шаг навива ≤ D трубы | Ошибка валидации (VAL-32) |

Ошибки сохраняются в результатах расчёта и не теряются при перезагрузке.
