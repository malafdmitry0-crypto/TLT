# 13. Методика расчёта скин-систем (индукционно-резистивный обогрев)

> **Статус: проект методики для утверждения Заказчиком.**
> Первоисточник ТНП по скин-системам отсутствует. Методика составлена по
> общепринятой инженерной практике skin-effect trace heating:
> IEEE 844 / IEEE 844.1 + CSA C293.1 (skin effect trace heating of
> pipelines), ГОСТ IEC 60079-30-1/-2, практика систем типа nVent STS /
> Thermon TubeTrace SECT / отечественных ИРСН. После утверждения переносится
> в контракт бизнес-логики и QA-реестр.

## 13.1. Физическая модель

Скин-система — обогрев протяжённых трубопроводов (сотни метров — десятки
километров) от одной точки питания. Конструкция:

- **тепловыделяющая трубка** (скин-трубка) из ферромагнитной стали
  (типично Ø25…57 мм, стенка 3…4 мм), приваренная или закреплённая на
  продуктовой трубе под изоляцией;
- внутри трубки — изолированный **проводник** (медь, изоляция 3…10 кВ),
  соединённый с трубкой на дальнем конце;
- питание переменным током 50 Гц между проводником и трубкой на ближнем
  конце.

Из-за скин-эффекта и эффекта близости обратный ток концентрируется на
**внутренней** поверхности трубки в слое глубиной

```
δ = √(2ρ_ст / (ω × μ0 × μr))    ≈ 1 мм для стали при 50 Гц
   (ρ_ст ≈ 0,1…0,2 мкОм·м, μr ≈ 300…1000, ω = 2π·50)
```

поэтому наружная поверхность трубки практически эквипотенциальна земле —
трубку допустимо приваривать к продуктовой трубе и заземлять. Тепло
выделяется в стенке трубки (и частично в проводнике).

## 13.3. Электрическая модель

### СК-01. Погонные параметры

Конфигурация (типоразмер трубки + сечение проводника) характеризуется
каталожными погонными параметрами при рабочей температуре:

```
R_лин(T)  [Ом/м]  — активное погонное сопротивление контура
X_лин     [Ом/м]  — реактивное погонное сопротивление
Z_лин = √(R_лин² + X_лин²)
cos φ = R_лин / Z_лин          (типично 0,7…0,9)
```

`R_лин(T)` интерполируется по каталожной таблице (сопротивление растёт с
температурой); консервативно принимается значение при температуре
поддержания.

### СК-02. Ток, мощность, напряжение цепи

```
q = I² × R_лин                      [Вт/м]   — удельное тепловыделение
I = √(q_треб / R_лин)               [А]      — требуемый ток
U = I × Z_лин × L_цепи              [В]      — напряжение питания цепи
P_цепи = q × L_цепи                 [Вт]
S_тр = U × I                        [В·А]    — мощность питающего трансформатора
```

`L_цепи` — длина одной цепи: при одностороннем питании `L_цепи = L_об / M`;
при питании из середины (двустороннее) каждая половина — отдельная цепь
`L_цепи = L_об / (2M)`.

## 13.4. Алгоритм подбора (детерминированный)

```
Вход: q_треб, L_об, U_max, T1/T2, каталог
1. Отфильтровать каталог по температурам (T_max изоляции проводника ≥ max(T1,T2))
   и T-классу зоны.
2. Число скин-трубок на трубе:
     n_тр = ceil(q_треб / q_max_трубки)     — если одна трубка не покрывает q_треб
     q_на_трубку = q_треб / n_тр
3. Для каждой конфигурации (R_лин(T), X_лин, I_max, q_max):
     I = √(q_на_трубку / R_лин(T1))
     если I > I_max → конфигурация непригодна
     L_max_цепи = U_max / (I × Z_лин)       — предел по напряжению
4. Число цепей: M = ceil(L_об / L_max_цепи);  L_цепи = L_об / M
   (двустороннее питание при необходимости удваивает покрытие точки питания)
5. Факт: U = I × Z_лин × L_цепи ≤ U_max;  P_цепи = q_на_трубку × L_цепи;
   S_тр = U × I / cos φ (на цепь)
6. Из пригодных выбрать минимальную по порядку:
     (a) меньше n_тр; (b) меньше M; (c) меньше S_тр.
Выход: конфигурация, n_тр, M, L_цепи, I, U, P_общ = q_треб × L_об,
       S_тр суммарная, cos φ.
```

Проверка температуры поверхности трубки для Ex-зон — по стабилизированному
методу ГОСТ IEC 60079-30-1 (каталожная зависимость T_поверхности от q и
T_трубы) — аналогично МИ-03.

## 13.5. Ограничения и особенности

- Навив и «нитки» неприменимы: `winding_step = 0`; аналог ниток — число
  скин-трубок `n_тр` (фиксируется в результате отдельным полем).
- Минимальная экономически осмысленная длина — сотни метров; для коротких
  объектов система должна предупреждать о нецелесообразности (warning, не
  ошибка).
- Точки питания требуют трансформатора с регулировкой/отпайками; состав
  оборудования (трансформатор, шкаф, концевая коробка) включается в BOM
  отдельными правилами (дополнение к документу 6 после утверждения).
- Теплопотери считаются стандартной методикой документа 3; скин-система
  влияет только на электрическую часть.
