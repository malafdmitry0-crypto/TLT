# 10. Сравнение с лучшими мировыми системами и требования следующей очереди

Сравнение проведено с репрезентативными промышленными инструментами
проектирования электрообогрева и теплоизоляции (по их публичной
документации; численный benchmark расчётных движков не выполнялся):

| Система | Профиль | Ключевое для сравнения |
|---|---|---|
| nVent RAYCHEM / Chemelex **TraceCalc Pro / TraceCalc Net** | Проектирование heat tracing труб | Теплопотери, автоподбор кабеля, цепи, BOM, отчёты, heat sinks (клапаны/опоры/фланцы), сертификация и hazardous area |
| Thermon **CompuTrace Express / Design Suite** | Проектирование heat tracing | Проект → цепи → дизайн → BOM; анализ разогрева/остывания; ветер; weather barrier/эмиссивность; area classification, T-rating, AIT |
| NAIMA/NIA **3E Plus** | Расчёт теплоизоляции | Теплопотери и температура поверхности по **ASTM C680** |
| ROCKWOOL **Rockassist** | Теплоизоляция (process/marine/offshore) | **EN ISO 12241:2022**, **VDI 2055**, VDI 4610, подбор продуктов |
| Armacell **ArmaWin** | Теплоизоляция | ISO 12241, VDI 2055-1, JIS A 9501, GB/T 8175 |

## 10.1. Где настоящая система соответствует мировому уровню

| Критерий | Оценка |
|---|---|
| Физическое ядро: многослойная цилиндрическая стенка, `R = ln(r2/r1)/(2πλ)` | Соответствует базовой инженерной модели всех ведущих систем |
| Температурная λ(tm) изоляции из справочника | Совпадает по идее с материальными базами 3E Plus/TraceCalc (не стандартизована как ASTM/ISO — см. 10.2) |
| Ветер: `α = 11,6 + 7√v`, indoor/outdoor режимы | Аналог запроса wind speed в TraceCalc/CompuTrace |
| Подземная труба `R = arccosh(H/r)/(2πλ_гр)` и подземный резервуар | Сильная сторона: у многих vendor-инструментов buried-ветка ограничена |
| Автоподбор кабеля по каталогу + цепные параметры (нитки, навив, схемы) | Соответствует концепции vendor tools |
| BOM из условных правил ТНП | Аналог quote-ready BOM CompuTrace Express / BOM reports TraceCalc |
| Открытость и трассируемость: первоисточник → документация → код → тесты → oracle | **Сильнее** закрытых vendor-движков; уникальное преимущество для аккредитации |
| Локальный климатический справочник (СП 131.13330) с политикой K по диаметру | Локальное преимущество для рынка РФ |

## 10.2. Отставания от мировых систем → требования следующей очереди

Требования ниже — **рекомендуемые** (очередь 2); они не блокируют приёмку
полной версии ТНП, но фиксируются как целевые для конкурентного паритета.

- **РО-01. Температура наружной поверхности изоляции.** 3E Plus считает
  surface temperature по ASTM C680 — критично для безопасности (ожоги),
  конденсации и проверки изоляции. Добавить расчёт `surface_temperature` в
  результаты трубы и резервуара.
- **РО-02. Режим сверки по международному стандарту.** Добавить хотя бы один
  альтернативный режим/бенчмарк расчёта теплопотерь: ASTM C680 или
  ISO 12241 (как у Rockassist/ArmaWin), с golden-набором из 5–7 одинаковых
  кейсов (наружная труба; ветер 3 м/с; помещение; 2 слоя; подземная труба
  H=1,5 м; арматура; T>150 °C).
- **РО-03. Типизированные тепловые мосты.** Заменить единый `L_экв` на
  типизированные элементы: задвижка, задвижка с приводом, пара фланцев,
  опора, подвес — со справочником эквивалентных добавок (аналог valve/flange
  adder tables и fin-модели опор TraceCalc/CompuTrace).
- **РО-04. Покрытие и эмиссивность.** Учесть weather barrier / материал
  обшивки / эмиссивность поверхности в наружной теплоотдаче (как
  CompuTrace).
- **РО-05. Динамика разогрева/остывания.** Heat-up / cool-down анализ
  (время разогрева продукта, время остывания до температуры поддержания) —
  как в Thermon CompuTrace Design Suite.
- **РО-06. Инженерные предупреждения.** Явные warnings в результатах:
  большой диаметр → проверить распределение температуры внутри; высокая
  температура → увеличить запас; жёсткая изоляция → припуск под кабель;
  мокрая/повреждённая изоляция не компенсируется коэффициентом K.
- **РО-07. Сертификация и взрывоопасные зоны.** Сквозной workflow
  hazardous area: класс зоны, T-rating, AIT, допустимые семейства изделий
  (сейчас Ex учитывается только в BOM-корзинах СКВ).
- **РО-08. Отчёты промышленного уровня.** Project summary line list,
  electrical line list, single line detail (по образцу TraceCalc Net) —
  поверх существующего мастера отчёта.
- **РО-09. Эталонный численный benchmark.** Для каждого сравнения с внешней
  программой хранить пакет: входные данные, версия программы, скриншот/отчёт,
  дата (методика — `codex-workspace/heat-loss/*-global-software-comparison.md`).

## 10.3. Почему числа могут отличаться от внешних программ (для приёмки)

| Причина | Влияние |
|---|---|
| Другая табличная база λ материалов | Различие q до единиц процентов |
| Другой стандарт конвекции (ISO/ASTM vs `11,6+7√v`) | Различие внешней теплоотдачи |
| Эмиссивность/покрытие у vendor tools | TLT пока не моделирует |
| Подробные heat sinks vs эквивалентная длина | Различие на объектах с арматурой |
| Политики safety factor | TraceCalc рекомендует >10% для высоких температур |
| `location_indoor = 0,9` | Продуктовая политика, отсутствует в первоисточниках — см. документ 11 |
| Каталожные округления vendor tools | Длина/мощность цепей округляется по каталогу |

Приёмка по числам выполняется **только** против контрольных примеров ТНП
настоящего ТЗ (документы 3–6), а не против внешних программ.
