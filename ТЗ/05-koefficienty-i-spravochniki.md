# 5. Корректирующие коэффициенты и встроенные справочники

Все справочники поставляются как версионируемые данные (JSON в репозитории,
для теплоизоляции — дополнительно runtime-таблица БД). Изменение значений —
только через администратора или новую версию поставки.

## 5.1. Корректирующие коэффициенты (таблица `correction_coefficients`)

Настраиваются администратором; применяются расчётным сервисом в строго
определённых местах (не «ко всему подряд»).

| Ключ | По умолчанию | Диапазон | Где применяется |
|---|---|---|---|
| `safety_factor` (K) | 1,1 | 1,05…1,7 | Множитель итогового Q (трубы и резервуары); в электрорасчёте — запас мощности, ровно один раз (ТР-10/ЭР-01). Климатический алгоритм может задавать 1,1/1,12 (ТР-08) |
| `wind_factor` | 1,0 | — | Множитель расчётного α_внеш надземных объектов; применяется после `11,6 + 7√v`; итог ограничен 52 Вт/(м²·К) |
| `location_indoor` | 0,9 | — | Множитель итогового Q при размещении «в помещении» (продуктовая политика — см. документ 11) |
| `location_outdoor` | 1,0 | — | Множитель итогового Q при размещении «на улице» |
| `ground_conductivity` (default) | 1,5 Вт/(м·К) | 0,5…3,0 | λ грунта по умолчанию для подземной прокладки |
| `max_current_a` (алиас `resistive_max_current_a`) | 65 А | — | Предел тока резистивных схем |
| `start_voltage` (алиасы `resistive_start_voltage_v`, `resistive_default_voltage_v`) | 220 В | — | Начальное напряжение перебора |
| `high_voltage` (алиас `resistive_high_voltage_v`) | 380 В | — | Повышенное напряжение перебора |
| `min_adjusted_voltage` (алиасы `resistive_min_adjusted_voltage_v`, `resistive_min_voltage_v`) | 40 В | — | Минимум при шаговом снижении напряжения |
| `voltage_step` (алиас `resistive_voltage_step_v`) | 5 В | — | Шаг снижения напряжения |
| `max_parallel_schemes` (алиас `resistive_max_parallel_schemes`) | 20 | 1…1000 | Максимум параллельных схем M |
| `max_linear_power_w_m` (алиасы `resistive_single_core_…`, `resistive_three_core_…`) | из справочника | — | Переопределение cap p3 (Р1 = 40, Р3 = 50 Вт/м) |
| `max_conductor_temperature` (алиас `resistive_max_conductor_temperature`) | 130 °C | — | Максимальная температура резистивного кабеля под нагрузкой; минимум по умолчанию −60 °C |

Имена ключей нормативны и совпадают с фактическими ключами таблицы
`correction_coefficients` (приоритет чтения: override запроса → params
объекта → коэффициент БД → fallback кода). Приоритет ввода λ грунта и K:
значение в параметрах объекта выше коэффициента БД.

### 5.1.1. Экономические данные исключены из объёма (решение 2026-06-10)

Экономические расчёты и денежные данные **полностью исключены** из системы:
цены, стоимость, веса коммерческого ранжирования
(`commercial_balanced_weight_*`, `commercial_balanced_weights_approved`,
`commercial_accessory_cost_per_circuit_*`) удаляются из кода, сидов,
коэффициентов и интерфейса. При нескольких технически пригодных кандидатах
автоподбор использует **только технический порядок** (минимальные нитки →
минимальная паспортная мощность → минимальная установленная мощность —
ЭР-05). Допустимые нестоимостные признаки внешней БД (наличие, срок
поставки, приоритет поставщика) могут быть возвращены отдельным решением
Заказчика — без денежных полей.

## 5.5. Справочник грунтов (29 записей)

Группы: песок, суглинок, глинистые. Параметры записи: плотность (кг/м³),

## 5.7. Внешняя (расширенная) БД кабелей и аксессуаров

- Управляется администратором; доступна сотруднику как «база расчёта»
  (`builtin` / `extended` / `all`).
- Технические поля кабеля обязаны содержать все параметры, используемые
  формулами соответствующего типа (мощность/Q1/Q2/сопротивление/сечение,
  температурные пределы, паспортное напряжение).
- Денежные поля (цена, стоимость) во внешней БД **не ведутся** — экономика
  исключена из объёма (5.1.1). Любая проекция внешней БД поверх встроенной
  линейки не должна затирать паспортные технические поля (включая
  `voltage`).
