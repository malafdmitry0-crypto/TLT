## Вопрос 1 (блокер). Схема «звезда» резистивных кабелей — расхождение в 9 раз

### Суть простыми словами

В методике ТНП формулы подбора резистивного кабеля для схем «линия» и
«петля» соответствуют электрической схеме соединения. Для схемы «звезда»
формула ТНП математически описывает **другое** соединение: будто весь кабель
(все три нитки подряд) включён последовательно на фазное напряжение.

Если же «звезда» монтируется как обычная электрическая звезда — три
параллельные ветви, каждая между фазой и нулевой точкой, — то кабель,
подобранный по формуле ТНП, выдаст **в 9 раз больше мощности**, чем
рассчитано. Это перегрев, превышение допустимого тока 65 А и риск выхода
кабеля из строя.

```
Формула ТНП (как написано):   Sк = Q/(U/√3)² × ρ × 3N
   ↳ соответствует: вся длина 3N последовательно на фазном напряжении
Физическая звезда (3 ветви по N параллельно): мощность в 9 раз выше
```

Важно: для «петли» формула ТНП с физикой **совпадает** — расхождение только
в «звезде». Поэтому мы не можем сами решить, что это: осознанный запас
методики, иное понимание схемы или ошибка в документе.

### Что просим

Один контрольный пример реального расчёта «звезды» из практики, с числами:

| Поле | Ваш ответ |
|---|---|
| Теплопотери объекта Q, Вт | |
| Длина обогреваемого участка L, м | |
| Напряжение U, В (линейное) | |
| Температура продукта Tж, °C | |
| Как соединён кабель в «звезде» (3 отдельные нитки между фазой и нулём / одна непрерывная линия / иное — опишите) | |
| Выбранное сечение жилы Sк, мм² (или марка кабеля) | |
| Итоговая мощность P, Вт и ток I, А | |

### Что будет по итогам ответа

- Подтвердится модель ТНП → фиксируем её приёмочным тестом, в отчёте
  появится пояснение схемы соединения.
- Подтвердится физическая звезда → исправляем формулу (сечение уменьшится,
  расчётная мощность вырастет в 9 раз), пересчитываем существующие проекты.

**Пока нет ответа:** система считает по формуле ТНП (как в документе).

## Вопрос 2 (блокер). Паспортная кривая мощности кабеля 15ТТВ2

### Суть простыми словами

Мощность саморегулирующегося кабеля в методике задана прямой
`q = Q1 × T + Q2` (T — температура поддержания). Для марки **15ТТВ2** в
таблице ТНП указан коэффициент **Q1 = −0,491** — он в точности совпадает с
коэффициентом марки **33ТТН2** из соседней таблицы и резко выбивается из
ряда серии ТТВ:

| Марка | Q1 (наклон) | Мощность обнуляется при T = |
|---|---:|---:|
| 30ТТВ2 | −0,141 | 227 °C |
| 45ТТВ2 | −0,217 | 230 °C |
| 60ТТВ2 | −0,250 | 264 °C |
| **15ТТВ2 (в таблице)** | **−0,491** | **32,6 °C** ← аномалия |
| 15ТТХ2 (для сравнения) | −0,072 | 236 °C |

С таким коэффициентом 15ТТВ2 по таблице выдаёт **ноль мощности уже при
+33 °C** и «отрицательную» — выше, хотя серия ТТВ заявлена для поддержания
до 120 °C. По закономерности ряда ожидается Q1 ≈ −0,07. Похоже на ошибку
копирования строки между таблицами при подготовке документа.

### Что просим

Паспортную кривую мощности 15ТТВ2 — любой из вариантов:

| Вариант | Ваш ответ |
|---|---|
| Правильные коэффициенты: Q1 = ___, Q2 = ___ | |
| Либо 2–3 точки паспортной кривой: мощность (Вт/м) при T = 10 / 40 / 80 °C | |
| Либо подтверждение: марка 15ТТВ2 исключается из каталога | |

### Что будет по итогам ответа

Исправляем коэффициент в справочнике, добавляем приёмочный тест «мощность
каждой марки положительна во всём заявленном диапазоне серии».

**Пока нет ответа:** автоподбор защищён — марки с нулевой/отрицательной
расчётной мощностью исключаются из кандидатов автоматически, поэтому
15ТТВ2 при T > 32 °C просто не будет предлагаться.
