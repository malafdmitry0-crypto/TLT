# 7. Отчёты, предпросмотр и экспорт

## 7.1. Предпросмотр и печать (все роли)

- **ОТ-01.** HTML-превью отчёта на экране (санитизация содержимого —
  DOMPurify или аналог) и печать средствами браузера — доступны гостю,
  сотруднику и администратору.
- **ОТ-02.** Мастер состава отчёта: выбор включаемых разделов; должен быть
  выбран хотя бы один раздел (VAL-63).

## 7.2. Состав отчёта (минимальный обязательный)

1. Титульная часть: название проекта, номер задачи, дата, исполнитель
   (финальный корпоративный шаблон — по утверждению Заказчика, документ 11).
2. Исходные данные по каждому объекту: геометрия, изоляция (слои, материалы,
   λ и их источники), температуры и их источники (климат/вручную),
   размещение, грунт.
3. Результаты теплотехнического расчёта: q, Q, диагностические
   сопротивления, применённые коэффициенты (K, K_разм, α, tm).
4. Результаты электротехнического расчёта по активному СО: тип кабеля,
   марка, длина, нитки (запрошено/применено), шаг навива, мощность, ток,
   напряжение; объекты с ошибками — с причиной.
5. Спецификация (базовая или полный BOM — по выбранному режиму).
6. Сводные итоги по проекту: суммарная мощность, суммарный ток, длины
   кабеля по маркам.
7. Сводный отчёт по всем СО (при ≥2 вариантах): сравнительная таблица
   вариантов.

## 7.3. Экспорт (сотрудник и администратор)

- **ОТ-03.** Экспорт отчёта в PDF, DOCX, XLSX. Гостю endpoint недоступен
  (VAL-56) с понятным сообщением.
- **ОТ-04.** Экспорт содержимого должен соответствовать предпросмотру
  (одна модель данных отчёта для HTML и экспортёров).
- **ОТ-05.** Экспорт таблиц объектов в Excel (сотрудник).
- **ОТ-06.** Кириллица обязана корректно отображаться во всех форматах
  (шрифты с поддержкой кириллицы вшиваются в PDF).

## 7.4. Трассируемость расчёта в отчёте

- **ОТ-07.** Для каждого расчётного значения отчёт указывает источник:
  справочник (с кодом материала/города), ручной ввод, климатическое
  автозаполнение, коэффициент администратора.
- **ОТ-08.** Рекомендуется (следующая очередь): печать применённых формул и
  промежуточных величин в режиме «инженерная расшифровка» — по образцу
  отчётов nVent TraceCalc (single line detail report).
