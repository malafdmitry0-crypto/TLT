# Тестовые файлы для импорта объектов

Готовые примеры для проверки функции «Импорт из Excel / CSV» на странице «Расчёт тепловых потерь».

## Файлы

| Файл | Формат | Что внутри |
|---|---|---|
| `sample_import.xlsx` | Excel | **100 записей**: лист «Трубопроводы» (60 труб разных DN от 21 до 426 мм), лист «Резервуары» (40 резервуаров — цилиндры, параллелепипеды, шары) |
| `sample_import.csv` | CSV (разделитель `;`, UTF-8 BOM) | **100 записей** в одном файле, колонка «Тип» со значениями `труба`/`резервуар`, порядок перемешан |

> **Важно:** по умолчанию MVP ограничен лимитом 50 объектов на проект
> (`GUEST_MAX_OBJECTS_PER_PROJECT`). Если хотите импортировать все 100 записей
> — поднимите лимит в `.env` или разбейте импорт на два проекта.

## Как использовать

1. Открыть приложение → `Расчёт тепловых потерь` (Шаг 1).
2. В левой панели: **Импорт (Excel/CSV)** → выбрать один из файлов.
3. После импорта появится модалка с результатом (создано / пропущено с описанием ошибок по строкам).

## Формат Excel

Два листа с заголовками:

**Трубопроводы:** `Наименование · Диаметр, мм · Длина, м · Толщина изоляции, мм · Материал изоляции · T° среды · T° продукта`

**Резервуары:** `Наименование · Форма · Диаметр, мм · Длина, мм · Ширина, мм · Высота, мм · Толщина изоляции, мм · Материал изоляции · T° среды · T° продукта`

Для каждой формы резервуара заполняются только релевантные габариты:
- **Цилиндр** — Диаметр + Высота
- **Параллелепипед** — Длина + Ширина + Высота
- **Шар** — Диаметр

## Формат CSV

Один общий файл, первая колонка — `Тип`:

```
Тип;Наименование;Форма;Диаметр, мм;Длина, мм;Ширина, мм;Высота, мм;Длина, м;Толщина изоляции, мм;Материал изоляции;T° среды;T° продукта
труба;Пример DN100;;108;;;;50;50;Минеральная вата;-20;80
резервуар;Бак цил.;Цилиндр;2000;;;3000;;80;Минеральная вата;-20;80
```

Разделитель определяется автоматически (`;`, `,` или табуляция). Кодировка — UTF-8 (с BOM или без) либо CP1251.

## Допустимые значения

**Материалы изоляции:** Минеральная вата, Пеностекло, Пенополиуретан (ППУ), Пенополистирол, Аэрогель, Силикат кальция — либо англ. коды (`mineral_wool`, `foam_glass`, `polyurethane`, `polystyrene`, `aerogel`, `calcium_silicate`).

**Формы резервуара:** Цилиндр / Параллелепипед / Шар (либо `cylindrical` / `rectangular` / `spherical`).

## Обновление / пересборка файлов

Сэмплы генерируются скриптом `scripts/gen_import_samples.py` (детерминированный
seed — результаты воспроизводимы).

```bash
docker cp scripts/gen_import_samples.py heatcalc_backend:/tmp/gen.py
docker exec heatcalc_backend python3 /tmp/gen.py
docker cp heatcalc_backend:/tmp/sample_import.xlsx docs/samples/sample_import.xlsx
docker cp heatcalc_backend:/tmp/sample_import.csv  docs/samples/sample_import.csv
```

Количество записей и диапазоны параметров настраиваются внутри скрипта
(`gen_pipes(60)`, `gen_tanks(40)`).
