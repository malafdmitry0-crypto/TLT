# Программный комплекс ТЛТ — Документация для приёмки

Комплект документации для демонстрации и приёмки программного комплекса
теплотехнического и электротехнического расчёта систем электрообогрева
(греющий кабель ТЛТ).

Версия сборки: **1.0.0-demo** · Статус: **full-version target, готов к демонстрации**

Актуальное правило: проект проверяется против полной версии. Исторические
упоминания базового уровня ТЗ в комплекте не снижают критерий приемки формул,
алгоритмов и справочников.

## Что НЕ входит в этот комплект

Для чистоты клиентской презентации из документации вынесены следующие файлы
(они доступны в основном репозитории разработчика):

- `CLAUDE.MD`, `backend/CLAUDE.MD`, `frontend/CLAUDE.MD` — внутренние инструкции
  для AI-ассистента разработки
- `docs/playbooks/*` — процедурные заметки для разработчиков
- `docs/context/pitfalls.md` — известные грабли разработки
- `TO_DO.md` — внутренний список задач
