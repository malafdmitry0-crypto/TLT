# MVP — статус и ограничения

## Реализованный функционал (сверка с ТЗ)

По матрице MVP из Приложения №2 ТЗ:

| Раздел ТЗ | Статус | Где реализовано |
|---|:---:|---|
| Гостевой вход | ✅ | `auth/guest`, in-memory IPRateLimiter |
| Управление проектом (создание/открытие/сохранение) | ✅ | `projects/*` CRUD + `projectStore` persist |
| Типы объектов: трубопроводы + ёмкости | ✅ | `PipeTable` / `TankTable`, `ObjectWizard` (3 шага) |
| Формулы MVP из ТНП | ✅ | `heat_loss/pipe.py`, `heat_loss/tank.py` |
| Интеграция климата + теплоизоляции | ✅ | `reference_data/climate.json` (536), `insulation.json` (6) |
| Подсветка некорректных строк | ✅ | `row-invalid` + Alert-легенда |
| Drag-and-drop сортировки | ✅ | `@dnd-kit` в Pipe/TankTable |
| Импорт таблиц из Excel / CSV | ✅ | `/objects/import-excel` |
| Автоподбор ТЛТ | ✅ | `electrical/self_regulating.py` + `batch_calc_electrical` |
| Базовая спецификация | ✅ | `SpecificationPage`, `specification_service.py` |
| Генерация отчёта (HTML preview) | ✅ | `report.html` + `ReportPreview` (+ DOMPurify) |
| Экспорт PDF/DOCX/XLSX (сотрудник) | ✅ | `reports/export/*` (сверх MVP) |
| Docker + docker-compose | ✅ | `docker-compose.yml`, `.dev.yml`, `.prod.yml`, `demo/` |
| Работа в локальной сети без интернета | ✅ | Справочники встроены |

**Сверх MVP реализовано** (в «Полной версии» ТЗ):
- Аутентификация сотрудника/администратора с JWT
- Админка коэффициентов и каталогов
- Экспорт отчёта в 3 форматах
- Проводник проектов

## Известные ограничения

| Ограничение | Описание | Решение в следующей версии |
|---|---|---|
| In-memory rate limiter | Сбрасывается при перезапуске, не работает на нескольких инстансах | slowapi + Redis |
| Теплопроводность изоляции | Константа (не зависит от T°) | Температурозависимая модель |
| Одноинстансный деплой | Нет горизонтального масштабирования | Docker Swarm / K8s |
| Нет email-верификации | Сотрудник создаётся только администратором | Self-service регистрация |
| Только саморегулирующийся кабель ТЛТ | Резистивные, MI, скин-системы — в «Полной версии» | US-09.7 / 09.8 / 09.9 |
| Лимит 50 объектов на проект | Настраивается через `GUEST_MAX_OBJECTS_PER_PROJECT` | — |
| Шифрование формул/справочников | Вариант А (ТЗ §5): внутри Docker-образа | Варианты Б/В (Vault, KMS) |
