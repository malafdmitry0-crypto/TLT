# ТЛТ — Инструкция по запуску демо-версии

Программный комплекс теплотехнического и электротехнического расчёта систем
электрообогрева. Версия **1.0.0-demo**.

Эта инструкция рассчитана на человека, который **не является программистом**.
Следуйте шагам **по порядку**, ничего не пропуская.

---

## Что вам понадобится

1. **Компьютер** с Windows 10/11, macOS или Linux.
2. **Интернет** — только на этапе установки Docker и (опционально) для скачивания образов.
3. **Папка `demo`** (эта папка со всем содержимым).
4. **Права администратора** на вашем компьютере (один раз, для установки Docker).

Оперативной памяти нужно минимум **4 ГБ свободных**, на диске — **2 ГБ**.

---

## Шаг 1 — Установить Docker Desktop

Docker Desktop — это программа, которая позволит запустить приложение.
**Устанавливается один раз**, потом не требуется.

### Windows

1. Откройте в браузере: **https://www.docker.com/products/docker-desktop/**
2. Нажмите **«Download for Windows»** → сохраните файл.
3. Запустите скачанный `Docker Desktop Installer.exe`.
4. В окне установки оставьте все галочки по умолчанию → **OK**.
5. После установки нажмите **«Close and restart»** — компьютер перезагрузится.
6. После перезагрузки запустите **Docker Desktop** (значок кита на рабочем столе).
7. Примите лицензионное соглашение. Регистрация **не обязательна** — нажмите **«Skip»** или **«Continue without signing in»**.
8. Дождитесь, пока в левом нижнем углу окна появится **зелёная точка** и надпись **«Engine running»**.

### macOS

1. Откройте **https://www.docker.com/products/docker-desktop/**
2. Нажмите **«Download for Mac»** → выберите версию для вашего процессора
   (Apple Silicon — для M1/M2/M3, Intel — для старых Mac).
3. Откройте скачанный `Docker.dmg`, перетащите значок Docker в папку Applications.
4. Запустите **Docker** из Launchpad. Разрешите установку привилегированного
   компонента (введите пароль от Mac).
5. Дождитесь значка кита в строке меню вверху — он должен перестать мигать.

### Проверка установки

Откройте **терминал** (Windows: `PowerShell`; macOS: `Terminal`) и выполните:

```
docker --version
```

Должно напечатать что-то вроде `Docker version 24.x.x, build ...`.
Если ошибка — перезапустите Docker Desktop и попробуйте снова.

## Шаг 2 — Загрузить образы приложения

В папке `demo/images/` лежат два файла:
- `heatcalc-backend-1.0.0-demo.tar.gz` (~156 МБ)
- `heatcalc-frontend-1.0.0-demo.tar.gz` (~25 МБ)

Откройте терминал, **перейдите в папку `demo`**:

- **Windows** (PowerShell): `cd "путь\к\папке\demo"`
  — например: `cd "C:\Users\Иванов\Desktop\TLT\demo"`
- **macOS/Linux**: `cd /путь/к/папке/demo`

Затем выполните **две команды** (скопируйте и вставьте целиком):

```
docker load -i images/heatcalc-backend-1.0.0-demo.tar.gz
docker load -i images/heatcalc-frontend-1.0.0-demo.tar.gz
```

Каждая команда выведет строку вида `Loaded image: heatcalc-backend:1.0.0-demo`.
Это значит, что образ успешно загружен. **Делается один раз**.

## Шаг 3 — Запустить приложение

В терминале, находясь в папке `demo`, выполните:

```
docker compose up -d
```

Что произойдёт:
1. Docker запустит базу данных (PostgreSQL).
2. Запустит backend — применит миграции и **автоматически наполнит базу
   тестовыми данными** (10 проектов, 5 сотрудников, кабели, аксессуары).
3. Запустит frontend (веб-интерфейс).

**Первый запуск длится 30–60 секунд.** Дождитесь, пока в терминале не появится
текст вида `✔ Container heatcalc_frontend  Started`.

### Проверить, что всё работает

Выполните:

```
docker compose ps
```

Должны отобразиться **три строки** со статусом `Up` или `Up (healthy)`:
- `heatcalc_db`
- `heatcalc_backend`
- `heatcalc_frontend`

## Управление приложением

Все команды выполняются в терминале из папки `demo`.

### Остановить приложение
```
docker compose down
```
Данные **сохранятся** — при следующем `docker compose up -d` всё будет на месте.

### Перезапустить
```
docker compose restart
```

### Посмотреть логи (если что-то не работает)
```
docker compose logs -f backend
```
Остановить просмотр логов — `Ctrl+C`.

### Полностью удалить всё (включая базу данных)
```
docker compose down -v
```
⚠️ Это **удалит все созданные вами проекты и расчёты**.

## Частые проблемы

### «port is already allocated» / «порт занят»

На компьютере уже что-то использует порт 8080.

**Решение:** откройте файл `docker-compose.yml` в Блокноте, найдите строку
```
      - "8080:80"
```
и замените **левую** цифру — например на `9000:80`. Сохраните файл,
выполните `docker compose down`, затем `docker compose up -d`.
Приложение будет доступно по адресу `http://localhost:9000`.

### «Cannot connect to the Docker daemon»

Docker Desktop не запущен. Запустите его и дождитесь зелёной точки
«Engine running». Повторите команду.

### Приложение открывается, но «502 Bad Gateway» или «пустая страница»

Backend ещё не успел запуститься. Подождите 30 секунд и обновите страницу (F5).
Если не помогло — посмотрите логи: `docker compose logs backend`.

### «no space left on device»

На диске закончилось место. Освободите минимум 2 ГБ.

---

**Контакт поддержки:** в случае проблем приложите вывод команды
`docker compose logs --tail=100 > logs.txt` и отправьте файл `logs.txt` разработчику.
