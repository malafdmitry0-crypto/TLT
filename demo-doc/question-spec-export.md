# Вопрос к заказчику: формат выгрузки спецификации

## Контекст

В текущем контуре реализовано:
- **Просмотр спецификации на экране** — `Шаг 3 → Спецификация` (все роли).
- **Экспорт полного отчёта** в PDF / DOCX / XLSX (только Сотрудник).
  Отчёт содержит пять разделов: титул, теплотехнический расчёт,
  электротехнический расчёт, **спецификация**, итог. Один файл на проект.

Вопрос: нужна ли **отдельная** выгрузка только спецификации (без остальных
разделов отчёта) в Excel и/или Word?

Ниже — пять реальных сценариев использования спецификации. Отметьте, какие
из них у вас встречаются — это определит, нужна ли доработка.

---

## UC-1. Выдача проектной документации

**Актор:** Инженер-проектировщик ТЛТ.

**Сценарий:**
1. Инженер заканчивает расчёт проекта в системе.
2. Формирует **полный отчёт** в PDF (титул + расчёты + спецификация).
3. Подписывает и передаёт заказчику как проектную документацию.

**Достаточно ли текущего функционала?** ✅ Да, отчёт содержит всё.
**Нужна отдельная выгрузка спеки?** ❌ Нет.

---

## UC-2. Передача спецификации в отдел закупок / сметный

**Актор:** Инженер-проектировщик → менеджер по закупкам / сметчик.

**Сценарий:**
1. Проект рассчитан.
2. Менеджеру по закупкам нужна **только таблица позиций с количествами**
   (кабель, аксессуары), без титулов и расчётов.
3. Данные копируются / импортируются в:
   - внутренняя смета (Excel);
   - ERP-система (1С:Предприятие, SAP);
   - система учёта склада.

**Достаточно ли текущего функционала?** ⚠️ Частично.
- Открывают XLSX-отчёт, вручную вычищают лишние страницы → выходит спецификация.
- На 5–10 проектов в месяц — терпимо. На 50+ — раздражает.

**Нужна отдельная выгрузка?** ✅ Да, если UC встречается.

---

## UC-3. Согласование спецификации с заказчиком до отправки полного отчёта

**Актор:** Инженер ↔ заказчик (представитель).

**Сценарий:**
1. До финального отчёта заказчик просит «показать, что будем ставить».
2. Инженер шлёт **только спецификацию** (Word или Excel) по почте.
3. Заказчик правит количества / вычёркивает позиции / утверждает.
4. Инженер отражает изменения в проекте, после утверждения формирует
   полный отчёт.

**Достаточно ли текущего функционала?** ⚠️ Частично.
- Можно скинуть PDF всего отчёта — но это избыточно и «пугает» заказчика.
- Скрин-шот таблицы не подходит для правок.

**Нужна отдельная выгрузка?** ✅ Да, желательно в **Word** (для комментариев).

---

## UC-4. Включение спецификации в тендерную документацию

**Актор:** Тендерный отдел заказчика (энергетическая/нефтегазовая компания).

**Сценарий:**
1. Проект рассчитан, собирается тендер на поставку оборудования.
2. В тендерный пакет идёт **таблица спецификации** с артикулами, без упоминания
   программного комплекса и внутренних расчётов.
3. Табличный формат Excel — стандарт для тендерных запросов.

**Достаточно ли текущего функционала?** ❌ Нет, для тендера из полного отчёта
данные копируются вручную в их шаблон.

**Нужна отдельная выгрузка?** ✅ Да, в **Excel** (формат артикул/описание/кол-во).

---

## UC-5. Архивная копия спецификации по объекту

**Актор:** Архивариус / ответственный хранения документации.

**Сценарий:**
1. После сдачи объекта обязательное хранение всех документов в архиве.
2. Полный отчёт уже в архиве (PDF).
3. Отдельная спецификация дублируется — «удобно при поиске позиций».

**Достаточно ли текущего функционала?** ✅ Да, PDF-отчёт содержит спеку,
поиск по Ctrl+F работает.

**Нужна отдельная выгрузка?** ❌ Нет.

## Что будет реализовано в зависимости от ответов

| Ответ заказчика | Объём работ | Сроки |
|---|---|---|
| UC-1 и UC-5 (только полный отчёт нужен) | Ничего — фича уже готова | 0 |
| UC-2 / UC-4 актуальны → Excel-экспорт спеки | Endpoint + кнопка + шаблон + тесты | 1 рабочий день |
| UC-3 актуален → Word-экспорт спеки | + Word-шаблон с полями для комментариев | +0.5 дня |
| Кастомный шаблон (ГОСТ/фирменный) | + согласование макета, доработка генератора | +1–3 дня |

### Рекомендация команды

Если заказчик **UC-2 / UC-4 подтверждает** — фичу стоит включить в следующую
очередь работ (не блокирует текущую приёмку, но даёт ощутимую ценность бизнесу).

Если ни один из этих сценариев не встречается — оставить как есть, отчёт
покрывает все задачи.
