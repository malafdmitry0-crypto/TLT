# Замечание 5. Верхняя и нижняя границы температуры окружающей среды

**Дата:** 2026-08-16

**Статус:** рабочая позиция для ответа клиенту; не является ACTIVE-очередью разработки

**Источник требований:** `ТНП/1_Кейс_«Расчёт спецификации для неавторизованных пользователей» (1).pdf`,
редакция 4 от 07.07.2026, §6.13–6.14; `ТНП/Алгоритмы/алгоритм климат.pdf|.vsdx`;
справочник `ТНП/Внутренние справочники/Климат.xlsx`

## Прямая цитата клиента

> «Температуру окружающей среды нужно отображать и редактировать как по верхней,
> так и по нижней границе».

## Статус и решение

По **нижней границе** требование **уже реализовано**: расчётная минимальная
температура окружающей среды отображается и редактируется (ручной ввод
перекрывает климатическую подстановку и не перезаписывается системой).

По **верхней границе** замечание **не принимаем без отдельного согласования**:
ни одна формула действующей методики (Кейс ред. 4, §6.13–6.14; VSDX «алгоритм
климат») верхнюю границу не использует, а справочник «Климат.xlsx» верхних
температур не содержит. Редактируемое поле, которое не участвует ни в одном
расчёте, создаёт у инженера ложное ощущение, что система его учла.

## Что прямо написано в источниках

1. Кейс §6.13: температура окружающей среды участвует в подборе как проверка
   нижнего предела марки — `если T_env < T_min: марка не подходит`. Верхнего
   предела по среде в методике нет (верхний предел проверяется по температуре
   продукта: 65/120/150 °C).
2. VSDX «алгоритм климат»: расчётная температура — **минимальная**
   (температура наиболее холодной пятидневки обеспеченностью 0,92 при
   D ≥ 100 мм, абсолютная минимальная при D < 100 мм; коэффициент запаса
   1,1/1,12 соответственно). Базисы — параметры холодного периода
   СП 131.13330 «Строительная климатология».
3. Справочник «Климат.xlsx» содержит только параметры холодного периода:
   пятидневка 0,98/0,92, абсолютный минимум, ветер. Верхних (летних)
   температур в нём нет — отображать и редактировать по верхней границе
   нечего даже как справочную подсказку.
4. Теплопотери, требуемая мощность, стартовый ток при холодном пуске —
   все расчёты методики выполняются на худший **холодный** случай.

## Как реализовано сейчас (проверено на приложении 2026-08-16)

- Поле «Температура окружающей среды, °C» на форме объекта; при ручном вводе
  источник помечается `manual`, и климатическая подстановка его не трогает.
- Автоподстановка по городу (проверка на Москве): труба D = 108 мм →
  −23 °C (пятидневка 0,92, Kзап = 1,1); труба D = 57 мм → −43 °C
  (абсолютный минимум, Kзап = 1,12) — в точности значения из «Климат.xlsx».
- В таблицах отображаются «Т окр.» (теплорасчёт) и «Т среды, °C» +
  «Твкл, °C» + «Климат» (город и применённое правило) — электрорасчёт.

## Когда верхняя граница станет нужна

Если в методику войдёт проверка перегрева / температурного класса для
взрывоопасных зон: по ГОСТ IEC 60079-30 максимальная температура поверхности
кабеля проверяется при **максимальной** температуре окружающей среды.
Это отдельная доработка с тремя обязательными частями: поле верхней границы,
расширение «Климат.xlsx» параметрами тёплого периода (СП 131.13330) и
формула-потребитель. В действующем Кейсе ред. 4 такой проверки нет.

## Готовая формулировка ответа клиенту

> Нижняя граница температуры окружающей среды уже отображается и редактируется:
> значение подставляется автоматически по городу и климатическому правилу
> (пятидневка 0,92 или абсолютный минимум — по диаметру трубы, СП 131.13330)
> и может быть введено вручную — ручное значение система не перезаписывает.
> Верхняя граница в действующей методике (Кейс ред. 4) не участвует ни в одном
> расчёте: подбор кабеля, теплопотери и стартовый ток считаются на худший
> холодный случай, а верхний предел проверяется по температуре продукта.
> Поле для верхней границы появится вместе с проверкой, которая его использует
> (например, контроль температуры поверхности для Ex-исполнений по
> ГОСТ IEC 60079-30) — для этого потребуется также расширение климатического
> справочника параметрами тёплого периода. Если имелось в виду иное
> (например, выбор между пятидневкой и абсолютным минимумом вручную), просим
> уточнить формулировку.
