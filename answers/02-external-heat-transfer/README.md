# Замечание 2. Коэффициент наружной теплоотдачи

**Дата:** 2026-08-14

**Статус:** рабочая позиция для ответа клиенту; не является ACTIVE-очередью разработки

**Источник требований:** `ТНП/1_Кейс_«Расчёт спецификации для неавторизованных пользователей» (1).pdf`,
редакция 4 от 07.07.2026.

## Прямая цитата клиента

> «1) коэффициент наружной теплоотдачи это расчетное значение или табличное,
> убрать опцию заполнения».

Цитата содержит две отдельные части: просьбу убрать ручное заполнение и вопрос
о способе определения коэффициента.

## Статус и решение

- Убрать опцию ручного заполнения — **принимаем. Выполнено.**
- Считать коэффициент обязательно расчётным либо табличным —
  **не определено ТЗ**.

Удалена именно опция заполнения. Отображение применённого коэффициента в
результатах или расшифровке расчёта этому решению не противоречит.

## Как сейчас работает

Для трубопровода пользователь больше не задаёт коэффициент наружной
теплоотдачи вручную. Система определяет его по размещению объекта:

| Размещение  | Применяемое значение                                                               |
| ----------- | ---------------------------------------------------------------------------------- |
| В помещении | Постоянное значение `9 Вт/(м²·К)`                                                  |
| На улице    | Расчёт по формуле `α = 11,6 + 7√v`, где `v` — скорость ветра, м/с                  |
| Под землёй  | Коэффициент наружной теплоотдачи не применяется; используется сопротивление грунта |

## Скриншоты

На форме нет поля ручного ввода коэффициента наружной теплоотдачи ни для
улицы, ни для помещения, ни для подземной прокладки.
