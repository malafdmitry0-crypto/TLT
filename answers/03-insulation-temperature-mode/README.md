# Замечание 3. Режим температуры изоляции (`tm`)

**Дата:** 2026-08-14

**Статус:** рабочая позиция для ответа клиенту; не является ACTIVE-очередью разработки

**Источник требований:** `ТНП/1_Кейс_«Расчёт спецификации для неавторизованных пользователей» (1).pdf`,

## Прямая цитата клиента

> «2) Режим температуры изоляции (tm) откуда это и на что влияет?»

## Статус и решение

Это **запрос на пояснение**, а не дефект и не дополнительное требование.
Изменение продукта не требуется. В ответе нужно объяснить связь поля с ТЗ,
способ определения `tm` в текущей реализации и его влияние на расчёт.

## Что прямо написано в ТЗ

На странице 24 предусмотрен параметр `Условия для расчета изоляции`. Для него
указано:

> «Если есть разные условия эксплуатации»; «Помещение, улица зима/лето, канал,
> тоннель, чердак, подвал и т.п.»; «Влияет на расчетную теплопроводность
> изоляции».

Таким образом, ТЗ прямо требует учитывать условия эксплуатации при определении
теплопроводности изоляции. При этом термина `Режим температуры изоляции (tm)`,
значений `tm` и формул их расчёта в PDF кейса 1 нет. Поле продукта является
реализацией более общего требования ТЗ об условиях расчёта изоляции.

## Откуда это в текущей реализации

Названия режимов соответствуют перечисленным в ТЗ условиям эксплуатации.
Доступные значения и режим по умолчанию зависят от размещения объекта:

| Размещение объекта | Доступные режимы                             | Режим по умолчанию    |
| ------------------ | -------------------------------------------- | --------------------- |
| В помещении        | Помещение, чердак, подвал                    | Помещение             |
| На улице           | Открытый воздух, лето; открытый воздух, зима | Открытый воздух, зима |
| Под землёй         | Канал, тоннель, техническое подполье         | Канал                 |

`tm` рассчитывается из температуры продукта `Tпродукта` по выбранному режиму:

```text
открытый воздух, зима -> tm = Tпродукта / 2
остальные режимы -> tm = (Tпродукта + 40 °C) / 2
```

Эти формулы в проект перенесены из внутреннего справочника
`Теплоизоляция.docx`, основанного на СП 61.13330.2012, приложение Б, таблица
Б.1, примечание 1. Сами формулы не являются отдельным требованием PDF кейса 1.

## На что влияет

`tm` — это расчётная температура, при которой определяется справочная
теплопроводность материала `λ(tm)`. Это не температура продукта и не
температура окружающей среды.

```text
режим -> tm -> λ(tm) -> сопротивление изоляции -> теплопотери
       -> требуемая мощность обогрева -> подбор кабеля и спецификация
```

Например, при температуре продукта `80 °C`:

- для режима `Открытый воздух, зима` получается `tm = 40 °C`;
- для остальных режимов получается `tm = 60 °C`.

Если у справочного материала `λ` зависит от температуры, разные значения `tm`
дают разные `λ` и могут изменить последующие результаты расчёта. Для материала
`Другое` с вручную заданной постоянной `λ` режим `tm` в текущей реализации
численно не меняет `λ` и теплопотери.
