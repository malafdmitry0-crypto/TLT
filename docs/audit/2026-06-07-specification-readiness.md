## 2. Чего НЕТ

### 2.1. Данные от заказчика (блокирующие) — отсутствуют в репозитории
| Данные | Зачем нужны | Без них |
|---|---|---|
| **Таблица `L_max` (макс. длина секции по маркам)** — «таблица Виктора» | разбиение на нагревательные секции (§2) | нельзя посчитать число секций → нельзя посчитать комплекты заделки |
| **`k_пуск` (кратность пускового тока по маркам)** | пусковой ток секции (§3) | нет одного из трёх обязательных параметров секции |
| **`R,гр` (значение по умолчанию + кто задаёт)** | множитель во всех формулах BOM | количество всех комплектов неопределённо |
| **Полный перечень продукции (669 позиций)** | реальная номенклатура спецификации | в backend загружено 6 из ~668 (~1%) |
| **Маппинг «вариант СКВ (Nk1..Nk12) → артикул/код»** | выбор конкретной коробки по `dтр/Ex/К1i/К2i/Кiu` | 12 веток коробок без привязки к товару |
| Полный список условий `Кiu`, темп-классов `T,секц` | ветвление BOM | неполная логика выбора |
| **Методика кабеля MI (минеральная изоляция)** | ветка при T1>150 / T2>250 | нет расчёта для сверхвысокого класса |

### 2.2. Решения (бизнес)
| Вопрос | Статус |
|---|---|
| Каталог **ТЛТ** без первоисточника (марки `ТЛТ-N` синтетические) | *Needs business decision* — даташит или placeholder |
| Напряжение самрега **230 vs 220 В** | подтвердить → строка кабеля и токи зависят |
| Граница температурных классов `<` vs `≤` (на точках 65/120/150…) | аудио **исключено** как основание (заказчик мог оговориться); по умолчанию VSDX `<`; нужно письменное решение — `temperature-class-boundary-decision.md` |
| Полнота/обрыв аудио | нужна полная запись (коробки СКВ, MI, резистив описаны не до конца) |

### 2.3. Реализация (код)
| Не реализовано | Раздел спека |
|---|---|

| **Параметры секции** (пусковой/рабочий ток, мощность) + UI подтаблица | §3 |
| **Условный BOM** (СКВ/КСН/хомуты/ленты/ЗИП по условиям) | `spec-bom-oracle.md` |
| **Диалог настроек** спецификации (Ex, мин. длина, R,гр) | §5 |

| Предложение MI при сверхвысоком классе | §4 |

## 4. Вывод

- **Методику спецификации — можем оформить и реализовать прямо сейчас**: формулы
  BOM, алгоритм секций, температурные классы и поток уже задокументированы (три
  файла выше). Код по ним писать можно.
- **Боевую спецификацию с реальными количествами и артикулами — пока нет.**
  Блокируют 5 наборов данных от заказчика (§2.1): таблица `L_max`, `k_пуск`, `R,гр`,
  перечень 669 позиций, маппинг СКВ→артикул; плюс методика MI и полная аудиозапись.

### Минимальный путь к рабочей версии
1. Получить от заказчика **таблицу `L_max`** и **`R,гр`** → реализовать секции (§2)
   и комплекты заделки (КСН) — это уже даёт осмысленную спецификацию для самрега.
2. Добавить параметры секции (§3) — нужен **`k_пуск`**.
3. Загрузить **перечень 669** + маппинг СКВ → закрыть коробки/хомуты/ленты.
4. Диалог настроек (§5).
5. MI и резистивные ветки — после стабилизации (методику запросить).
