# Спецификация: BOM-oracle из инженерного эталона

**Источник:** `ТНП/Расчет_спецификации_трубы_самрег29_05_26.xlsx`, лист
«Список материалов Самрег» (192 строки). Формулы хранятся как **текстовые правила**
в ячейках (не Excel `=`), извлечены через openpyxl. Это deterministic-oracle для
будущей реализации и тестов автоспецификации (см. разрыв в
`2026-06-07-primary-sources-vs-code.md` — сейчас код даёт лишь 6 generic-аксессуаров).

## Базовые правила

- `Σ(i)` — расчёт ведётся по **каждой** позиции электрорасчёта и суммируется по
  всем позициям проекта.
- `R,гр` — коэффициент резерва («горячий резерв»), множитель на длину/комплекты.
- `N,секц` — число секций (ниток×участков) кабеля позиции; `L,секц` — длина секции;
  `M,секц` — длина материала позиции.
- `dтр` — наружный диаметр трубы (мм в этих формулах).
- Условия ветвления BOM: `Ex` (взрывозащита), `К1i`, `К2i`, `Кiu`, темп-класс
  `T,секц` — управляют выбором подкатегорий коробок/комплектов.

## Извлечённые формулы (цитаты ячеек)

| Поз. | Ячейка | Формула | Смысл |
|---|---|---|---|
| Длина кабеля, низкотемп. (ТТН) | M9–M16 | `L1 = Σ(i)(M,секц = L,секц * N,секц * R,гр)` | суммарная длина низкотемп. кабеля с резервом |
| Длина кабеля, высокотемп. (ТТВ/ТТХ) | M17–M26 | `L2 = Σ(i)(M,секц = L,секц * N,секц * R,гр)` | то же для высокотемп. |
| Заделка КСН-1 (низкотемп.) | M27 | `Fl1 = Σ(i) N,секц * R,гр` | 1 на секцию × резерв |
| Заделка КСН-2 (низкотемп., доп.) | M28 | `Fl2 = Σ(i) N,секц * R,гр * 2` | удвоенный (условие К2i) |
| **Заделка КСВ-1 (высокотемп.)** | M29 | `Fl3 = Σ(i) N,секц*R,гр` | высокотемп. секции (ТТВ/ТТХ), не «КСН-3» |
| **Заделка КСВ-2 (высокотемп., доп.)** | M30 | `Fl4 = Σ(i) N,секц*R,гр*2` | удвоенный (условие К2i) |
| Ремкомплект КСР-1 (низкотемп.) | M31 | `N1 = округл.вверх(ΣL1 / 150; 0)` | 1 компл / 150 м кабеля |
| Ремкомплект КСР-2 (высокотемп.) | M32 | `N2 = округл.вверх((ΣL2+ΣL3) / 150; 0)` | то же для высокотемп. |
| Коробки СКВ (12 вариантов) | M33–M44 | `Nk{1..12} = Σ(i) округл.вверх(N,секц / 3; 0)` | 1 коробка на 3 секции; вариант СКВ выбирается по комбинации `dтр≷57`, `Ex`, `К1i`, `К2i`, `Кiu` |
| Хомут ХК | M48 | `Kr3 = Σ(i)(((dтр*3,14*1,2)+50)/1000) * 2 * (Nk1..Nk6)` | по числу коробок |
| Лента крепёжная ЛКС | M50 | `Kr1 = Σ(i)((3,14*dтр*2,5/1000)*(L1/0,3)) * 1,1` | по длине кабеля, шаг 0.3 м, +10% |
| Этикетка | (по тексту) | `MrEl1 = Σ округл.вверх(Lтр / 3,5)` | 1 этикетка / 3.5 м трубы |

## Как превратить в тесты

1. **Unit (builder):** задать 1 позицию электрорасчёта с известными `N,секц`,
   `L,секц`, `R,гр`, `dтр`, флагами `Ex/К1i/К2i` → проверить, что builder выдал
   ожидаемые `L1`, `Fl*`, `Nk*`, `Kr*` ровно по формулам выше. Каждая ветка СКВ
   (12 вариантов) = отдельный кейс с граничным `dтр=57` и `N,секц=3` (граница
   `округл.вверх`).
2. **Boundary:** `округл.вверх` — кейсы на точные кратные (150 м, 3 секции, 3.5 м):
   ΣL1=150 → N1=1; ΣL1=151 → N1=2.
3. **Σ(i):** 2+ позиции → суммирование по проекту.
4. **Registry:** при формализации перенести таблицу в machine-readable вид рядом с
   `qa-agent/examples/tlt-formulas.registry.yaml` (отдельная секция `specification`).
