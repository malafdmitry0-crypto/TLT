## 3. Ключевое изменение — не цифры, а класс защиты

Все семь дефектов были **регрессиями инструментов**, которые ничто не удерживало.
Теперь каждый закрыт вместе с guard, показанным красным на сломанном входе:

| Guard | Ловит |
|---|---|
| `cssArchitectureGate` | ratchet-файл переименован или потерян |
| `agentEntrypoints` | hook ссылается на несуществующий скрипт; исчез root вход; второй Playwright config |
| `repoRootHygiene` | tracked артефакт в корне; неизвестный корневой файл |
| `agentScopeCommands` | prose в командной позиции; несуществующий npm-скрипт; фильтр без совпадений |
| `canonicalDodCommand` | CI и доки разошлись в имени полного proof |

Один из них сработал по-настоящему в момент внедрения: `repoRootHygiene` упал
на том, что root `AGENTS.md` создан, но не добавлен в индекс.
