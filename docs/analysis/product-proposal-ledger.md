# Реестр продуктовых предложений

**Обновлено:** 2026-07-19

**Статус всех записей:** концепция; не утверждённое требование и не обещание
реализации.

Этот реестр сохраняет полезные идеи из двух старых больших proposal-файлов без
устаревающих оценок, псевдоточного roadmap и неподтверждённых заявлений о
текущем коде. Перед планированием любой записи нужно заново пройти цепочку
`ТЗ/PDL -> текущий контракт -> код -> тесты` и проверить, не реализована ли уже
часть сценария под другим названием.

## Правила перевода в работу

- Запись становится требованием только после явного решения владельца продукта
  и добавления в ТЗ/PDL/SRS.
- Для расчётных идей обязательны независимый source/oracle, boundary и
  metamorphic cases; название технологии не является методикой.
- Для импорта, массовых операций и версионирования обязательны идемпотентность,
  стабильные ключи, partial success и повторный запуск.
- Для SaaS/API/подписи/АСУ ТП сначала утверждаются security и ownership
  boundaries.
- Оценка сроков делается после свежего impact analysis. Оценки из удалённых
  proposal-документов 2026-05 не считаются актуальными.
