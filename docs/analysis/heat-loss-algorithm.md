## 2. Алгоритм по первоисточникам

### 2.1. Трубопровод (P-PIPE, P-PIPE-VAR)

**Общая формула (P-PIPE):**

```text
Q = (Tж − Tос) / R_итого × (L + Lдоп) × K

R_итого = R_стенки + Σ R_из_i + R_внеш

R_слоя (цилиндр) = ln(d_внеш / d_внут) / (2π × λ)     — на 1 м длины

Lдоп = Σ (l_i × n_i)
```

**Надземно (P-PIPE):**

```text
R_внеш = 1 / (π × α_внеш × d_нар_из)
α_внеш = 11,6 + 7 × √v                              — P-NORM-α; в помещении α = 9,0 (P-PIPE-VAR, α диапазон 7…52)
```

**Под землёй, бесканальная прокладка (P-PIPE):**

```text
R_внеш = (1 / (2π × λ_гр)) × ln[(2H / d_нар) + √((2H / d_нар)² − 1)]
```

Эквивалентно `arccosh(H / r_нар) / (2π × λ_гр)` при `r_нар = d_нар / 2`.

**Переменные и диапазоны (P-PIPE-VAR):**

| Символ | Наименование | Единица | Диапазон в XLSX |
|---|---|---|---|
| dтр | Наружный диаметр | м | 0,0108 – 3,0 |
| Tж | Температура жидкости | °C | −90…+600 |
| Tос | Температура среды | °C | −70…+70 |
| n | Число слоёв изоляции | — | 1…3 |
| δиз_i | Толщина i-го слоя | м | 0,01…500 |
| L | Длина секции | м | 0,5 – 200 000 |
| H | Глубина заложения | м | 0 – 200 |
| K | Коэффициент запаса | — | 1,05 – 1,7 |
| αвнеш | Наружная теплоотдача | Вт/(м²·К) | 7 – 52 |
| λгр | Теплопроводность грунта | Вт/(м·К) | **0,8 – 3** |
| l_i | Экв. длина локального элемента | м | 0,1 – 6,9 |

**Удельная мощность для электроподбора (P-PIPE):**

```text
q_для_электроподбора = Q / (L + Lдоп)     — без K в q; K применяется в электрическом блоке один раз
```

**λ изоляции (P-INSUL):** не константа; `λ_из = f(tm)` по материалу.  
Режимы tm: теплые — `tm = (Tж + 40) / 2`; открытый воздух зима — `tm = Tж / 2`.

**λ стенки трубы:** P-PIPE-VAR задаёт λтр 0,001…400; конкретные зависимости λ(T) — из материалов проекта / базы (не в DOCX 30.04).

### 2.2. Резервуар (P-TANK, P-TANK-VAR)

**На воздухе (P-TANK):**

```text
Q = (Tж − Tос) / (δ_р/λ_р + δ_из/λ_из + R_внеш) × S × K + Q_доп

R_внеш = 1 / α_внеш
α_внеш = 11,6 + 7 × √v
```

**Площадь S (P-TANK):**

```text
Круглое сечение:     S = (π × d_р²) / 2 + π × d_р × H
Прямоугольное:       S = 2 × (L + B) × H + 2 × L × B
```

**Под землёй (P-TANK):**

```text
Q = [(Tж−Tос)/(δ_р/λ_р + δ_из/λ_из + h/λ_гр) × S_1
   + (Tж−Tос)/(δ_р/λ_р + δ_из/λ_из + R_внеш) × S] × K + Q_доп
```

**Площади при частичном погружении (P-TANK), h — высота подземной части:**

```text
Круг:  S   = πd²/4 + πd(H−h)          S_1 = πd²/4 + πdh
Прям.: S   = 2(L+B)(H−h) + LB        S_1 = 2(L+B)h + LB
```

**Qдоп (P-TANK, P-TANK-VAR):** дополнительные потери (днище, штуцера); прибавляются **после** умножения основной части на K.

**Периметр для длины кабеля (P-TANK):**

```text
Круг:  П = 3,14 × d_р
Прям.: П = 2 × (L + B)
```

**q для электроподбора (P-TANK):**

```text
q = Q / N,   где N — длина греющей части кабеля по схеме укладки
q_для_электроподбора = (Q / K) / N     — если Q уже содержит K
```

## 4. Открытые расхождения (только vs первоисточники)

### 4.1. Kразm (location_indoor / location_outdoor)

- **Первоисточники:** P-PIPE, P-TANK содержат K, Lдоп, Qдоп; помещение учитывается через α=9. Отдельного множителя Kразm=0,9 в DOCX/XLSX **нет**.
- **Приложение:** умножает итоговое Q на 0,9 (indoor) / 1,0 (outdoor).
- **Нужно:** подтверждение инженером/заказчиком или удаление множителя.

### 4.2. Диапазон λгр

- **P-PIPE-VAR:** 0,8…3,0 Вт/(м·К).
- **Приложение:** принимает 0,5…3,0.
- **Нужно:** сузить до 0,8 или подтвердить расширение справочником P-SOIL.

## 5. Что подтверждено первоисточниками (не является отклонением)

- `(L + Lдоп) × K` — скобки вокруг всей длины, K не только на Lдоп (P-PIPE).
- Qдоп резервуара не умножается на K (P-TANK).
- λ изоляции — функция tm, не фиксированная 0,045 (P-INSUL).
- Rвнеш резервуара — плоская стенка `1/α`, не цилиндрическая формула трубы (P-TANK).
- Периметр прямоугольника `2(L+B)`, не `2LB` (P-TANK).
