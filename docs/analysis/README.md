## Контекст проекта

**HeatCalc** — веб-приложение для автоматизации инженерных расчётов тепловой защиты технологических трубопроводов и оборудования нефтегазовой отрасли.

### Проблема, которую решает система

Расчёт теплопотерь и подбор кабельного обогрева исторически выполнялся вручную в Excel-таблицах, что приводило к:

- **Ошибкам** из-за ручного ввода и неактуальных коэффициентов
- **Несогласованности** — разные специалисты применяли разные методики
- **Медленному согласованию** — отчёты в произвольных форматах затрудняли проверку
- **Потере знаний** — при смене сотрудника методология «уходила вместе с ним»

### Решение

Единая платформа с:
- Встроенными формулами (закон Фурье, многослойная цилиндрическая стенка)
- Централизованными корректирующими коэффициентами, управляемыми администратором
- Автоматической генерацией спецификации и отчётов в трёх форматах (PDF, DOCX, XLSX)
- Гостевым режимом для внешних проектировщиков без регистрации

### Архитектура (кратко)

```
Frontend (React/Vite/Ant Design) ←→ Backend (FastAPI/Python) ←→ PostgreSQL
```
