## Подтверждено последним пользовательским скрином

- Тип: трехжильный нагревательный кабель постоянной мощности `ТТ Р3`.
- Максимальная температура под нагрузкой: `130 °C`.
- Максимальная температура без нагрузки: `180 °C`.
- Минимальная температура эксплуатации/хранения/монтажа: `-60 °C`.
- Сечение жилы: `0,5; 0,7; 1,0; 1,5; 2; 3; 4; 6; 8; 10; 12; 14; 16 мм²`.
- Номинальное линейное напряжение питания: `~1000 В`.
- Строительная длина кабеля, не менее: `200 м`.
- Температурный класс: `T6...T3`.
- Взрывозащита: `Ex 60079-30-1 IIC T6...T3 Gb X`.

## Ограничение конвертации и оставшаяся сверка

Этот документ теперь доверяет последним пользовательским скринам как источнику
истины для перечисленных выше полей `ТТ Р3`. Рабочий машинный справочник в
приложении находится в `backend/app/reference_data/resistive_cables.json`.

Машинный справочник хранит технические поля явно: `conductor_section_mm2` и
`resistance_ohm_km`. Сечение берётся из подтверждённого списка сечений ТТ Р3,
а сопротивление для расчётного fallback фиксируется как `17.5 / S`, Ом/км.
Runtime-код сначала использует явные технические поля; извлечение сечения из
строки `model` оставлено только как fallback для legacy/неполных каталогов.

Поля `standard_supply_voltage_v = 380` и `max_linear_power_w_m = 50` в JSON
сейчас оставлены как ранее существующие справочные значения, но на последних
двух скринах они не видны. Для их финальной приемки нужен отдельный скрин или
исходная страница.
