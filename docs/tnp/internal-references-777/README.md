# Карта конверсии папки `ТНП/Внутренние справочники777`

Папка содержит 12 файлов. Девять из них байт-в-байт совпадают с уже
подключёнными источниками либо с алгоритмом климата. Для них повторные
Markdown-копии не создавались. Три уникальных источника конвертированы отдельно.
