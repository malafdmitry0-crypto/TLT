```text
q=(Q) / (N)
```

Если `Q` уже содержит коэффициент запаса `K`, а электрический расчет применяет
`safety_factor` отдельно, для передачи в электрический подбор используется
мощность без повторного `K`: `q_для_электроподбора = (Q / K) / N`.

### q – строка 24

В электрическом подборе значение из базы `qб` сравнивается с эффективной
требуемой мощностью `q_для_электроподбора × safety_factor`.
