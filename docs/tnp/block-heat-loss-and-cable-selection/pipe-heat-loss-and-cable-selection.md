### Формулы подбора резистивных кабелей

```text
q_для_электроподбора=(Q) / ((L+∑(L_доп))×K)
```

Для электрического подбора передается удельная теплопотеря без повторного
коэффициента запаса. Если использовать `q = Q / (L+∑(L_доп))`, то следующий
электрический расчет должен идти с `K = 1`, иначе коэффициент запаса будет
применен дважды. В текущем приложении используется первый контракт:
`q_для_электроподбора` без `K`, а электрический расчет применяет свой
`safety_factor` ровно один раз.

В электрическом подборе значение из базы `qб` сравнивается с эффективной
требуемой мощностью `q_для_электроподбора × safety_factor`.
