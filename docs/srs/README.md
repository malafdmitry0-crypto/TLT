## ER-SUPERSESSION

Файлы этой папки создавались для baseline с фиксированными `СО1…СО4`.
Соответствующие пункты, таблицы и ASCII-макеты сохранены как историческая
трассировка, но с 18–19.07.2026 **не являются текущим ER-контрактом**.

Вместо них действует следующее:

- до readiness-инициализации проект может иметь 0 ЭР, после неё — 1…5;
- ЭР имеет изменяемое имя и постоянный project-scoped UUID;
- `legacy_variant_number=1…5` — временный compatibility detail, не identity;
- UI показывает динамические вкладки по именам и отдельно хранит selected/active;
- specification/report принимают явные UUID ЭР и не смешивают их результаты;
- фактические переходные ограничения перечислены в `docs/api.md` и
  `codex-docs/requirements-map.md`.

Остальные требования старой декомпозиции также нужно сверять по цепочке
`ТЗ/PDL → текущий контракт → код → тесты`; дата файла сама по себе не доказывает
актуальность.
