UI-прототипы SRS

Программный комплекс ТЛТ — теплотехнический и электротехнический расчёт систем электрообогрева

Гость без регистрации

Один активный проект, индикатор сессии в шапке, операции «Создать новый» и «Загрузить CSV» с заменой текущего. Все 4 типа кабеля и до 4 вариантов расчёта (CO1…CO4) на проект.
  1. SC-01. Главная (выбор режима)
  2. SC-03. Рабочий стол · «Теплопотери» (плоская встроенная форма; кабель и CO — на следующем шаге)
  3. SC-04. Рабочий стол · «Электрорасчёт» (встроенная форма выбора кабеля + CO1…CO4 + сравнение)
  4. SC-05. Рабочий стол · «Спецификация»
  5. SC-06. Рабочий стол · «Отчёт» (только печать)

Сотрудник по логину и паролю

Авторизация, проводник проектов, множество проектов, чужие проекты с пометкой владельца, тогглер «База расчёта» (встроенная / расширенная внешняя), расширенная спецификация, мастер выбора состава отчёта, экспорт PDF / DOCX / XLSX, сводный отчёт по нескольким CO.
  1. SC-02. Форма входа Сотрудника
  2. SC-08. Проводник проектов
  3. SC-03. Рабочий стол · «Теплопотери» (плоская встроенная форма; кабель и CO — на следующем шаге)
  4. SC-04. Рабочий стол · «Электрорасчёт» (тогглер базы расчёта + встроенная форма кабеля + CO1…CO4 + сравнение)
  5. SC-05. Рабочий стол · «Спецификация» (расширенный режим, замена позиций)
  6. SC-06. Рабочий стол · «Отчёт» (+ экспорт в файлы + мастер состава)
  7. SC-09. Мастер выбора состава отчёта (отдельное окно)
ⓘ Прототипы — иллюстративные. При несогласованности между UI-прототипом и основным документом SRS преимущество имеет основной документ (../01-user-stories.md … ../07-report-requirements.md).
Образец-ориентир по UX рабочего стола — программа-аналог «Тепломаг»: встроенная плоская форма ввода объекта без шагов, панель действий «Добавить / Изменить / Применить ко всем / Удалить» и единая таблица трубопроводов и резервуаров.
Полная версия: 4 типа кабеля (саморегулирующийся / одножильный / трёхжильный / минеральная изоляция), множественные варианты расчёта CO1…CO4 с активным маркером, расширенная внешняя БД для Сотрудника, расширенная спецификация, мастер выбора состава отчёта.
