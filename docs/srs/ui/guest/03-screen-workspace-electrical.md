# UI · Гость · Рабочий стол — «Электрорасчёт»

В файле собраны сценарии второго шага рабочего стола Гостя —
электротехнического расчёта. На странице Гость:

1. Сверху страницы выбирает **активный вариант расчёта CO1 … CO4**
   (страничный режим). В выбранном варианте отображаются параметры
   и результаты расчёта.
2. В каждой **карточке объекта** ниже выбирает кабель (тип, марка,
   шаг навива, количество ниток). По умолчанию выбор сохраняется
   **для текущего варианта CO**, но в модалке ручного выбора марки можно
   отметить дополнительные CO1 … CO4. Кабель задаётся **отдельно для
   каждого объекта**.

Сценарии:

- **UC-G-14.** Автоматический электрорасчёт.
- **UC-G-15.** Выбор марки кабеля (в карточке объекта).
- **UC-G-16.** Настройка навива и нескольких ниток.
- **UC-G-25.** Выбор типа кабеля (из 4 типов).
- **UC-G-26.** Создание варианта расчёта (CO1 … CO4).
- **UC-G-28.** Выбор активного варианта расчёта.

## SC-04. Общий вид страницы «Электрорасчёт»

Структура страницы (сверху вниз):

1. **Страничные CO-вкладки** — CO1, CO2, CO3, ＋ Добавить вариант
   (CO4); под ними — кнопки «★ Сделать активным», «✎
   Переименовать», «🗑 Удалить вариант», «⚡ Пересчитать вариант».
2. **Сводка по проекту** — длина кабеля, мощность, ток (по
   текущему выбранному варианту CO).
3. **Баннер ошибок** — если есть объекты с ошибкой расчёта.
4. **Карточки объектов** — по одной на объект; в каждой —
   собственная форма выбора кабеля (тип, марка, шаг навива,
   количество ниток) + поля результата (длина, мощность, ток,
   статус).

### Состояния карточки объекта

| Состояние                       | Иконка | Содержимое                                                         |
|---------------------------------|--------|--------------------------------------------------------------------|
| Успех (Расчёт выполнен)         | ✓     | Зелёный заголовок; марка, длина, мощность, ток                     |
| Ошибка                          | ⚠     | Красный заголовок; причина ошибки + рекомендация                   |
| Не рассчитан                    | ⚪    | Серый Tag «—»; ссылка «Перейти к теплопотерям»                    |

### Триггер расчёта

Электрорасчёт запускается автоматически в двух случаях:
- При нажатии кнопки `[ Электрорасчёт → ]` на странице SC-03.
- При изменении параметров объекта (марка кабеля, навив, нитки) в
  таблице SC-03 — пересчитывается только один объект.

При массовом пересчёте `[Пересчитать все]` или `[Пересчитать выбранные]`
строки с ручной маркой кабеля сохраняются по умолчанию. Если такие строки есть,
подтверждение показывает их количество и unchecked чекбокс
`Перезаписать ручные выборы`; без этого чекбокса ручные строки пропускаются и
остаются в таблице с меткой `ручн.`.

## UC-G-15 / UC-G-25. Выбор типа и марки кабеля в карточке объекта

- **FR:** FR-33, FR-36. **VAL:** VAL-30, VAL-58, VAL-61.

В **каждой карточке объекта** на SC-04 — собственная форма выбора кабеля.
По умолчанию она работает с текущим вариантом CO (выбран сверху страницы);
модалка ручного выбора марки содержит чекбоксы `СО1` … `СО4`, где текущий
CO отмечен при открытии, а пользователь может дополнительно отметить другие
варианты для сохранения того же выбора. Сохранение в несколько CO выполняется
атомарно: если выбранная марка или автоподбор не проходят хотя бы для одного
отмеченного варианта, изменения по этому действию не применяются ни к одному
из отмеченных CO. Поля:

- **Тип кабеля** — Select из 4 значений: Саморегулирующийся /
  Одножильный постоянной мощности / Трёхжильный постоянной
  мощности / Кабель с минеральной изоляцией.
- **Марка** — список марок зависит от выбранного типа и активной
  базы расчёта.
- **Шаг навива** и **Количество ниток** — задаются здесь же; для
  типа «минеральная изоляция» оба поля блокируются (VAL-61).

Кабель и параметры укладки задаются **отдельно для каждого
объекта**. При смене типа список марок обновляется автоматически.

## UC-G-26 / UC-G-28. Создание варианта расчёта и выбор активного

- **FR:** FR-56, FR-58. **VAL:** VAL-59, VAL-60.

В верхней части SC-04 — страничные **CO-вкладки**: CO1, CO2, CO3,
**＋ Добавить вариант (CO4)**. Клик по табу `＋` создаёт новый
вариант (до 4 на проект). При переключении CO-вкладки карточки
объектов ниже показывают параметры кабеля и результаты для
выбранного варианта.

Кнопка `[★ Сделать активным]` помечает текущий вариант маркером
**★** — ровно один активный на проект. Активный вариант идёт в
спецификацию и отчёт; смена активного автоматически переформирует
спецификацию.

Создание 5-го варианта отклоняется с сообщением «Не более 4
вариантов расчёта» (VAL-59).

> **На этой странице нет вкладки «Сравнение вариантов»** —
> переключение между CO выполняется страничными CO-вкладками.

## UC-G-14. Автоматический электрорасчёт

- **Роль:** Гость. **US:** US-G-18.
- **FR:** FR-33, FR-34, FR-35, FR-39.

### Шаги

**Шаг 1.** Гость на SC-03 нажимает `[ Электрорасчёт → ]`.

**Шаг 2.** Система для каждого объекта с маркой кабеля «Авто»
подбирает оптимальную марку из активной базы расчёта в пределах выбранного типа кабеля.

**Шаг 3.** Происходит переход на SC-04, где видна сводка и
карточки объектов.

**Шаг 4.** Если есть объекты с ошибкой — баннер «Ошибок: N» в
шапке сводки и красные карточки внизу.

## UC-G-16. Настройка навива и нескольких ниток

- **Роль:** Гость. **US:** US-G-20.
- **FR:** FR-37, FR-38, FR-39. **VAL:** VAL-31, VAL-32, VAL-34.

Настройка выполняется **в карточке каждого объекта** на SC-04 для
текущего варианта CO (выбран сверху страницы).

### Поля карточки объекта на SC-04

```
 │ Тип кабеля ▼ │ Марка ▼  │ Шаг навива │ Ниток ▼ │
 │ Самор-ся   ▼ │ ТЛТ-15 ▼ │   60 мм    │   2 ▼   │
```

### Логика расчёта (для понимания)

```
   Длина кабеля       = L_трубы × k_навива × n_ниток × 1.10
                         где k_навива = π·D / шаг_навива  (если шаг > 0)
                         иначе k_навива = 1
   Совокупная мощн.  = P_удельная × длина_кабеля
   Совокупная мощн. ≥ q_суммарные  (VAL-34)
```

### AF-1. Две нитки 15 Вт/м вместо одной 30 Вт/м

Пример: пользователь выбирает ТЛТ-15 (15 Вт/м) с двумя нитками
вместо одной ТЛТ-30 (30 Вт/м). Снято ограничение «удельная
мощность ≥ q/L» — VAL-34 проверяет совокупную мощность по сумме
ниток.

```
 Объект: труба DN150, q=72 Вт/м, L=80 м (q_суммарные = 5760 Вт)
 
 ┌─ Вариант 1: ТЛТ-30, 1 нитка, без навива ────────────────┐
 │  Длина кабеля    = 80 × 1.10 = 88 м                     │
 │  Совокупная мощн.= 30 × 88   = 2640 Вт                  │
 │  Достаточно?     ❌ 2640 < 5760 — недостаточно          │
 └─────────────────────────────────────────────────────────┘
 
 ┌─ Вариант 2: ТЛТ-15, 2 нитки, шаг навива 60 мм ──────────┐
 │  k_навива        = π·159 / 60 = 8.32                    │
 │  Длина кабеля    = 80 × 8.32 × 2 × 1.10 = 1463 м        │
 │  Совокупная мощн.= 15 × 1463 = ... (упрощённо)          │
 │  → проверяется по точной формуле                         │
 │  Достаточно?     ✓ — расчёт успешен                     │
 └─────────────────────────────────────────────────────────┘
```

> **Q-D в открытых вопросах документа 01:** точная формула
> расчёта длины кабеля с учётом навива и количества ниток
> **передаётся Заказчиком отдельно** — пример выше иллюстративный.

### EF-1. Шаг навива меньше наружного диаметра

При попытке ввести шаг навива меньше Ø трубы — поле подсвечивается
и появляется inline-сообщение:

```
 Шаг навива:
 [ 50 ] мм   ⚠ Шаг навива должен быть больше наружного диаметра 
              трубы (Ø 108 мм).
```

### EF-2. Совокупная мощность недостаточна (VAL-34)

Объект на SC-04 в карточке отображается с красным заголовком и
текстом ошибки + рекомендацией (см. карточку «Труба-3» в общем
макете SC-04 выше).
