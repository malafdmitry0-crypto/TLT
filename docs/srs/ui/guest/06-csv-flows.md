# UI · Гость · Обмен проектами в формате CSV

В файле собраны сценарии Гостя по сохранению и загрузке проекта
целиком в формате CSV.

- **UC-G-19.** Экспорт проекта в CSV.
- **UC-G-20.** Импорт проекта из CSV (с заменой текущего проекта).

> Импорт **объектов** в существующий проект — другая операция, см.
> UC-G-12 в файле `02-screen-workspace-heatcalc.md`.

> **Phase 5 override, 19.07.2026.** По PDL-ER-41 новый export создаётся только
> в schema v3; v2 остаётся import-only adapter. Missing/mismatched
> formula/catalog source восстанавливает inputs/graph, но помечает calculated
> state stale/unsupported. Guest-файл с manual BOM rows отклоняется атомарно.
> Пример schema v2 ниже сохраняется как описание legacy input, а не target
> export.

## UC-G-19. Экспорт проекта в CSV

- **Роль:** Гость. **US:** US-G-24.
- **FR:** FR-49, FR-51.

### Точка входа

В меню проекта (боковая панель рабочего стола) — пункт «Экспорт CSV».

### Шаги

**Шаг 1.** Гость нажимает «Экспорт CSV» в меню проекта.

**Шаг 2.** Система формирует CSV-файл с секциями `metadata`,
`objects`, `electrical`, `specifications` и инициирует загрузку:

```
                ┌───────────────────────────────────────────────────────────┐
                │ Загружается: T-2026-DEMO_Мой-проект.tlt.csv               │
                │ Размер: 18.4 КБ                                          │
                │ [✓] Загрузка завершена                                  │
                └───────────────────────────────────────────────────────────┘
```

### Имя файла

Шаблон: `«‹номер задачи›_‹название›.tlt.csv»`. Если номер задачи
не задан — `«‹название›.tlt.csv»`. Кириллица в имени — через RFC 5987,
файл с UTF-8 BOM (для совместимости с Excel в русской локали).

### Структура CSV (для понимания, схематично)

```
[SECTION];metadata
key;value
schema_version;2
name;Мой проект
task_number;T-2026-DEMO
description;
status;draft

[SECTION];objects
object_key;type;name;sort_order;params;results;is_valid;validation_errors
obj-1;pipe;Труба-1;0;{"outer_diameter":0.108,...};{"heat_loss_per_meter":54.3,...};true;
obj-2;pipe;Труба-2;1;{"outer_diameter":0.159,...};{"heat_loss_per_meter":72.1,...};true;

[SECTION];electrical
object_key;variant_number;cable_type;cable_type_source;cable_mark;cable_mark_source;params;results
obj-1;1;self_regulating;auto;ТЛТ-10;auto;{};{"installed_cable_length":50.0,"order_cable_length":55.0,"total_power":1650,"current":7.5}
obj-2;1;self_regulating;auto;ТЛТ-15;auto;{};{"installed_cable_length":160.0,"order_cable_length":176.0,"total_power":5280,"current":24.0}

[SECTION];specifications
variant_number;items
1;[{"category":"Кабель","name":"ТЛТ-10",...}, ...]
```

### Зачем экспортировать

Гостевая сессия удаляется после 3 дней неактивности (PDL-ER-26). Экспорт
CSV — единственный способ для Гостя сохранить проект на следующий
сеанс работы:

```
   Цикл работы Гостя:
   
   t=0       Войти без регистрации → Мой проект
             ▼
   t=10 мин  Заполнил объекты, выполнил расчёт, сформировал отчёт
             ▼
   t=11 мин  📥 Экспорт CSV → Мой-проект.tlt.csv (на диске)
             ▼
   ...3 дня неактивности — сессия удалена...
             ▼
   t=24 ч    Войти заново → новая сессия с пустым «Мой проект»
             ▼
   t=24 ч    📤 Загрузить CSV (с заменой) → восстановлен проект (UC-G-20)
```

## UC-G-20. Импорт CSV (с заменой текущего проекта)

- **Роль:** Гость. **US:** US-G-25.
- **FR:** FR-50. **VAL:** VAL-43, VAL-44, VAL-46, VAL-47.

### Точка входа

В меню проекта — пункт «Загрузить CSV (заменить)».

### Шаги

**Шаг 1.** Гость в меню проекта выбирает «Загрузить CSV (заменить)».

**Шаг 2.** Открывается диалог выбора файла:

```
                ╔═══════════════════════════════════════════════════════════╗
                ║          Загрузить проект из CSV (с заменой)              ║
                ╠═══════════════════════════════════════════════════════════╣
                ║                                                           ║
                ║   ⚠  Текущий проект и все его данные (5 объектов,         ║
                ║      результаты расчётов, спецификация) будут             ║
                ║      БЕЗВОЗВРАТНО удалены и заменены на загружаемый.     ║
                ║                                                           ║
                ║   ⓘ Если хотите сохранить текущий проект, сначала         ║
                ║      нажмите «Экспорт CSV» в меню проекта.                ║
                ║                                                           ║
                ║   ┌───────────────────────────────────────────────────┐   ║
                ║   │                                                   │   ║
                ║   │   Перетащите .tlt.csv-файл сюда или нажмите       │   ║
                ║   │   кнопку                                          │   ║
                ║   │                                                   │   ║
                ║   │              [ Выбрать файл ]                     │   ║
                ║   │                                                   │   ║
                ║   └───────────────────────────────────────────────────┘   ║
                ║                                                           ║
                ║                                          [ Закрыть ]      ║
                ╚═══════════════════════════════════════════════════════════╝
```

**Шаг 3.** Гость выбирает файл — открывается окно подтверждения
замены (VAL-44):

```
                ╔═══════════════════════════════════════════════════════════╗
                ║   ⚠  Подтвердить замену проекта?                          ║
                ╠═══════════════════════════════════════════════════════════╣
                ║                                                           ║
                ║   Текущий проект «Мой проект» и все его данные будут     ║
                ║   удалены.                                                ║
                ║                                                           ║
                ║   Вместо него будет загружен:                             ║
                ║                                                           ║
                ║      📄  T-2026-DEMO_Мой-проект.tlt.csv                  ║
                ║          17 объектов | спецификация: есть                ║
                ║                                                           ║
                ║                  [ Загрузить ]   [ Отмена ]              ║
                ╚═══════════════════════════════════════════════════════════╝
```

**Шаг 4.** Гость подтверждает. Текущий проект удаляется,
загруженный становится активным. Восстанавливаются: общие
первичные данные, объекты, результаты электрорасчёта,
спецификация. Гость попадает на рабочий стол загруженного
проекта.

### EF-1. Файл повреждён или неподдерживаемый формат

```
                ┌─────────────────────────────────────────────────────────┐
                │  ⚠  Не удалось загрузить файл                           │
                │                                                         │
                │  Причина: отсутствует обязательная секция [metadata].   │
                │                                                         │
                │  Текущий проект НЕ удалён и остаётся активным.          │
                │                                                         │
                │                              [   ОК    ]                │
                └─────────────────────────────────────────────────────────┘
```

## Сравнение экспорта и импорта у Гостя

| Аспект                        | Экспорт (UC-G-19)         | Импорт (UC-G-20)                     |
|-------------------------------|---------------------------|---------------------------------------|
| Точка входа                   | Меню проекта на SC-03     | Меню проекта на SC-03                 |
| Действие с текущим проектом   | Не изменяется             | **Удаляется** (с заменой)             |
| Подтверждение                 | Не требуется              | Обязательно (VAL-44)                  |
| При ошибке                    | Не применимо              | Текущий проект **сохраняется**        |
| Что в результате              | Файл .tlt.csv на диске    | На месте текущего — загруженный проект|
