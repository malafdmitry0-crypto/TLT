# UI · Сценарии для роли «Гость»

## Применимость

В этой папке собраны UI-схемы и сценарии для роли **«Гость»** —
пользователь, работающий **без регистрации**.

### Особенности роли «Гость»

- Сессия создаётся одним нажатием кнопки «Войти без регистрации»
  на главной странице. Логин и пароль не запрашиваются.
- В сессии активен **ровно один** проект. Списка нескольких
  проектов и переключения между ними нет.
- При входе автоматически создаётся пустой проект «Мой проект».
- Гость может **создать новый проект** (с заменой текущего),
  **загрузить проект из CSV** (с заменой текущего) или **удалить
  текущий проект** (после удаления Система автоматически создаёт
  новый пустой «Мой проект»).
- Перед заменой / удалением рекомендуется сохранить проект через
  экспорт CSV.
- **Недоступны:** экспорт отчёта в файлы (PDF / DOCX / XLSX),
  ведение нескольких проектов, проводник проектов, доступ к чужим
  проектам.
- Сессия и временный project восстанавливаются по валидному session id и
  завершаются после 3 дней без активности (sliding TTL, PDL-ER-26).

## Маршрут пользователя

```
   SC-01 «Главная»                                                                  
   ─────────────────────                                                            
   [ Войти без регистрации ]                                                        
                  │                                                                 
                  ▼                                                                 
   SC-03 «Теплопотери» (рабочий стол активного проекта «Мой проект»)               
   ──────────────────────                                                          
   • Заполнить параметры трубопровода или резервуара во встроенной форме SC-03
   • Импорт XLSX/CSV объектов / редактирование / удаление / копирование строк      
                  │                                                                 
                  ▼                                                                 
   SC-04 «Электрорасчёт»
   • Выбрать CO-вариант, базу расчёта, тип/марку кабеля и параметры подбора
                  │                                                                 
                  ▼                                                                 
   SC-05 «Спецификация»                                                             
                  │                                                                 
                  ▼                                                                 
   SC-06 «Отчёт» (HTML-предпросмотр + печать средствами браузера)                  
                                                                                    
   В любой момент:                                                                  
   • Меню проекта → «Создать новый» (с заменой)                                    
   • Меню проекта → «Загрузить CSV» (с заменой)                                    
   • Меню проекта → «Экспорт CSV» (сохранить проект)                               
   • Меню проекта → «Удалить проект» (с автосозданием нового пустого)              
                                                                                    
   Через 3 дня неактивности (фоновый процесс):
   • Сессия удаляется → проект и все данные каскадно очищаются (UC-G-21)          
```
