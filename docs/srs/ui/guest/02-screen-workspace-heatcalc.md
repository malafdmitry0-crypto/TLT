### Шаги

**Шаг 1.** Гость открывает блок (или Система открывает автоматически
при первом входе в проект).

**Шаг 2.** Заполняет регион — соседние поля «Температура окр. среды»
и «Скорость ветра» подставляются из справочника.

**Шаг 3.** Уточняет остальные параметры. Подсказки рядом с полями
(см. UC-G-24).

**Шаг 4.** Сохраняет. Если в проекте уже есть объекты — Система
показывает баннер «Пересчитать все объекты по новым параметрам?»
с кнопкой пересчёта.

## UC-G-07 и UC-G-08. Добавление объекта (трубопровод / резервуар)

- **Роль:** Гость. **US:** US-G-10, US-G-11.
- **FR:** FR-19 … FR-26. **VAL:** VAL-14 … VAL-29.

> **Важно.** Форма ввода / редактирования объекта — **встроенная
> плоская форма**, постоянно видимая в верхней части рабочего
> стола. Это **часть основного интерфейса**, **не модальное окно**.
> Все поля видны одновременно (без шагов / вкладок / кнопок
> «Далее»). Ориентир по UX — программа «Тепломаг».
>
> **Как пользоваться:**
> - Клик по строке таблицы → форма наверху наполняется
>   значениями этой строки (режим «редактирование»).
> - Клик «+ Добавить» в панели действий → форма очищается под
>   новую запись (режим «новая»).
> - Изменения применяются кнопкой «💾 Сохранить изменения» (для
>   текущей строки) или «Применить ко всем» (для всех выделенных
>   строк).
>
> Над инженерными группами формы отображается пустой резервный раздел
> «алгоритм выбора кабеля». На SC-03 он не задаёт тип/марку кабеля и
> служит местом для дальнейшего уточнения требований заказчика.

### Матрица появления и скрытия полей встроенной формы

Эта матрица является обязательной частью SRS для SC-03. Если
условие не выполнено, поле не должно занимать место в форме, не
должно быть доступно с клавиатуры и не должно отправляться как
пользовательский ввод. Исключение — служебные hidden-поля источника
климата, которые не имеют видимого представления.

#### Размещение и тип объекта

| Тип объекта | Размещение | Видимые зависимые поля | Скрытые зависимые поля |
|-------------|------------|-------------------------|-------------------------|
| Трубопровод | На открытом воздухе | `Скорость ветра`, `α внеш` | `Глубина прокладки`, `Грунт`, `λ грунта` |
| Трубопровод | В помещении | `α внеш` | `Скорость ветра`, `Глубина прокладки`, `Грунт`, `λ грунта` |
| Трубопровод | Подземно | `Глубина прокладки`, `Грунт`, `λ грунта` | `Скорость ветра`, `α внеш` |
| Резервуар | На открытом воздухе | `Скорость ветра`, `α внеш` | `Высота подземной части`, `Грунт`, `λ грунта` |
| Резервуар | В помещении | `α внеш` | `Скорость ветра`, `Высота подземной части`, `Грунт`, `λ грунта` |
| Резервуар | Подземно | `Высота подземной части`, `Грунт`, `λ грунта`, `Скорость ветра`, `α внеш` | — |

Для подземного резервуара `Скорость ветра` и `α внеш` остаются
видимыми, потому что расчёт делится на надземную площадь
`S_возд` и подземную площадь `S_гр`. Для подземной трубы эти поля
скрываются, так как используется грунтовое сопротивление.

#### Климат

| Состояние | Видимые поля | Скрытые поля | Поведение |
|-----------|--------------|--------------|-----------|
| Климат не выбран | `T° окр. среды`; при наружном воздухе — `Скорость ветра` | `Температура климата` / `Обеспеченность климата`, метка `из климата` | Пользователь вводит значения вручную |
| Климат выбран | `Температура климата` (`0,92`, `0,98`, `Абс. мин.`), `T° окр. среды`, при наружном воздухе — `Скорость ветра`, метка источника | — | Система заполняет `T° окр. среды` и `Скорость ветра` из справочника, если значения есть |
| Значение температуры/ветра изменено вручную | Те же поля | — | Метка конкретного поля меняется на `вручную`; выбранный климат остаётся для трассировки |

Служебные поля `climate_city`, `climate_region`,
`ambient_temperature_source`, `wind_speed_source` не отображаются в
UI. Их появление как пустых инпутов считается дефектом интерфейса.

#### Режим λ трубы

| Режим | Видимые поля | Скрытые поля | Данные для сохранения |
|-------|--------------|--------------|------------------------|
| `Справ.` | `Материал трубы` | Ручное поле `λ трубы` | `pipe_material` |
| `Вручн.` | Ручное поле `λ трубы` | `Материал трубы` | `pipe_lambda` |

Если задана толщина стенки трубы, расчёт должен получить либо
`pipe_material`, либо `pipe_lambda`. Одновременная отправка обоих
значений из формы не допускается.

#### Слои изоляции

| Кол-во слоёв ИЗ | Видимые поля | Скрытые поля |
|-----------------|--------------|--------------|
| `1 слой` | `Материал изоляции`, `Толщина изоляции`, `λ 1-го слоя` | Все поля 2-го и 3-го слоя |
| `2 слоя` | Поля 1-го слоя + `Материал 2-го слоя`, `Толщина 2-го слоя`, `λ 2-го слоя` | Все поля 3-го слоя |
| `3 слоя` | Поля 1-го, 2-го и 3-го слоя | — |

Для любого слоя: поля `λ` и `Диапазон T` видимы и доступны всегда. Если
выбран материал из справочника, они заполняются справочными значениями;
при ручном изменении `λ` или диапазона T материал слоя автоматически
переключается на `Другое`, а ручные значения становятся обязательными.

## UC-G-13. Ручной ввод λ для материала «Другое»

- **Роль:** Гость. **US:** US-G-12.
- **FR:** FR-23. **VAL:** VAL-28, VAL-29.

В мастере объекта на шаге «Теплофизика»:

```
   Материал слоя 1: [ Минеральная вата ▼ ]
                                                                  
   λ, Вт/(м·К):    [ 0.045 ]   ← поле активно всегда; ручная правка
                                   переключает материал на «Другое»
                                                                  
   ⓘ Диапазон 0,001…400 Вт/(м·К). Используется вместо табличного.
                                                                  
   Толщина:         [ 80 ] мм                                     
```

Если λ вне диапазона — поле подсвечивается красным, кнопка
«Далее» неактивна:

```
   λ, Вт/(м·К):    [ 8.5 ]    ⚠ Значение должно быть в диапазоне 
                              0,001 … 400 Вт/(м·К)
```

## UC-G-23. Excel-подобная работа с таблицей

- **US:** US-G-27. **FR:** FR-29, FR-30.

В заголовке колонки «#» — чекбокс «Выбрать все»; в каждой строке —
чекбокс. После выбора активируются кнопки группового действия
под таблицей: «Скопировать выделенное» и «Удалить выделенные».

Стандартными `Ctrl+C` / `Ctrl+V` копируется выделенная
прямоугольная область ячеек таблицы. Затронутые строки
автоматически пересчитываются.

> экспорт текущего вида в Excel — см. вопрос Q-B документа 01.

создаётся новый пустой с указанными свойствами и становится
