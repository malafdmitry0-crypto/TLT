# UI · Гость · Рабочий стол — «Отчёт»

В файле собран сценарий финального шага рабочего стола Гостя —
просмотра и печати отчёта.

- **UC-G-18.** Предпросмотр и печать отчёта (только средствами браузера).

> **Важно.** Гостю **недоступен** экспорт отчёта в файлы PDF /
> DOCX / XLSX. Эту операцию выполняет только Сотрудник
> (см. файл `employee/06-screen-workspace-report.md`).

### Состав отчёта (общий для обеих ролей)

| Раздел                                     | Содержимое                                                  |
|--------------------------------------------|-------------------------------------------------------------|
| 1. Титульная часть                          | Название отчёта, проект, номер задачи, дата                |
| 2. Общие первичные данные                  | Регион, температура, напряжение, запас, прокладка          |
| 3. Исходные данные по объектам             | Таблицы трубопроводов и резервуаров                          |
| 4. Результаты расчёта теплопотерь          | Линейные / удельные / суммарные значения                    |
| 5. Результаты электротехнического расчёта   | Марка, длина, мощность, ток + сводная часть                 |
| 6. Спецификация материалов                  | Группировка по категории, артикулы, количество             |
| 7. Справочная часть                          | (на согласование) коэффициенты, формулы, нормативы          |

> **Подробный состав** и точный перечень полей — в документе
> `07-report-requirements.md`. Подлежит согласованию с Заказчиком.

## UC-G-18. Предпросмотр и печать отчёта

- **Роль:** Гость. **US:** US-G-22, US-G-23.
- **FR:** FR-44, FR-45, FR-47.

### Шаги

**Шаг 1.** Гость на пошаговой навигации выбирает шаг 4 «Отчёт» —
открывается SC-06.

**Шаг 2.** Видит HTML-предпросмотр отчёта.

**Шаг 3 (печать).** Нажимает кнопку `[ 🖨 Печать ]` — браузер
открывает стандартный диалог печати.

```
                ╔══════════════════════════════════════════════╗
                ║   Печать                       (диалог браузера)║
                ╠══════════════════════════════════════════════╣
                ║                                              ║
                ║   Принтер: [ Microsoft Print to PDF ▼ ]      ║
                ║                                              ║
                ║   Страницы: ( ) Все   (●) 1-3                ║
                ║   Ориентация: (●) Книжная   ( ) Альбомная    ║
                ║   Цвет: (●) Цветной   ( ) Чёрно-белый        ║
                ║                                              ║
                ║   Предпросмотр:                              ║
                ║   ┌──────────────────────┐                   ║
                ║   │  ОТЧЁТ ПО РАСЧЁТУ... │                   ║
                ║   │  ...                 │                   ║
                ║   └──────────────────────┘                   ║
                ║                                              ║
                ║                       [ Печать ] [ Отмена ]  ║
                ╚══════════════════════════════════════════════╝
```

При печати элементы навигации, боковая панель и индикаторы сессии
**скрываются** (стиль `@media print`).

### EF-1. Гость пытается обратиться к экспорту в файлы (VAL-56)

Если Гость по прямой ссылке вызывает endpoint экспорта в PDF /
DOCX / XLSX:
