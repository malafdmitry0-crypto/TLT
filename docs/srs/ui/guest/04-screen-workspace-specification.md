### Колонки таблицы спецификации

| Колонка          | Источник                                                       |
|------------------|----------------------------------------------------------------|
| #                | Порядковый номер                                                |
| Категория        | Кабель / Муфты / Управление / Защита / Индикация / Монтаж     |
| Наименование     | Из справочника аксессуаров (для кабелей — название марки)       |
| Артикул          | Уникальный код позиции из справочника                           |
| Ед. изм.         | м (для кабеля), шт (для всех остальных)                         |
| Количество       | Сумма по проекту                                                |

Сортировка: сначала по категории, затем по наименованию.

## UC-G-17. Формирование и просмотр спецификации

- **Роль:** Гость. **US:** US-G-21.
- **FR:** FR-40 … FR-43.

### Шаги

**Шаг 1.** Гость переходит на SC-05 (Шаг 3 пошаговой навигации).

**Шаг 2.** Если спецификация ещё не формировалась, страница
показывает только кнопку `[ Сформировать спецификацию ]` и
краткую подсказку:

```
                ┌─────────────────────────────────────────────────────┐
                │                                                     │
                │       Спецификация ещё не сформирована.             │
                │                                                     │
                │   Для генерации спецификации требуется выполненный  │
                │   электрорасчёт хотя бы для одного объекта.         │
                │                                                     │
                │           [ Сформировать спецификацию ]             │
                │                                                     │
                └─────────────────────────────────────────────────────┘
```

**Шаг 3.** Гость нажимает кнопку. Система:
- группирует кабели по марке, суммируя длину;
- добавляет набор аксессуаров для активного варианта CO (муфты, термостаты,
  защитную автоматику, индикаторы, крепёж — из справочника);
- сортирует позиции по категории и наименованию.

**Шаг 4.** Появляется таблица (см. SC-05 выше).

### AF-1. Повторное формирование

При повторном нажатии кнопки `[ Сформировать спецификацию ]`
открывается подтверждение:

```
                ╔═══════════════════════════════════════════════╗
                ║  Перегенерировать спецификацию?                ║
                ╠═══════════════════════════════════════════════╣
                ║                                                ║
                ║   Текущая спецификация будет полностью         ║
                ║   перезаписана с учётом актуальных результатов ║
                ║   электрорасчёта.                              ║
                ║                                                ║
                ║                  [ Перегенерировать ] [Отмена] ║
                ╚═══════════════════════════════════════════════╝
```

### AF-2. Нет валидных объектов

Если в проекте нет ни одного объекта с успешным электрорасчётом,
после нажатия кнопки появляется пустая спецификация с подсказкой:

```
                ┌─────────────────────────────────────────────────────┐
                │  Спецификация пустая.                               │
                │                                                     │
                │  Для формирования спецификации добавьте объекты и   │
                │  выполните электрорасчёт (Шаги 1–2).                │
                │                                                     │
                │       [ ← Перейти к теплопотерям ]                  │
                └─────────────────────────────────────────────────────┘
```
