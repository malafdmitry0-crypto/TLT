# UI · Жизненный цикл гостевой сессии (фоновые процессы)

В файле собран сценарий автоматической очистки данных Гостя при
неактивности.

- **UC-G-21.** Автоматическое завершение сессии по неактивности.

> **Важно.** Этот сценарий применим **только** к роли Гость.
> Сессия Сотрудника управляется через токен авторизации с
> отдельной логикой продления и не удаляется автоматически по
> неактивности.

---

## UC-G-21. Автоматическое завершение сессии по неактивности

- **Роль:** Гость (фоновый процесс выполняется Системой без
  участия пользователя).
- **US:** US-G-07.
- **FR:** FR-05. **NFR:** NFR-REL-04.
- **VAL:** VAL-54.

---

## Жизненный цикл сессии: визуализация

```
   t = 0           Вход без регистрации (UC-G-01)
   ───────────────────────────────────────────────────────────────────
   ┌──────────────────────────────────────────────────────────────┐
   │  Гость нажимает «Войти без регистрации»                       │
   │  → Создаётся сессия + один пустой проект «Мой проект»         │
   │  → last_activity = now                                         │
   └──────────────────────────────────────────────────────────────┘
                               │
                               ▼
   t = 0..N мин    Активная работа Гостя
   ───────────────────────────────────────────────────────────────────
   ┌──────────────────────────────────────────────────────────────┐
   │  Каждое действие (запрос к серверу) обновляет last_activity   │
   │  Индикатор в шапке: ⓘ Гость, осталось 19′ (обновляется)      │
   └──────────────────────────────────────────────────────────────┘
                               │
                               ▼  Гость уходит / закрывает вкладку
   t = N мин       Сессия становится неактивной
   ───────────────────────────────────────────────────────────────────
   ┌──────────────────────────────────────────────────────────────┐
   │  Никаких запросов от Гостя; last_activity остаётся прежним    │
   └──────────────────────────────────────────────────────────────┘
                               │
                               ▼
   t = N + 20′     TTL истекает
   ───────────────────────────────────────────────────────────────────
   ┌──────────────────────────────────────────────────────────────┐
   │  Сессия отмечена как протухшая (last_activity < now − 20′)   │
   └──────────────────────────────────────────────────────────────┘
                               │
                               ▼
   t < N + 30′     Фоновая задача удаляет сессию
   ───────────────────────────────────────────────────────────────────
   ┌──────────────────────────────────────────────────────────────┐
   │  Раз в 10 мин фоновая задача `cleanup_guest_sessions`         │
   │  удаляет сессии с last_activity < now − 20′. Каскадно         │
   │  удаляются:                                                   │
   │     • проект                                                  │
   │     • объекты                                                 │
   │     • результаты расчётов                                     │
   │     • спецификация                                            │
   └──────────────────────────────────────────────────────────────┘
```

### Гарантии по времени

| Событие                                         | Время |
|-------------------------------------------------|-------|
| Минимальное время до удаления данных Гостя      | 20 мин неактивности |
| Максимальное время до удаления (с учётом фоновой задачи) | 30 мин (TTL 20′ + интервал 10′) |
| Типичное время на практике                      | ≤ 25 мин |

## UI: индикатор оставшегося времени в шапке

В шапке всех экранов Гостя виден индикатор, наведение мыши на
который раскрывает подсказку:

```
   Свёрнутый вид:
   ┌──────────┐
   │ ⓘ 19′    │   ← обновляется при каждом действии
   └──────────┘

   Наведение мыши:
   ┌─────────────────────────────────────────────────┐
   │ ⓘ Сессия Гостя                                   │
   │   Осталось до автоматического завершения: 19 мин │
   │   Сессия продлевается при любом действии в       │
   │   приложении.                                     │
   │   Чтобы сохранить проект перед уходом — нажмите  │
   │   «Экспорт CSV» в меню проекта.                  │
   └─────────────────────────────────────────────────┘
```

## UI: сообщение при возврате после завершения сессии

Гость возвращается в браузер позже 30 минут и пытается выполнить
какое-либо действие (нажать кнопку, перейти на другую страницу).
Сервер возвращает ошибку «Сессия не найдена», и приложение
показывает блокирующее модальное окно:

```
                ╔═══════════════════════════════════════════════════════════╗
                ║   ⓘ  Сессия завершена по неактивности                     ║
                ╠═══════════════════════════════════════════════════════════╣
                ║                                                           ║
                ║   Ваша гостевая сессия и все её данные были автоматически ║
                ║   удалены, так как никаких действий не выполнялось более  ║
                ║   20 минут.                                                ║
                ║                                                           ║
                ║   Чтобы продолжить работу, войдите заново.                 ║
                ║                                                           ║
                ║   Если у вас был сохранённый CSV-файл проекта, его можно ║
                ║   будет загрузить через меню проекта в новой сессии.      ║
                ║                                                           ║
                ║                              [ Войти заново ]             ║
                ╚═══════════════════════════════════════════════════════════╝
```

После нажатия «Войти заново» Гость попадает на SC-01 (главная
страница).

---

## Что не происходит

- Сессия Сотрудника **не подвержена** этому сценарию — у Сотрудника
  отдельный механизм авторизации (токен) с собственными правилами.
- Активная работа Гостя (любое действие на странице, отправляющее
  запрос на сервер) **продлевает** сессию автоматически — даже если
  Гость не сохраняет проект явно.
- Открытое окно браузера само по себе **не** считается активностью —
  важны именно запросы к серверу.
