# UI · Гость · Главная страница

В файле — единственный сценарий стартового экрана для роли «Гость»:

- **UC-G-01.** Вход без регистрации с автоматическим созданием проекта.

---

## SC-01. Главная страница (выбор режима)

### Назначение

Стартовый экран приложения. Гость нажимает «Войти без регистрации»
и сразу попадает на рабочий стол с автоматически созданным
пустым проектом. Кнопка «Войти как сотрудник» из этой роли не
используется (приведена для полноты, ведёт в раздел Сотрудника).

### Элементы экрана

| Элемент                          | Тип    | Назначение                                                              |
|----------------------------------|--------|-------------------------------------------------------------------------|
| Кнопка «Войти без регистрации»   | Button | Вызывает UC-G-01: создаётся гостевая сессия + один пустой проект         |
| Кнопка «Войти как сотрудник»     | Button | Не относится к роли «Гость» (см. папку `employee/`)                     |

## UC-G-01. Вход без регистрации с автоматическим созданием проекта

- **Роль:** Гость.
- **US:** US-G-01.
- **FR:** FR-01, FR-02, FR-06.
- **VAL:** VAL-55 (лимит 10 сессий с одного IP в час).

### Шаги сценария

**Шаг 1.** Гость открывает SC-01 и нажимает «Войти без регистрации».

**Шаг 2.** Система создаёт гостевую сессию + один пустой проект
«Мой проект» и сразу делает его активным. Гость попадает на
SC-03 — рабочий стол «Теплопотери».

```
SC-01                            SC-03 «Теплопотери» (рабочий стол)
┌──────────────────────┐         ┌────────────────────────────────────────┐
│                      │         │ ТЛТ │ Шаги 1●─2○─3○─4○ │ ⓘГость 19′    │
│ [ Войти без рег.] ───┼────────►│ Проект: «Мой проект» (создан только что)│
│ [ Войти как сотр.]   │         │ Объектов: 0/50  · Электрорасчёт: не запущен│
└──────────────────────┘         │ ...                                    │
                                 └────────────────────────────────────────┘
```

### Альтернативные / исключительные потоки

**EF-1.** Превышен лимит **VAL-55** — Гость остаётся на SC-01,
поверх формы появляется уведомление:

```
                ┌──────────────────────────────────────────────────────────┐
                │  ⚠  Слишком много попыток входа с этого IP                │
                │                                                          │
                │  Превышен лимит 10 гостевых сессий с одного IP в час.    │
                │  Попробуйте войти позже или обратитесь к администратору. │
                │                                                          │
                │                                       [   ОК    ]        │
                └──────────────────────────────────────────────────────────┘
```

**EF-2.** Сервис временно недоступен — баннер «Сервис временно
недоступен, попробуйте позже».

### Постусловие

Создана гостевая сессия. У Гостя есть один активный пустой проект
«Мой проект», открыт рабочий стол. Индикатор оставшегося времени в
шапке начинает отсчитывать TTL (см. UC-G-21).
