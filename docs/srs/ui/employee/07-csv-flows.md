# UI · Сотрудник · Обмен проектами в формате CSV

В файле собраны сценарии Сотрудника по сохранению и загрузке
проекта целиком в формате CSV.

- **UC-G-19.** Экспорт текущего проекта в CSV.
- **UC-E-06.** Импорт CSV как нового проекта (без замены существующих).

> **Важно.** В отличие от Гостя, у Сотрудника:
> - Импорт CSV **не заменяет** существующие проекты — просто
>   создаёт новый проект в проводнике.
> - При конфликте номера задачи название получает суффикс «(импорт)».
> - Точка входа в импорт — **из проводника проектов** (SC-08),
>   а не из меню текущего проекта.

## UC-G-19. Экспорт проекта в CSV

- **Роль:** Сотрудник. **US:** US-G-24.
- **FR:** FR-49, FR-51.

### Точки входа

У Сотрудника есть **две** точки входа в экспорт CSV:

1. **Из рабочего стола** — пункт «Экспорт CSV» в меню проекта
   (боковая панель SC-03).
2. **Из проводника проектов** — кнопка `[ CSV ]` в строке
   проекта на SC-08 (см. файл `02-screen-projects-explorer.md`).

Обе точки приводят к одному и тому же действию.

### Шаги

**Шаг 1.** Сотрудник нажимает «Экспорт CSV» (в меню проекта или в
проводнике).

**Шаг 2.** Система формирует CSV-файл с секциями `metadata`,
`objects`, `electrical`, `specifications` и инициирует загрузку:

```
                ┌───────────────────────────────────────────────────────────┐
                │ Загружается: T-2026-001_Усть-Луга-нефтебаза.tlt.csv      │
                │ Размер: 18.4 КБ                                          │
                │ [✓] Загрузка завершена                                  │
                └───────────────────────────────────────────────────────────┘
```

### Имя файла

Шаблон: `«‹номер задачи›_‹название›.tlt.csv»`. Если номер задачи
не задан — `«‹название›.tlt.csv»`. Кириллица — через RFC 5987,
файл с UTF-8 BOM (для совместимости с Excel в русской локали).

### Структура CSV (для понимания, схематично)

```
[SECTION];metadata
key;value
schema_version;1
project_name;Усть-Луга нефтебаза
task_number;T-2026-001
owner_email;ivanov@tlt.ru
created_at;2026-04-12T10:30:00
common_data;{"region":"Сургут","ambient_t":-44,"voltage":220,...}

[SECTION];objects
id;type;name;sort_order;params;results;is_valid
1;pipe;Труба-1;0;{"outer_diameter":0.108,...};{"heat_loss_per_meter":54.3,...};true
2;pipe;Труба-2;1;{"outer_diameter":0.159,...};{"heat_loss_per_meter":72.1,...};true

[SECTION];electrical
object_id;variant_number;cable_mark;results
1;1;ТЛТ-10;{"cable_length":55.0,"total_power":1650,"current":7.5}
2;1;ТЛТ-15;{"cable_length":176.0,"total_power":5280,"current":24.0}

[SECTION];specifications
items
[{"category":"Кабель","name":"ТЛТ-10",...}, ...]
```

## UC-E-06. Импорт CSV как нового проекта (без замены)

- **Роль:** Сотрудник. **US:** US-E-06.
- **FR:** FR-50. **VAL:** VAL-43, VAL-45, VAL-46, VAL-47.

### Точка входа

В проводнике проектов (SC-08) — кнопка «Загрузить из CSV».

### Шаги

**Шаг 1.** Сотрудник на SC-08 нажимает «Загрузить из CSV».

**Шаг 2.** Открывается диалог выбора файла:

```
                ╔═══════════════════════════════════════════════════════════╗
                ║          Загрузить проект из CSV                           ║
                ╠═══════════════════════════════════════════════════════════╣
                ║                                                           ║
                ║   В проводнике появится новый проект, владелец = Вы.      ║
                ║   Существующие проекты не изменятся.                      ║
                ║                                                           ║
                ║   ┌───────────────────────────────────────────────────┐   ║
                ║   │                                                   │   ║
                ║   │   Перетащите .tlt.csv-файл сюда или нажмите       │   ║
                ║   │   кнопку                                          │   ║
                ║   │                                                   │   ║
                ║   │              [ Выбрать файл ]                     │   ║
                ║   │                                                   │   ║
                ║   └───────────────────────────────────────────────────┘   ║
                ║                                                           ║
                ║                                          [ Закрыть ]      ║
                ╚═══════════════════════════════════════════════════════════╝
```

**Шаг 3.** Сотрудник выбирает файл — Система разбирает его и
сразу создаёт проект (без подтверждения замены — у Сотрудника
замены нет).

**Шаг 4.** В проводнике появляется новая запись с владельцем =
текущий Сотрудник. Существующие проекты не изменены.

```
   До импорта (в проводнике 11 проектов):
   ┌────┬─────────────────────────────────────┬────────────────┐
   │ #  │ Название                            │ № задачи       │
   ├────┼─────────────────────────────────────┼────────────────┤
   │ 1  │ Усть-Луга нефтебаза                  │ T-2026-001     │
   │ ...│ ...                                  │ ...            │
   │ 11 │ ...                                  │ ...            │
   └────┴─────────────────────────────────────┴────────────────┘
   
   После импорта (12-я запись добавлена):
   ┌────┬─────────────────────────────────────┬────────────────┐
   │ #  │ Название                            │ № задачи       │
   ├────┼─────────────────────────────────────┼────────────────┤
   │ 1  │ Усть-Луга нефтебаза                  │ T-2026-001     │
   │ ...│ ...                                  │ ...            │
   │ 11 │ ...                                  │ ...            │
   │ 12 │ Новороссийский порт                  │ T-2026-014     │ ← новый
   └────┴─────────────────────────────────────┴────────────────┘
```

### AF-1. Конфликт по номеру задачи (VAL-45)

Если у Сотрудника уже есть проект с таким же `task_number`,
название нового получает суффикс «(импорт)»:

```
   В проводнике появилось:
   ┌────┬─────────────────────────────────────┬────────────────┬──────────────┐
   │ #  │ Название                            │ № задачи       │ Владелец     │
   ├────┼─────────────────────────────────────┼────────────────┼──────────────┤
   │ 1  │ Усть-Луга нефтебаза                  │ T-2026-001     │ ivanov@      │
   │ ...│ ...                                  │ ...            │ ...          │
   │ 12 │ Усть-Луга нефтебаза (импорт)        │ T-2026-001     │ ivanov@      │ ← новый
   └────┴─────────────────────────────────────┴────────────────┴──────────────┘
```

### EF-1. Файл повреждён или неподдерживаемый формат

```
                ┌─────────────────────────────────────────────────────────┐
                │  ⚠  Не удалось загрузить файл                           │
                │                                                         │
                │  Причина: отсутствует обязательная секция [metadata].   │
                │                                                         │
                │  Существующие проекты в проводнике не изменены.         │
                │                                                         │
                │                              [   ОК    ]                │
                └─────────────────────────────────────────────────────────┘
```

## Сравнение поведения с импортом у Гостя

| Аспект                            | Гость (см. `guest/06-csv-flows.md`)   | Сотрудник (UC-E-06)              |
|-----------------------------------|---------------------------------------|-----------------------------------|
| Куда заходит для импорта          | Меню проекта на рабочем столе         | Кнопка в проводнике проектов SC-08|
| Действие с текущим проектом       | **Удаляется** (с заменой)             | Не изменяется                     |
| Подтверждение замены              | Обязательно                            | Не требуется                      |
| Что появляется в результате       | Один активный проект (загруженный)    | Новая запись в проводнике         |
| При конфликте номера задачи        | Не применимо                           | Суффикс «(импорт)»                 |
| Текущий проект при ошибке         | Сохраняется без изменений             | Не применимо (нет «текущего»)     |
