## SC-01. Главная страница (выбор режима)

### Назначение

Стартовый экран приложения. Сотрудник нажимает «Войти как
сотрудник» и переходит к форме авторизации (SC-02). Кнопка
«Войти без регистрации» относится к роли «Гость» и из этой роли
не используется (приведена для полноты).

Открывается со стартовой страницы по кнопке «Войти как сотрудник».
Получает учётные данные авторизованного пользователя.

| Поле           | Тип       | Обязательное | Валидация            | Подсказка                                              |

## UC-E-01. Авторизация Сотрудника

- **Роль:** Сотрудник.
- **US:** US-E-01.
- **FR:** FR-01, FR-03.
- **VAL:** VAL-01, VAL-02, VAL-03, VAL-04.

### Шаги сценария

**Шаг 1.** Сотрудник на SC-01 нажимает «Войти как сотрудник» —
открывается SC-02.

**Шаг 2.** Сотрудник заполняет логин и пароль, нажимает «Войти».

**Шаг 3 (успех).** Система создаёт авторизованную сессию и
открывает SC-08 — «Проводник проектов» (см. файл
`02-screen-projects-explorer.md`).

```
SC-01 ───► SC-02 ────► SC-08 «Проводник проектов»
                       ┌──────────────────────────────────┐
                       │ Сотрудник: ivanov@tlt.ru          │
                       │ Список проектов:                  │
                       │   1. Усть-Луга — нефтебаза        │
                       │   2. Новороссийский порт          │
                       │   3. ...                          │
                       └──────────────────────────────────┘
```

### Шаг 3 — альтернативные / исключительные потоки

**EF-1.** Неверный логин или пароль (VAL-03) — поле не
очищается, под кнопкой появляется красное сообщение:

```
┌────────────────────────────────────────────┐
│ Логин (e-mail):                            │
│ [ivanov@tlt.ru___________________________] │
│                                            │
│ Пароль:                                    │
│ [••••••__________________________________] │
│                                            │
│ ⚠ Неверный логин или пароль               │
│                                            │
│         [    Войти    ]    [ Отмена ]      │
└────────────────────────────────────────────┘
```

**EF-2.** Учётная запись отключена (VAL-04) — сообщение
«Учётная запись отключена, обратитесь к администратору».

### Шаг 4. Завершение работы

Сотрудник на любом этапе может нажать «Выйти» в шапке (см. SC-08
и SC-03 в других файлах) — сессия завершается, происходит возврат
на SC-01.

> **Важно.** В отличие от Гостя, авторизованная сессия Сотрудника
> **не удаляется автоматически** по неактивности. Управление
> длительностью сессии — через механизм продления токена
> авторизации.
