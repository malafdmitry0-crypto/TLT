# UI · Сотрудник · Рабочий стол — «Отчёт»

В файле собраны два сценария финального шага рабочего стола
Сотрудника — просмотр / печать отчёта (как у Гостя) и
дополнительный экспорт в файлы.

- **UC-G-18.** Предпросмотр и печать отчёта.
- **UC-E-09.** Экспорт отчёта в PDF / DOCX / XLSX (только Сотрудник).
- **UC-E-12.** Мастер выбора состава отчёта в отдельном окне.
- **UC-E-13.** Сводный отчёт по нескольким вариантам CO.

### Состав отчёта

Тот же, что и у Гостя — состав определяется документом
`07-report-requirements.md`.

| Раздел                                     | Содержимое                                                  |
|--------------------------------------------|-------------------------------------------------------------|
| 1. Титульная часть                          | Название отчёта, проект, номер задачи, владелец, дата      |
| 2. Общие первичные данные                  | Регион, температура, напряжение, запас, прокладка          |
| 3. Исходные данные по объектам             | Таблицы трубопроводов и резервуаров                          |
| 4. Результаты расчёта теплопотерь          | Линейные / удельные / суммарные значения                    |
| 5. Результаты электротехнического расчёта   | Марка, длина, мощность, ток + сводная часть                 |
| 6. Спецификация материалов                  | Группировка по категории, артикулы, количество             |
| 7. Справочная часть                          | (на согласование) коэффициенты, формулы, нормативы          |

> Подробный состав и точный перечень полей — в документе
> `07-report-requirements.md`. Подлежит согласованию с Заказчиком
> (Q-01 … Q-19).

## UC-G-18. Предпросмотр и печать отчёта

- **Роль:** Сотрудник. **US:** US-G-22, US-G-23.
- **FR:** FR-44, FR-45.

### Шаги

**Шаг 1.** Сотрудник на пошаговой навигации выбирает шаг 4
«Отчёт» — открывается SC-06.

**Шаг 2.** Видит HTML-предпросмотр отчёта.

**Шаг 3 (печать).** Нажимает кнопку `[ 🖨 Печать ]` — браузер
открывает стандартный диалог печати.

```
                ╔══════════════════════════════════════════════╗
                ║   Печать                       (диалог браузера)║
                ╠══════════════════════════════════════════════╣
                ║   Принтер: [ Microsoft Print to PDF ▼ ]      ║
                ║   Страницы: ( ) Все   (●) 1-3                ║
                ║   Ориентация: (●) Книжная   ( ) Альбомная    ║
                ║   ...                                        ║
                ║                       [ Печать ] [ Отмена ]  ║
                ╚══════════════════════════════════════════════╝
```

При печати элементы навигации, боковая панель и индикаторы сессии
**скрываются** (стиль `@media print`).

## UC-E-09. Экспорт отчёта в PDF / DOCX / XLSX

- **Роль:** только Сотрудник. **US:** US-E-09.
- **FR:** FR-46. **VAL:** VAL-56.

### Шаги

**Шаг 1.** Сотрудник на странице «Отчёт» видит дополнительные
кнопки `[ Экспорт PDF ]`, `[ Экспорт Word ]`, `[ Экспорт Excel ]`
рядом с `[ 🖨 Печать ]`.

**Шаг 2.** Нажимает любую из них.

**Шаг 3.** Браузер инициирует загрузку файла:

```
                ┌───────────────────────────────────────────────────────────┐
                │ Загружается: T-2026-001_Усть-Луга-нефтебаза.pdf         │
                │ Размер: 387 КБ                                           │
                │ [✓] Загрузка завершена                                  │
                └───────────────────────────────────────────────────────────┘
```

**Шаг 4.** Имя файла формируется по шаблону:
`«‹номер задачи›_‹название›.‹расширение›»`. Кириллица в имени —
по RFC 5987.

### MIME-типы и расширения

| Кнопка               | Расширение | MIME-тип                                                                  |
|----------------------|:----------:|---------------------------------------------------------------------------|
| Экспорт PDF          | .pdf       | application/pdf                                                            |
| Экспорт Word (DOCX)  | .docx      | application/vnd.openxmlformats-officedocument.wordprocessingml.document   |
| Экспорт Excel (XLSX) | .xlsx      | application/vnd.openxmlformats-officedocument.spreadsheetml.sheet         |

### Содержимое экспорта

Содержимое файла соответствует составу, утверждённому в документе
`07-report-requirements.md`. Текст и таблицы соответствуют
HTML-предпросмотру; форматирование адаптировано под выбранный
формат:

- **PDF** — статичный, неизменяемый, готовый к подписанию;
- **DOCX** — редактируемый, для добавления комментариев и подписей
  в Microsoft Word;
- **XLSX** — табличные разделы (объекты, спецификация) разделены
  по листам; удобно для отдела снабжения.

### EF-1. Гость пытается обратиться по прямой ссылке (VAL-56)

Если Гость по прямой ссылке вызывает endpoint экспорта, Система
возвращает сообщение «Экспорт в файлы доступен только Сотруднику»
(см. файл `guest/05-screen-workspace-report.md`).

## UC-E-12. Мастер выбора состава отчёта (отдельное окно SC-09)

- **FR:** FR-62. **VAL:** VAL-63, VAL-64.

### Кнопка-триггер

Рядом с кнопками экспорта на странице SC-06 виден дополнительный
элемент:

```
[ 🖨 Печать ] [ ⚙ Состав отчёта ] [ Экспорт PDF ] [ Word ] [ Excel ]
```

### Окно мастера (SC-09)

Открывается по клику на «⚙ Состав отчёта» — модальное окно с
формой:

```
                ╔═══════════════════════════════════════════════════════════╗
                ║              Состав отчёта                                 ║
                ╠═══════════════════════════════════════════════════════════╣
                ║                                                           ║
                ║   Включаемые разделы:                                     ║
                ║   [✓] Титульная часть                                     ║
                ║   [✓] Общие первичные данные                              ║
                ║   [✓] Исходные данные по объектам                         ║
                ║   [✓] Результаты расчёта теплопотерь                      ║
                ║   [✓] Результаты электротехнического расчёта              ║
                ║   [✓] Спецификация материалов                             ║
                ║   [ ] Справочная часть                                    ║
                ║                                                           ║
                ║   Вариант расчёта (CO):                                   ║
                ║   (●) Активный CO                                         ║
                ║   ( ) Все варианты сводно                                 ║
                ║   ( ) Конкретный CO  [ CO1 ▼ ]                            ║
                ║                                                           ║
                ║                              [ Применить ]   [ Отмена ]   ║
                ╚═══════════════════════════════════════════════════════════╝
```

### Шаги

1. Сотрудник нажимает «⚙ Состав отчёта» — открывается мастер.
2. Отмечает чекбоксами разделы, выбирает режим вариантов CO.
3. Нажимает «Применить» — настройка сохраняется в проекте.
4. Все последующие операции экспорта формируют файлы по этой
   настройке.

### Ограничения

- Должен быть выбран хотя бы один раздел (VAL-63).
- «Все варианты сводно» допустим при наличии у хотя бы одного
  объекта ≥ 2 вариантов CO (VAL-64).

## UC-E-13. Сводный отчёт по нескольким вариантам CO

- **FR:** FR-63. **VAL:** VAL-64.

В мастере (UC-E-12) выбирается «Все варианты сводно». Дальнейший
экспорт PDF / DOCX / XLSX содержит по каждому объекту все
рассчитанные варианты CO. Активный вариант помечен ★ или жирным
шрифтом.

> **На согласование:** оформление сводного отчёта (вариант A —
> сводная таблица сравнения; вариант B — отдельные подзаголовки
> «Вариант CO1»; вариант C — основной отчёт + приложение
> «Альтернативы») — Q-22 в документе 7.
