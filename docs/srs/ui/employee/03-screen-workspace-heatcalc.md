# UI · Сотрудник · Рабочий стол — «Теплопотери»

В файле собраны все сценарии расчётного контура, которые
Сотрудник отыгрывает на рабочем столе (страница «Теплопотери»,
SC-03). Расчётный контур у Сотрудника **тот же, что и у Гостя**
— те же модальные окна, тот же мастер объектов, та же таблица.
Отличается **контекст**: проект открыт из проводника, в шапке —
имя Сотрудника и кнопка «Все проекты», в боковой панели — иное
меню проекта (без замены, с редактированием свойств).

Сценарии в этом файле:

- **UC-E-04.** Редактирование свойств проекта.
- **UC-G-06.** Заполнение общих первичных данных.
- **UC-G-07.** Добавление трубопровода.
- **UC-G-08.** Добавление резервуара.
- **UC-G-09.** Редактирование объекта.
- **UC-G-10.** Удаление объекта.
- **UC-G-11.** Изменение порядка строк (drag-and-drop).
- **UC-G-12.** Импорт объектов из Excel / CSV.
- **UC-G-13.** Ручной ввод λ для материала «Другое».
- **UC-G-22.** Копирование строки.
- **UC-G-23.** Excel-подобная работа с таблицей.
- **UC-G-24.** Активные подсказки в формах.

> **Внимание.** Выбор типа и марки кабеля (UC-G-15, UC-G-25),
> создание вариантов расчёта CO1 … CO4 (UC-G-26), выбор активного
> варианта (UC-G-28), переключение базы расчёта (UC-E-10)
> выполняются на следующем шаге — **SC-04 «Электрорасчёт»** —
> и описаны в файле `04-screen-workspace-electrical.md`. На
> странице «Теплопотери» кабель и варианты CO **не задаются** —
> здесь рассчитываются только теплопотери объектов.

> Сценарии управления проектами (создание, удаление, копирование,
> импорт CSV без замены) у Сотрудника происходят **в проводнике
> проектов** — см. файл `02-screen-projects-explorer.md`.

### Отличия шапки и боковой панели от Гостя

| Зона      | У Гостя                                              | У Сотрудника                                             |
|-----------|------------------------------------------------------|----------------------------------------------------------|
| Шапка     | «ⓘ Гость 19′» (индикатор сессии), «Выйти»           | e-mail Сотрудника, кнопка «← Все проекты», «Выйти»       |
| Боковая   | Одна карточка проекта без указания владельца         | Карточка проекта с номером задачи и **именем владельца** |
| Меню       | «Создать новый» / «Загрузить CSV» / «Удалить»        | «Редактировать свойства» / «Создать на основании» / «Удалить» |

> Гостевые проекты подрядчиков не открываются Сотрудником без отдельного
> процесса передачи; прямой доступ к ним отклоняется backend-политикой.

### Меню проекта Сотрудника

| Пункт меню                       | Сценарий       | Где описан                           |
|----------------------------------|----------------|--------------------------------------|
| Редактировать свойства           | UC-E-04        | этот файл, ниже                      |
| Создать на основании              | UC-E-07        | `02-screen-projects-explorer.md`     |
| Экспорт CSV                       | UC-G-19        | `07-csv-flows.md`                    |
| Удалить проект                    | UC-E-05        | `02-screen-projects-explorer.md`     |

> **У Сотрудника НЕТ:** пункта «Создать новый проект» в меню
> рабочего стола — он находится в проводнике проектов (SC-08).
> Также нет пункта «Загрузить CSV (заменить)» — у Сотрудника
> импорт CSV происходит в проводнике и создаёт новый проект без
> замены.

### Приватность гостевых проектов (UC-E-08)

Если Сотрудник получает ссылку на гостевой проект подрядчика,
открытие рабочего стола должно завершиться отказом доступа. Такой
проект не должен попадать в список проводника, CSV-экспорт или
операции дублирования без отдельного процесса передачи в рабочий
контур.

Если ссылка ведёт на проект другого сотрудника, рабочий стол может
открыться для чтения; операции изменения остаются ограничены
владельцем проекта и администратором.

## UC-G-07 и UC-G-08. Добавление объекта (трубопровод / резервуар)

- **Роль:** Сотрудник. **US:** US-G-10, US-G-11.
- **FR:** FR-19 … FR-26. **VAL:** VAL-14 … VAL-29.

Полностью идентично сценарию у Гостя. Форма ввода / редактирования
объекта — **встроенная плоская форма**, постоянно видимая в верхней
части рабочего стола (это **часть основного интерфейса**, не
модальное окно). Все поля одновременно, без шагов / вкладок /
переходов «Далее». Клик по строке таблицы наполняет форму её
значениями; кнопка «+ Добавить» очищает форму под новую запись.
Подробный макет — в файле `guest/02-screen-workspace-heatcalc.md`,
разделы «Плоская форма трубопровода» и «Матрица появления и
скрытия полей встроенной формы». Для роли Сотрудник матрица
зависимых полей полностью совпадает с ролью Гость.

### Резервуар (UC-G-08)

Аналогично — та же встроенная плоская форма, колонка «Геометрия»
заменяется на «Форма и геометрия резервуара» с radio-выбором формы
(Цилиндр / Параллелепипед / Шар) и соответствующими габаритами.
Поля количества фланцев / опор / задвижек у резервуара
отсутствуют.

## UC-G-13. Ручной ввод λ для материала «Другое»

- **Роль:** Сотрудник. **US:** US-G-12.
- **FR:** FR-23. **VAL:** VAL-28, VAL-29.

В мастере объекта на шаге «Теплофизика»:

```
   Материал слоя 1: [ Другое ▼ ]                                  
   λ, Вт/(м·К):     [ 0.045 ]   ← поле появляется при «Другое»     
   ⓘ Диапазон 0,001…400 Вт/(м·К). Используется вместо табличного.
   Толщина:         [ 80 ] мм                                     
```

При нарушении диапазона — поле подсвечивается, кнопка «Далее»
неактивна.

пересчёт теплопотерь и электрорасчёта.

## UC-G-11. Изменение порядка строк (drag-and-drop)

**Статус реализации:** целевой UI-сценарий; в активном `HeatCalcPage` row
drag-and-drop сейчас не подключён. Backend reorder-контракт покрыт отдельно.

Иконка-«гамбургер» ⠿ слева в каждой строке — захват и
перетаскивание мышью. После 6 px движения начинается drag.

---

## UC-G-12. Импорт объектов из Excel / CSV

Кнопка `[ Импорт XLSX/CSV ▼ ]` имеет пункты: «Шаблон .xlsx»,
«Шаблон .csv», «Загрузить файл».

Диалог импорта — тот же, что у Гостя (см. `guest/02-...`). После
импорта — отчёт с количеством успешных строк и списком ошибок.

---

## UC-G-22. Копирование строки

Кнопка [Коп.] в строке создаёт копию объекта со всеми параметрами,
имя получает суффикс «(копия)».

---

## UC-G-23. Excel-подобная работа с таблицей

Чекбоксы выбора строк, копирование диапазона ячеек (Ctrl+C/V),
групповое удаление выделенных строк.

---

## UC-G-24. Активные подсказки в формах

Каждое поле ввода имеет активную подсказку «ⓘ» под полем (формат
итоговой подачи — см. вопрос Q-C документа 01).
