# UI · Сценарии для роли «Сотрудник»

## Применимость

В этой папке собраны UI-схемы и сценарии для роли **«Сотрудник»**
— авторизованный пользователь, работающий **по логину и паролю**.

### Особенности роли «Сотрудник»

- Сессия создаётся через форму входа с полями «Логин (e-mail)» и
  «Пароль».
- Стартовая страница после авторизации — **«Проводник проектов»**
  с поиском и фильтрами (по типу объектов, году создания, номеру
  задачи, владельцу).
- Сотрудник может вести **сколько угодно проектов одновременно**.
- В проводнике видны **все** проекты системы — свои и чужие.
- Может **создавать**, **редактировать свойства**, **удалять**,
  **копировать (создавать на основании)** свои проекты, а также
  **просматривать и редактировать** чужие.
- Импорт CSV создаёт **новый проект**, не заменяя существующие.
- Дополнительно может **экспортировать отчёт в файлы** PDF, DOCX, XLSX.
- Расчётный контур (общие первичные данные, ввод объектов, расчёт
  теплопотерь, электрорасчёт, спецификация, предпросмотр отчёта) —
  **тот же, что и у Гостя**, без отличий в формулах и интерфейсе
  расчёта.

## Что Сотрудник делает в проводнике, а что — в рабочем столе

| Операция                            | Где делает                                           |
|-------------------------------------|------------------------------------------------------|
| Создание нового проекта (без замены)| Проводник: кнопка «+ Новый проект» (UC-E-03)         |
| Импорт CSV как нового проекта        | Проводник: кнопка «Загрузить из CSV» (UC-E-06)       |
| Создание на основании другого        | Проводник: кнопка «Копия» в строке (UC-E-07)         |
| Удаление проекта                    | Проводник: кнопка «Удалить» в строке **или** меню проекта в рабочем столе (UC-E-05) |
| Открытие чужого проекта             | Проводник: клик по строке (UC-E-08)                  |
| Редактирование свойств проекта      | Рабочий стол: меню проекта → «Редактировать свойства» (UC-E-04) |
| Заполнение общих первичных данных   | Рабочий стол: блок «Общие первичные данные» (UC-G-06) |
| Ввод и редактирование объектов      | Рабочий стол, страница «Теплопотери» (UC-G-07..G-13, G-22) |
| Электрорасчёт                       | Рабочий стол, страница «Электрорасчёт» (UC-G-14, G-16) |
| Спецификация                        | Рабочий стол, страница «Спецификация» (UC-G-17)      |
| Экспорт отчёта в PDF / DOCX / XLSX  | Рабочий стол, страница «Отчёт» (UC-E-09)             |
