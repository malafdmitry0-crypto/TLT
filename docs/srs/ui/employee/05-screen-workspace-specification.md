# UI · Сотрудник · Рабочий стол — «Спецификация»

В файле собран сценарий третьего шага рабочего стола Сотрудника —
формирования и просмотра спецификации.

- **UC-G-17.** Формирование и просмотр спецификации.
- **UC-E-11.** Расширенная спецификация (группировка, сортировка, выбор позиций).

> У Сотрудника спецификация **расширенная**: группировка
> переключаемая (по категории / по объекту-варианту CO),
> сортировка по любой колонке, кнопка «Заменить на аналог»
> в каждой строке-позиции, кнопка «+ Добавить позицию» (выбор из
> активной базы расчёта — встроенная / расширенная внешняя).
> Банер сверху таблицы показывает текущую активную базу.

### Колонки таблицы спецификации

| Колонка          | Источник                                                       |
|------------------|----------------------------------------------------------------|
| #                | Порядковый номер                                                |
| Категория        | Кабель / Муфты / Управление / Защита / Индикация / Монтаж     |
| Наименование     | Из справочника аксессуаров (для кабелей — название марки)       |
| Артикул          | Уникальный код позиции из справочника                           |
| Ед. изм.         | м (для кабеля), шт (для всех остальных)                         |
| Количество       | Сумма по проекту                                                |

Сортировка: сначала по категории, затем по наименованию.

## UC-G-17. Формирование и просмотр спецификации

- **Роль:** Сотрудник. **US:** US-G-21.
- **FR:** FR-40 … FR-43.

### Шаги

**Шаг 1.** Сотрудник переходит на SC-05 (Шаг 3 пошаговой
навигации).

**Шаг 2.** Если спецификация ещё не формировалась, видна только
кнопка `[ Сформировать спецификацию ]`.

**Шаг 3.** Сотрудник нажимает кнопку. Система:
- группирует кабели по марке, суммируя длину;
- добавляет набор аксессуаров для активного варианта CO (муфты, термостаты,
  защитную автоматику, индикаторы, крепёж);
- сортирует позиции по категории и наименованию.

**Шаг 4.** Появляется таблица.

### AF-1. Повторное формирование

При повторном нажатии кнопки `[ Сформировать спецификацию ]`
открывается подтверждение:

```
                ╔═══════════════════════════════════════════════╗
                ║  Перегенерировать спецификацию?                ║
                ╠═══════════════════════════════════════════════╣
                ║                                                ║
                ║   Текущая спецификация будет полностью         ║
                ║   перезаписана с учётом актуальных результатов ║
                ║   электрорасчёта.                              ║
                ║                                                ║
                ║                  [ Перегенерировать ] [Отмена] ║
                ╚═══════════════════════════════════════════════╝
```

### AF-2. Нет валидных объектов

Если в проекте нет ни одного объекта с успешным электрорасчётом,
после нажатия кнопки появляется пустая спецификация с подсказкой
вернуться к теплопотерям.

## UC-E-11. Расширенный режим спецификации (только Сотрудник)

- **FR:** FR-61. **VAL:** —.

### Дополнительные элементы интерфейса

- **Банер активной базы:** «База: встроенная» / «База: расширенная
  внешняя» — отражает значение тогглера UC-E-10.
- **Переключатель режима группировки:** «по категории» / «по
  объекту / варианту CO».
- **Кнопки сортировки** в шапке каждой колонки таблицы.
- **Кнопка «Заменить на аналог»** в каждой строке-позиции —
  открывает список аналогов из активной базы; при выборе строка
  обновляется (источник = `external_db`).
- **Кнопка «+ Добавить позицию»** над таблицей — выбор из активной
  базы; источник = `external_db` или `manual`.
- **Колонка «Источник»** — `built_in` / `external_db` / `manual`.
- **Колонка «Привязка к CO»** — номер варианта расчёта или
  «общая» (для аксессуаров, не зависящих от варианта).

### Ограничения

- Гостю расширенный режим **не доступен** — только просмотр
  авто-спецификации.
- Если активная база — «встроенная», список аналогов может быть
  пустым / содержать только аналоги из встроенного каталога.
