# UI · Проводник проектов (только Сотрудник)

В файле собраны сценарии работы со страницей-проводником
проектов:

- **UC-E-02.** Открытие проводника с поиском и фильтром.
- **UC-E-03.** Создание нового проекта.
- **UC-E-04.** Редактирование свойств проекта.
- **UC-E-05.** Удаление проекта из проводника.
- **UC-E-06.** Импорт CSV как нового проекта.
- **UC-E-07.** Создание проекта на основании другого.
- **UC-E-08.** Приватность гостевых проектов.

> **Важно.** Этот экран существует **только** для роли Сотрудник.
> Гость работает с одним проектом без проводника (см.
> `03-screen-workspace-heatcalc.md`).

## SC-08. Проводник проектов

### Назначение

Стартовый экран Сотрудника после авторизации. Содержит таблицу
проектов зарегистрированных сотрудников с поиском и фильтрами.
Гостевые проекты подрядчиков в этот список не попадают.

### Элементы экрана

| Элемент                          | Тип            | Назначение                                                 |
|----------------------------------|----------------|------------------------------------------------------------|
| Поле поиска                       | TextInput     | Поиск по подстроке в названии и номере задачи              |
| Фильтр «Тип»                      | Select        | По типу объектов: трубопроводы / резервуары / оба          |
| Фильтр «Год»                      | Select        | По году создания                                           |
| Фильтр «Номер задачи»             | TextInput     | Точное совпадение или подстрока                            |
| Фильтр «Владелец»                 | Select        | По владельцу проекта (e-mail Сотрудника)                   |
| Кнопка «Новый проект»             | Button        | Открывает форму создания (UC-E-03)                         |
| Кнопка «Загрузить из CSV»         | Button        | Открывает диалог импорта (UC-E-06)                         |
| Сортировка по любой колонке       | TableHeader   | Клик на заголовке колонки                                  |
| Действия в строке                 | Buttons       | «Открыть», «Создать на основании (Копия)», «Экспорт CSV», «Удалить» |
| Пагинация                         | Pager         | При количестве проектов > N на странице                    |

### Колонки таблицы

| Колонка                    | Источник                  |
|----------------------------|---------------------------|
| Название                   | `project.name`            |
| Номер задачи               | `project.task_number`     |
| Владелец                   | ФИО / e-mail Сотрудника  |
| Создан                     | `project.created_at`      |
| Изменён                    | `project.updated_at`      |
| Объ. (количество объектов) | количество объектов       |
| Стат. (состояние)          | «Черновик» / «Завершён»   |
| Действия                   | кнопки                     |

## UC-E-02. Открытие проводника с поиском и фильтром

- **Роль:** Сотрудник. **US:** US-E-02. **FR:** FR-09, FR-10.

### Шаги

**Шаг 1.** Сотрудник входит (UC-E-01) — попадает на SC-08.

**Шаг 2.** Видит таблицу всех проектов системы.

**Шаг 3.** Применяет фильтры или вводит поиск:

```
┌──────────────────────────────────────────────────────────┐
│ 🔍 [ Усть_______________________________ ]              │
│                                                          │
│ Тип ▼ [Трубопроводы ▼]  Год ▼ [2026 ▼]  Владелец ▼ [✓ ivanov@] │
│                                                          │
│ В таблице остаётся 1 запись — проект «Усть-Луга...»      │
└──────────────────────────────────────────────────────────┘
```

**Шаг 4.** Клик по строке — открывается рабочий стол проекта
(см. `03-screen-workspace-heatcalc.md`).

## UC-E-03. Создание нового проекта

- **Роль:** Сотрудник. **US:** US-E-03. **FR:** FR-11.
- **VAL:** VAL-05, VAL-06, VAL-07.

### Шаги

**Шаг 1.** Сотрудник на SC-08 нажимает «Новый проект».

**Шаг 2.** Открывается модальное окно создания:

```
                ╔══════════════════════════════════════════════╗
                ║              Новый проект                     ║
                ╠══════════════════════════════════════════════╣
                ║                                              ║
                ║  Название (обязательное):                    ║
                ║  [____________________________________]      ║
                ║  ⓘ От 1 до 200 символов                     ║
                ║                                              ║
                ║  Номер задачи:                               ║
                ║  [____________________________________]      ║
                ║  ⓘ До 50 символов                           ║
                ║                                              ║
                ║  Описание:                                   ║
                ║  ┌──────────────────────────────────────┐    ║
                ║  │                                      │    ║
                ║  │                                      │    ║
                ║  └──────────────────────────────────────┘    ║
                ║  ⓘ До 2000 символов                         ║
                ║                                              ║
                ║                  [ Создать ]   [ Отмена ]    ║
                ╚══════════════════════════════════════════════╝
```

**Шаг 3.** Сотрудник заполняет «Название» (обязательное), при
необходимости — «Номер задачи» и «Описание». Жмёт «Создать».

**Шаг 4.** Система создаёт проект (статус «Черновик», владелец —
текущий Сотрудник), переходит на рабочий стол нового проекта.

**EF-1.** Пустое «Название» — кнопка «Создать» неактивна, под полем
inline-сообщение «Название обязательно».

## UC-E-05. Удаление проекта из проводника

- **Роль:** Сотрудник. **US:** US-E-05. **FR:** FR-11.

### Шаги

**Шаг 1.** В строке проекта Сотрудник нажимает кнопку «Удалить».

**Шаг 2.** Поверх таблицы появляется диалог подтверждения:

```
                ╔══════════════════════════════════════════════╗
                ║  ⚠  Удалить проект?                           ║
                ╠══════════════════════════════════════════════╣
                ║                                              ║
                ║   Проект «Усть-Луга нефтебаза» (T-2026-001)  ║
                ║   будет удалён БЕЗВОЗВРАТНО вместе с:         ║
                ║                                              ║
                ║     • 17 объектами (трубы и резервуары)      ║
                ║     • результатами расчётов                   ║
                ║     • спецификацией материалов                ║
                ║                                              ║
                ║   Это действие НЕЛЬЗЯ отменить.              ║
                ║                                              ║
                ║                  [ Удалить ]   [ Отмена ]    ║
                ╚══════════════════════════════════════════════╝
```

**Шаг 3.** После подтверждения проект и все его данные удаляются.
В отличие от Гостя, **автосоздание нового пустого проекта не
выполняется** — у Сотрудника может быть и ноль проектов.

## UC-E-06. Импорт CSV как нового проекта

- **Роль:** Сотрудник. **US:** US-E-06. **FR:** FR-50.
- **VAL:** VAL-43, VAL-45, VAL-46, VAL-47.

### Шаги

**Шаг 1.** Сотрудник на SC-08 нажимает «Загрузить из CSV».

**Шаг 2.** Открывается диалог выбора файла (см. подробнее
`07-csv-flows.md`).

**Шаг 3.** После успешной загрузки в проводнике появляется новая
запись с владельцем = текущий Сотрудник. Существующие проекты не
изменены.

**AF-1.** Конфликт по номеру задачи (VAL-45) — название нового
проекта получает суффикс «(импорт)».

**EF-1.** Файл повреждён — сообщение об ошибке, проводник не
изменяется.

## UC-E-07. Создание проекта на основании другого

- **Роль:** Сотрудник. **US:** US-E-07. **FR:** FR-12.

### Шаги

**Шаг 1.** В строке исходного проекта Сотрудник нажимает кнопку
«Копия» (операция «Создать на основании»).

**Шаг 2.** Система создаёт новый проект:
- Имя: «‹исходное› (копия)».
- Владелец: текущий Сотрудник (даже если исходный — чужой).
- Объекты: копируются `params` и порядок строк.
- Результаты расчётов: пересчитываются заново.

**Шаг 3.** Новый проект становится активным (Сотрудник попадает
на его рабочий стол).

```
        Исходный проект                   Проект-копия
        ┌────────────────────┐            ┌────────────────────────────┐
        │ Усть-Луга нефтебаза│  → копия → │ Усть-Луга нефтебаза (копия)│
        │ Владелец: petrov@  │            │ Владелец: ivanov@          │
        │ 17 объектов        │            │ 17 объектов (без расчёта)  │
        │ Расчёт выполнен    │            │ Запускается batch-пересчёт │
        └────────────────────┘            └────────────────────────────┘
```

## UC-E-08. Приватность гостевых проектов

- **Роль:** Сотрудник. **US:** US-E-08. **FR:** FR-13.
- **NFR:** NFR-UX-08 (явно показывать владельца проекта сотрудника).

### Шаги

**Шаг 1.** В системе есть проект другого сотрудника и проект гостевой
сессии подрядчика.

**Шаг 2.** Сотрудник открывает проводник проектов. Проект другого
сотрудника отображается, гостевой проект подрядчика не отображается.

**Шаг 3.** Если Сотрудник открывает `project_id` другого сотрудника,
backend возвращает проект для чтения.

**Шаг 4.** Если Сотрудник пытается открыть гостевой `project_id`
по прямому URL или экспортировать его CSV, backend возвращает `403`.
