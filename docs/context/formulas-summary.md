## Трубопровод — цилиндрическая многослойная стенка

```
Q = ΔT / (R_стенки + Σ R_изоляции_i + R_внеш) × (L + L_доп) × K    [Вт]

R_слоя = ln(d_внеш / d_внутр) / (2π × λ_слоя)   — цилиндрическое сопр., м·К/Вт на 1 м

Надземно:  R_внеш = 1 / (π × α_внеш × d_нар_из)
Подземно:  R_внеш = arccosh(H / r_нар_из) / (2π × λ_гр)

α_внеш = 11,6 + 7 × √v    [Вт/(м²·К)],  помещение: α = 9,0  (SNiP 41-03-2003)
```

Контракт передачи в электрический подбор: `heat_loss_per_meter` передается без
уже примененного `K`; электрическая формула применяет свой `safety_factor`
ровно один раз.

## Резервуар — плоская стенка

```
Q = ΔT / (δ_р/λ_р + δ_из/λ_из + 1/α_внеш) × S × K + Q_доп    [Вт]

S (цилиндр):       π × d × H + π × d²/2
S (параллелепипед): 2 × (L×W + L×H + W×H)
S (шар):           π × d²

α_внеш = 11,6 + 7 × √v    [Вт/(м²·К)],  помещение: α = 9,0  (SNiP 41-03-2003)
Q_доп  — дополнительные теплопотери (днище, штуцера и пр.), Вт; default = 0
```

## Саморегулирующийся кабель ТТН/ТТВ/ТТХ

```
q_б(T_ж) = Q1 × T_ж + Q2    [Вт/м]  — линейная зависимость от температуры жидкости

Алгоритм серии: ТТН (T_ж≤65°C, T_пр≤85°C) → ТТВ (120/210) → ТТХ (150/250)
  Эскалация если ни один кабель в серии не даёт q_б ≥ q_required.
Марка: {мощность}ТТН/ТТВ/ТТХ2-СР (агрессивная среда: СТ)
N_circuits = заданное количество ниток или ceil(q_required / q_б)
L_каб = L_баз × k_навива × N_circuits
P_общ = q_б × L_каб
```

Температурные пределы ТТН/ТТВ/ТТХ считаются включительными паспортными
максимумами.

## Навив и несколько ниток

```
Для трубы:
k_навива = 1, если шаг = 0
k_навива = √(1 + (π × D / шаг)²), если шаг > 0

Шаг навива задаётся в мм и должен быть больше наружного диаметра трубы.
Количество ниток: 1 / 2 / 3.
Длина кабеля и установленная мощность считаются с учётом k_навива и ниток.
```

ТНП-ограничение максимального коэффициента навива по диаметру трубы:

| Диаметр D, мм | Максимальный Kn |
|---:|---:|
| `D < 57` | 1,0 |
| `D = 57` | 1,1 |
| `57 < D <= 75` | 1,2 |
| `75 < D <= 89` | 1,3 |
| `89 < D <= 108` | 1,4 |
| `D > 108` | 1,5 |

## Резистивный одножильный ТТ Р1

```
N = (L + L_доп) × w          — длина кабеля, м
ρ_T = 0.0175 × (1 + 0.0042 × (T_ж − 20))   [Ом·мм²/м]

Линия 220В:  Sк = (Q/U²) × ρ_T × N
Петля 220В:  Sк = (Q/U²) × ρ_T × 2N
Звезда 380В: Sк = (Q/(U/√3)²) × ρ_T × 3N
```

Справочник ТТ Р1 сверяется с последними пользовательскими скринами:
`docs/tnp/internal-references/resistive-cable-r1.md`. Для ТТ Р1 зафиксированы
питание до `~600 В`, `50 Гц`, схемы линия/петля/звезда, формат заказа и
таблица сопротивлений/сечений/диаметров/длин секций.

## Резистивный трёхжильный ТТ Р3

```
Линия:         Sк = (Q/U²) × ρ_T × N / 3
Петля 2×3ж:    Sк = (Q/U²) × ρ_T × 2N / 3
Петля 1×3ж:    Sк = (Q/U²) × ρ_T × 3N
Звезда 3×3ж:   Sк = (Q/(U/√3)²) × ρ_T × 3N / 3
Звезда 1×3ж:   Sк = (Q/(U/√3)²) × ρ_T × 3N
```

Справочник ТТ Р3 сверяется с последними пользовательскими скринами:
`docs/tnp/internal-references/resistive-cable-r3.md`. Для ТТ Р3 зафиксированы
температуры, сечения жил, строительная длина `200 м`, маркировка и таблица
габаритов/массы/радиусов изгиба.

## Коэффициенты

Таблица `correction_coefficients` — все роли включая гостей:

| Ключ | По умолчанию | Влияние |
|---|---|---|
| `safety_factor` | 1,1 | Множитель K для Q (трубы **и** резервуары) |
| `wind_factor` | 1,0 | Множитель α_внеш для труб (устаревший, не используется) |

## Реализация

Все формулы — чистые Python-функции (без ORM/БД):
- `backend/app/formulas/heat_loss/pipe.py` — цилиндр
- `backend/app/formulas/heat_loss/tank.py` — плоская стенка
- `backend/app/formulas/electrical/self_regulating.py` — автоподбор ТЛТ и
  ТТН/ТТВ/ТТХ
- `backend/app/formulas/electrical/resistive.py` — расчёт ТТ Р1 и ТТ Р3

Коэффициенты передаются как параметр `coefficients: dict[str, float]` —
сервисный слой достаёт их из БД через `get_correction_coefficients()`.

## Валидация входных данных

Pydantic-схемы в `backend/app/schemas/calculation.py` с `Field()` валидаторами:
- `outer_diameter > 0`
- `insulation_thickness > 0`
- `process_temperature > ambient_temperature`
- Для резервуара: `diameter ≤ 3 м` (исторически; при необходимости расширяется)
