# Бизнес-инженерное описание расчёта обогрева ёмкости

## 1. Назначение и границы расчёта

Расчёт определяет тепловые потери ёмкости и параметры системы электрообогрева,
необходимой для их компенсации при заданных условиях эксплуатации.

Расчёт состоит из двух связанных частей:

1. теплотехнический расчёт ёмкости — определение удельных и полных теплопотерь;
2. электротехнический расчёт — подбор саморегулирующегося нагревательного
   кабеля по мощности, температурным ограничениям и геометрии укладки.

В рамках данного документа рассматривается только саморегулирующийся кабель:

- линейка ТЛТ;
- линейки ТТН, ТТВ и ТТХ.

Другие типы нагревательных кабелей в данном расчёте не рассматриваются.

## 2. Исходные данные

### 2.1. Геометрия ёмкости

Для цилиндрической ёмкости задаются:

- наружный диаметр `d`, м;
- полная высота `H`, м.

Для прямоугольной ёмкости задаются:

- длина `L`, м;
- ширина `B`, м;
- полная высота `H`, м.

Для сферической ёмкости задаётся диаметр `d`, м.

Для частично заглублённой ёмкости дополнительно задаётся высота подземной
части `h`, м. Она не должна превышать полную высоту ёмкости.

Теплотехнический расчёт поддерживает цилиндрическую, прямоугольную и
сферическую формы. Расчёт укладки кабеля поддерживает только цилиндрическую и
прямоугольную формы.

### 2.2. Температурные условия

- `Tж` — температура продукта, °C;
- `Tос` — расчётная температура окружающей среды, °C;
- `T3` — температура поддержания, °C, для кабелей ТТН/ТТВ/ТТХ;
- `T2` — температура пропарки, °C, если она применяется.

Расчётный температурный напор:

```text
ΔT = Tж − Tос                                                [°C]
```

Для выполнения расчёта должно соблюдаться условие:

```text
Tж > Tос
```

### 2.3. Стенка и теплоизоляция

- `δр` — толщина стенки ёмкости, м;
- `λр` — теплопроводность материала стенки, Вт/(м·К);
- `δиз,i` — толщина i-го слоя изоляции, м;
- `λиз,i` — теплопроводность i-го слоя изоляции, Вт/(м·К).

Поддерживается от одного до трёх слоёв теплоизоляции. Для справочного
материала `λиз` определяется системой. Для материала «Другое» пользователь
задаёт теплопроводность и допустимый температурный диапазон вручную.

### 2.4. Условия размещения

Ёмкость может располагаться:

- на открытом воздухе;
- в помещении;
- частично под землёй.

Для наружной установки используется скорость ветра `v`, м/с. Для подземной
части задаётся теплопроводность грунта `λгр`, Вт/(м·К).

### 2.5. Поправочные параметры

- `K` — коэффициент запаса теплопотерь; значение по умолчанию `1,1`;
- `Kразм` — коэффициент размещения;
- `Qдоп` — дополнительные теплопотери через днище, штуцеры, опоры и другие
  конструктивные элементы, Вт.

В текущей конфигурации приложения:

```text
Kразм = 0,9  для помещения
Kразм = 1,0  для наружной установки
```

Коэффициент `Kразм` является текущей политикой приложения. Отдельный первичный
источник ТНП для значений `0,9/1,0` пока не подтверждён.

## 3. Площадь поверхности ёмкости

### 3.1. Цилиндрическая ёмкость

Полная площадь включает боковую поверхность и два днища:

```text
S = π × d × H + 2 × π × (d / 2)²
  = π × d × H + π × d² / 2                              [м²]
```

### 3.2. Прямоугольная ёмкость

```text
S = 2 × (L × B + L × H + B × H)                         [м²]
```

### 3.3. Сферическая ёмкость

```text
S = 4 × π × (d / 2)²
  = π × d²                                               [м²]
```

## 4. Термические сопротивления

### 4.1. Сопротивление стенки

Если толщина и теплопроводность стенки заданы:

```text
Rст = δр / λр                                            [м²·К/Вт]
```

Если эти данные не заданы, используется `Rст = 0`. Это инженерное упрощение:
сопротивление металлической стенки обычно значительно меньше сопротивления
теплоизоляции.

### 4.2. Сопротивление теплоизоляции

Для одного слоя:

```text
Rиз = δиз / λиз                                          [м²·К/Вт]
```

Для нескольких слоёв:

```text
Rиз,Σ = Σ(δиз,i / λиз,i)                                 [м²·К/Вт]
```

Сопротивления слоёв складываются последовательно. Увеличение толщины изоляции
или применение материала с меньшей теплопроводностью уменьшает теплопотери.

Для справочных изоляционных материалов теплопроводность рассчитывается при
расчётной температуре материала. В текущей модели:

```text
tm = Tж / 2                 для наружного зимнего режима
tm = (Tж + 40) / 2          для помещения и других тёплых режимов
```

Конкретная функция `λиз(tm)` берётся из справочника выбранного материала.

### 4.3. Наружное сопротивление

Для ёмкости на открытом воздухе:

```text
αвнеш = 11,6 + 7 × √v                                      [Вт/(м²·К)]
Rвнеш = 1 / αвнеш                                          [м²·К/Вт]
```

При увеличении скорости ветра `αвнеш` растёт, `Rвнеш` уменьшается, а
теплопотери увеличиваются.

Для помещения по умолчанию:

```text
αвнеш = 9,0                                                 [Вт/(м²·К)]
Rвнеш = 1 / 9,0                                             [м²·К/Вт]
```

Если `αвнеш` задан вручную, система использует заданное значение вместо
автоматического расчёта.

## 5. Удельные теплопотери надземной поверхности

Полное сопротивление теплопередаче:

```text
RΣ = Rст + Rиз,Σ + Rвнеш                                  [м²·К/Вт]
```

Удельные теплопотери:

```text
q = ΔT / RΣ
  = (Tж − Tос) / (δр/λр + Σ(δиз,i/λиз,i) + 1/αвнеш)       [Вт/м²]
```

Значение `q` показывает, сколько тепла теряется с одного квадратного метра
поверхности. Коэффициенты `K` и `Kразм` в `q` не включаются.

## 6. Полные теплопотери надземной ёмкости

```text
Q = q × S × K × Kразм + Qдоп                              [Вт]
```

где:

- `Q` — полные расчётные теплопотери ёмкости, Вт;
- `q` — удельные теплопотери, Вт/м²;
- `S` — площадь поверхности, м²;
- `K` — коэффициент запаса;
- `Kразм` — коэффициент размещения;
- `Qдоп` — дополнительные теплопотери, Вт.

`Qдоп` прибавляется после применения `K` и `Kразм`; теплотехнические
коэффициенты повторно к нему не применяются.

## 7. Частично заглублённая ёмкость

Для заглублённой ёмкости надземная и подземная части рассчитываются отдельно.

### 7.1. Цилиндрическая форма

```text
Sвозд = π × d² / 4 + π × d × (H − h)                     [м²]
Sгр   = π × d² / 4 + π × d × h                           [м²]
```

### 7.2. Прямоугольная форма

```text
Sвозд = 2 × (L + B) × (H − h) + L × B                    [м²]
Sгр   = 2 × (L + B) × h + L × B                          [м²]
```

### 7.3. Сопротивление грунта

```text
Rгр = h / λгр                                             [м²·К/Вт]
```

### 7.4. Раздельные удельные теплопотери

```text
qвозд = ΔT / (Rст + Rиз,Σ + Rвнеш)                       [Вт/м²]
qгр   = ΔT / (Rст + Rиз,Σ + Rгр)                         [Вт/м²]
```

### 7.5. Полные теплопотери

```text
Q = (qвозд × Sвозд + qгр × Sгр) × K × Kразм + Qдоп       [Вт]
```

Средние удельные теплопотери всей поверхности:

```text
qср = (qвозд × Sвозд + qгр × Sгр) / (Sвозд + Sгр)        [Вт/м²]
```

Подземный расчёт предусмотрен только для цилиндрической и прямоугольной форм.

## 8. Переход от теплопотерь к саморегулирующемуся кабелю

Паспортная мощность саморегулирующегося кабеля задаётся в Вт/м. Поэтому полные
теплопотери ёмкости в ваттах необходимо привести к требуемой мощности на метр
фактической трассы укладки.

### 8.1. Периметр укладки

Для цилиндрической ёмкости:

```text
P = π × d                                                  [м]
```

Для прямоугольной ёмкости:

```text
P = 2 × (L + B)                                            [м]
```

### 8.2. Базовая длина укладки

```text
Lбаз = (P / 2) × (Hобогр / w)                              [м]
```

где:

- `Hобогр` — высота зоны обогрева, м;
- `w` — шаг укладки кабеля, м;
- `P` — периметр ёмкости, м.

В текущей реализации шаг укладки должен находиться в диапазоне `0,1…0,4 м`.

Сферическая форма не имеет утверждённой формулы укладки. Для неё допускается
теплотехнический расчёт, но автоматический электротехнический подбор должен
завершаться диагностируемой ошибкой, а не использовать геометрию трубы.

### 8.3. Исключение двойного коэффициента запаса

Полные теплопотери `Q` уже содержат коэффициент `K`. Электрическая формула
саморегулирующегося кабеля также применяет `K`. Поэтому сначала определяется
мощность без ранее применённого запаса:

```text
QбезK = Q / K                                               [Вт]
```

Затем требуемая мощность на метр базовой укладки:

```text
qтреб,баз = QбезK / Lбаз                                    [Вт/м]
```

В электротехническом алгоритме коэффициент применяется ровно один раз:

```text
qтреб = qтреб,баз × K                                       [Вт/м]
```

Такой порядок не допускает двойного завышения мощности кабеля.

## 9. Подбор саморегулирующегося кабеля ТЛТ

### 9.1. Условия пригодности

Кабель считается подходящим, если одновременно выполняются условия:

```text
qкаб × kукл × N ≥ qтреб
Tmin,каб ≤ Tос
Tmax,каб ≥ Tж
```

где:

- `qкаб` — паспортная линейная мощность кабеля, Вт/м;
- `kукл` — коэффициент укладки;
- `N` — количество параллельных ниток;
- `Tmin,каб` — минимальная допустимая температура кабеля, °C;
- `Tmax,каб` — максимальная допустимая температура кабеля, °C.

### 9.2. Автоматический подбор

Если марка не задана, система рассматривает кабели справочника ТЛТ и
количество ниток `N = 1…3`. Технически подходящие варианты ранжируются в
следующем порядке:

1. меньшее количество ниток;
2. меньшая паспортная мощность, Вт/м;
3. меньшая установленная мощность.

Если количество ниток задано пользователем, система проверяет только это
значение и не увеличивает его автоматически.

### 9.3. Ручной выбор

При ручном выборе система не заменяет марку автоматически. Выбранный кабель
проверяется по мощности и температурным пределам. Если количество ниток не
задано, принимается одна нитка.

### 9.4. Результаты для ТЛТ

```text
kкомп = kукл × N
Lуст  = Lбаз × kкомп                                      [м]
Lзак  = Lуст × 1,1                                        [м]
Pобщ  = qкаб × Lуст                                       [Вт]
I     = Pобщ / Uкаб                                       [А]
```

где:

- `Lуст` — установленная длина кабеля;
- `Lзак` — заказная длина с монтажным запасом 10%;
- `Pобщ` — установленная электрическая мощность;
- `Uкаб` — паспортное напряжение выбранного кабеля;
- `I` — расчётный ток.

Монтажный запас 10% влияет на заказную длину, но не увеличивает расчётную
установленную мощность.

## 10. Подбор саморегулирующегося кабеля ТТН/ТТВ/ТТХ

Для этих линеек фактическая линейная мощность зависит от температуры
поддержания `T3`:

```text
qб(T3) = Q1 × T3 + Q2                                     [Вт/м]
```

Коэффициенты `Q1` и `Q2` берутся из паспортной строки кабеля.

Серия выбирается по температуре продукта `T1 = Tж` и температуре пропарки
`T2`:

```text
ТТН: T1 ≤ 65 °C,  T2 ≤ 85 °C
ТТВ: T1 ≤ 120 °C, T2 ≤ 210 °C
ТТХ: T1 ≤ 150 °C, T2 ≤ 250 °C
```

Границы считаются включительными. Система выбирает минимально подходящую по
температурам серию. Повышение серии только для уменьшения числа ниток не
выполняется.

Если одной нитки недостаточно:

```text
N = ceil(qтреб / (qб(T3) × kукл))
```

Для ТТН/ТТВ/ТТХ искусственное ограничение `N ≤ 3` не применяется.

Итоговые параметры:

```text
Lуст = Lбаз × kукл × N                                    [м]
Lзак = Lуст × 1,1                                         [м]
Pобщ = qб(T3) × Lуст                                      [Вт]
I    = Pобщ / Uкаб                                        [А]
```

Для агрессивной среды выбирается исполнение с суффиксом `-СР`, для
неагрессивной — `-СТ`.

## 11. Инженерный пример

Исходные данные:

- цилиндрическая ёмкость;
- `d = 2 м`;
- `H = 3 м`;
- `Tж = 80 °C`;
- `Tос = −20 °C`;
- `δиз = 0,08 м`;
- `λиз = 0,0534 Вт/(м·К)`;
- сопротивление стенки не учитывается;
- `v = 0 м/с`;
- `K = 1,1`;
- `Kразм = 1,0`;
- `Qдоп = 0`.

Площадь:

```text
S = π × 2 × 3 + π × 2² / 2
S ≈ 25,13 м²
```

Наружное сопротивление:

```text
αвнеш = 11,6 + 7 × √0 = 11,6 Вт/(м²·К)
Rвнеш = 1 / 11,6 ≈ 0,0862 м²·К/Вт
```

Сопротивление изоляции:

```text
Rиз = 0,08 / 0,0534 ≈ 1,498 м²·К/Вт
```

Удельные теплопотери:

```text
q = (80 − (−20)) / (1,498 + 0,0862)
q ≈ 63,1 Вт/м²
```

Полные теплопотери:

```text
Q = 63,1 × 25,13 × 1,1 × 1,0
Q ≈ 1744 Вт ≈ 1,74 кВт
```

Для примера укладки примем:

- `Hобогр = 3 м`;
- `w = 0,2 м`.

Тогда:

```text
P = π × 2 ≈ 6,283 м
Lбаз = (6,283 / 2) × (3 / 0,2) ≈ 47,12 м
qтреб,баз = (1744 / 1,1) / 47,12 ≈ 33,65 Вт/м
qтреб = 33,65 × 1,1 ≈ 37,02 Вт/м
```

Следовательно, выбранная комбинация марки, коэффициента укладки и количества
ниток должна обеспечивать не менее `37,02 Вт/м` и одновременно удовлетворять
температурным ограничениям продукта и окружающей среды.

## 12. Результаты, формируемые системой

Теплотехническая часть возвращает:

- площадь поверхности, м²;
- удельные теплопотери, Вт/м²;
- полные теплопотери, Вт;
- сопротивление стенки;
- суммарное сопротивление изоляции;
- наружное сопротивление;
- сопротивление грунта для подземной части;
- площади и удельные потери надземной и подземной частей;
- применённые коэффициенты;
- дополнительные теплопотери.

Электротехническая часть возвращает:

- выбранную марку саморегулирующегося кабеля;
- паспортную и установленную линейную мощность;
- количество ниток;
- установленную длину;
- заказную длину с монтажным запасом;
- общую электрическую мощность;
- напряжение и расчётный ток;
- источник выбора количества ниток и причину выбора кабеля;
- диагностическое сообщение, если подходящий кабель не найден.

## 13. Проверяемые инженерные инварианты

Корректный расчёт должен сохранять следующие зависимости:

- увеличение толщины изоляции уменьшает `q` и `Q`;
- увеличение разности температур увеличивает `q` и `Q`;
- увеличение площади при одинаковом `q` увеличивает `Q`;
- увеличение скорости ветра для наружной установки увеличивает теплопотери;
- увеличение `K` пропорционально увеличивает `Q`;
- `Qдоп` увеличивает только полные теплопотери и не изменяет `q`;
- коэффициент запаса не должен применяться дважды при переходе к подбору
  кабеля;
- выбранный кабель должен покрывать требуемую мощность и выдерживать
  температуры эксплуатации;
- заказная длина должна быть не меньше установленной длины.
