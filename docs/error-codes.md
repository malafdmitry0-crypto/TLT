# Справочник кодов ошибок (черновик)

**Статус:** Open — полный каталог ожидает согласования (см.
[docs/analysis/open-business-decisions.md](analysis/open-business-decisions.md) § DOC-ERR).

До утверждения единого реестра коды и HTTP-ответы описаны точечно в
[docs/api.md](api.md). При добавлении нового `error_code` в API обновлять
оба файла.

## Формат записи (целевой)

| Код | HTTP | Причина | Действие пользователя |
|---|---:|---|---|
| _пример_ | 422 | Некорректные параметры объекта | Исправить поля, отмеченные в форме |

## Импорт объектов

Ошибки импорта XLSX/CSV возвращаются в теле `{ created, errors: [{ sheet, row, message }] }`.
Построчные сообщения — человекочитаемые; машинный `error_code` для импорта
планируется в отдельной итерации.

## Расчёт

При ошибке электрорасчёта в БД сохраняется `results.error` (строка).
Коды категорий расчёта — в `docs/business-logic-contract.md` и тестах
`calculation_service`.
