# Архив frontend-документации

Здесь находятся завершённые планы, исторические snapshots и специализированные
промпты прошлых этапов. Они сохранены как evidence, но:

- не задают текущий `pending`;
- не являются источником актуальных LOC или baseline;
- не могут ослаблять [действующий стандарт](../agent-development-standard.md);
- не маршрутизируют работу агента.

Актуальная очередь: [refactor-backlog.md](../refactor-backlog.md).
