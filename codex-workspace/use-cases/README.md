# Юзер-кейсы TLT: что есть и что нужно реализовать

Сводный реестр пользовательских сценариев программного комплекса
теплотехнического и электротехнического расчёта. Источники: ТЗ
(`ТНП/Приложение_1...pdf`), ТНП-первоисточники (`ТНП/`), SRS
(`docs/srs/02-use-cases.md`), действующий код и
[`../tnp-source-analysis.md`](../tnp-source-analysis.md).
Дата сверки: 2026-06-08.

## Состав папки

| [`uc-implemented.md`](uc-implemented.md) | Реализованные сценарии (есть в продукте), сгруппированы по модулям, с привязкой к коду. |
| [`uc-to-implement.md`](uc-to-implement.md) | Сценарии к реализации/доработке: пробелы из ТЗ и ТНП со статусом и приоритетом. |

## Условные обозначения статуса

Статусы по правилу полной версии (`docs/context/full-version-rule.md`):

- ✅ **Реализовано** — сценарий работает в продукте.
- 🟡 **Needs implementation** — функционал отсутствует или закрыт частично.
- 🟠 **Needs correction** — реализовано, но расходится с контрактом/источником.
- 🔵 **Needs business decision** — требуется подтверждение спорного правила/данных.

## Роли (по матрице доступа ТЗ)

- **Пользователь (Гость)** — вход без регистрации, один авто-проект.
- **Сотрудник** — JWT, проводник проектов, внешняя БД, экспорт отчётов.
- **Администратор** — пользователи, коэффициенты, внешняя БД, ключи шифрования.
