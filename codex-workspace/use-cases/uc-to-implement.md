## UC-TODO-01 · Полная условная спецификация аксессуаров ✅ (формульная часть)

**Статус 2026-06-08:** реализовано — `formulas/specification/full_builder.py` +
`reference_data/spec_accessories.json`, режим `mode="full"` (Сотрудник), UI-
переключатель «Базовая/Полная» + опции Ex/резерв на странице спецификации.
Покрыто unit+integration тестами. Остаётся вне scope: «хвост» ТНП-листа без
формул (КИП, шкаф управления, монтажные кабели/лотки/трубы, ЗИП) — проектные
ручные позиции; их можно добавлять через расширенную БД (US-E-11).

**Актёр:** Сотрудник (и Гость на базовом наборе).
**Источник:** `ТНП/Расчет_спецификации_трубы_самрег29_05_26.xlsx`, ТЗ 4.3.3.
**Реализованный BOM из ТНП-алгоритма:**
- кабельные позиции `L = Σ(L,секц × N,секц × R,гр)` с резервом `R,гр` и
  температурным классом `T,секц`;
- комплекты КСН-1/2, КСВ-1/2 по серии и наличию концевых коробок;
- ремкомплекты КСР: `округл.вверх(ΣL/150)`;
- коробки СКВ 1201/1202/1601/1602 (+ -С/-С1) по условиям `dтр ≷ 57 мм`,
  `N,секц ≷ 3`, индикаторам `К1i/К2i/Кiu`, зоне `Ex`;
- хомуты ХК30, ленты ЛКС/ЛКВ (`(π·dтр·2.5/1000)·(L/0.3)·1.1`), вводы,
  герметики, этикетки, заземление, Z-профиль.
**Приоритет:** высокий (ядро full-version спецификации).
