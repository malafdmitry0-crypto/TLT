# Электротехнический расчёт: объяснение для инженера

Этот документ объясняет простым языком, как программа подбирает греющий кабель.
Он описывает текущую реализацию TLT, а не нормативный документ и не ТЗ.

## Главная Идея

Сначала программа считает, сколько тепла теряет объект (труба или резервуар).
Затем подбирает греющий кабель, который компенсирует эти потери:

```text
теплопотери объекта -> требуемая мощность обогрева -> подходящий кабель
```

Кабель должен одновременно:

- выдавать достаточную мощность;
- работать при температуре окружающей среды (монтаж/эксплуатация на холоде);
- не перегреваться при температуре продукта;
- укладываться на объект по длине с учётом навива и числа ниток.

## Какие Кабели Умеет Считать Программа

| Тип | Линейка | Как считается мощность |
|---|---|---|
| Саморегулирующийся | ТЛТ | по паспортной мощности кабеля, Вт/м |
| Саморегулирующийся | ТТН/ТТВ/ТТХ | мощность зависит от температуры поддержания: `q = q1·T3 + q2` |
| Резистивный одножильный | ТТ Р1 | по сопротивлению жилы и схеме подключения |
| Резистивный трёхжильный | ТТ Р3 | по сопротивлению трёх жил и схеме подключения |

Минеральная изоляция (MI) и скин-системы пока не считаются — это типы без формулы.

## Откуда Берётся Требуемая Мощность

Программа использует уже посчитанные теплопотери объекта. Здесь есть одно
важное правило: **коэффициент запаса применяется только один раз** за весь
расчёт.

- Для трубы с ТЛТ или ТТН/ТТВ/ТТХ на вход идёт удельная мощность **без** запаса
  (запас добавит сама электрическая формула).
- Для резервуара программа делит полные теплопотери на длину укладки кабеля по
  поверхности бака.
- Для резистивных кабелей целью служат полные ватты теплопотерь (запас в них
  уже учтён теплорасчётом).

Поэтому итоговая мощность кабеля не оказывается завышенной из-за двойного запаса.

## Как Идёт Подбор

### Автоматический подбор

Если марка кабеля не задана, программа перебирает каталог и берёт минимально
достаточный вариант, который проходит все проверки:

```text
мощность кабеля × коэффициент навива × число ниток ≥ требуемая мощность
температура среды не ниже минимальной для кабеля
температура продукта не выше максимальной для кабеля
```

- Для ТЛТ количество ниток автоподбор пробует от 1 до 3.
- Для ТТН/ТТВ/ТТХ сначала выбирается серия по температурам продукта и пропарки,
  потом номинал; если одной нитки мало — добавляются нитки без искусственного
  ограничения «не больше трёх».
- Для резистивных кабелей программа перебирает схемы подключения (линия, петля,
  звезда), напряжение и число параллельных контуров, пока не найдёт схему,
  которая укладывается в ограничение по току (≤ 65 А) и линейной мощности.

### Ручной выбор

Если инженер задал марку (или схему для резистивного), программа не ищет другую.
Она только проверяет, что выбранный вариант проходит по мощности и температурам,
и считает результат. Если не проходит — выдаёт понятную ошибку с причиной.

## Навив И Несколько Ниток

Если кабель укладывается с навивом (спиралью) или в несколько ниток, его длина и
суммарная мощность растут:

```text
коэффициент навива = √(1 + (π × D / шаг)²)   — если задан шаг навива
длина кабеля = длина обогрева × коэффициент навива × число ниток
```

Для трубы есть ограничение максимального навива по диаметру (чем тоньше труба,
тем меньше можно навить). Превышение лимита программа не пропускает.

## Длина И Ток

```text
длина для заказа = расчётная длина × 1.1   (монтажный запас 10%)
полная мощность  = мощность кабеля × расчётная длина
ток              = полная мощность / напряжение кабеля
```

Напряжение берётся из паспорта строки каталога. Заданное в объекте напряжение
питания используется только как запасной вариант.

## Коммерческий Выбор

Если технически подходящих кабелей несколько, программа может выбрать по
коммерческому критерию: минимальная цена, быстрая поставка, наличие на складе,
предпочтительный поставщик. По умолчанию выбирается технически минимальный
вариант. Если коммерческих данных не хватает, программа честно откатывается на
технический выбор и пишет предупреждение — расчёт при этом не падает.

## Что Сильнее Всего Влияет На Результат

| Параметр | Как влияет |
|---|---|
| Теплопотери объекта | Чем больше потери, тем мощнее нужен кабель. |
| Температура продукта | Ограничивает допустимые марки/серии. |
| Температура среды | Кабель должен работать на холоде. |
| Навив и число ниток | Увеличивают суммарную мощность и длину кабеля. |
| Схема подключения (резистивные) | Меняет мощность, ток и требуемое сопротивление. |
| Напряжение | Влияет на ток и на резистивный подбор. |

## Практические Замечания

- Запас прочности учитывается ровно один раз — не нужно закладывать его повторно.
- Для трубы длина обогрева уже включает локальные элементы (фланцы, опоры).
- Для резервуара обязательно задать геометрию укладки: форму, высоту обогрева и
  шаг укладки — иначе кабель посчитать нельзя.
- Если для объекта кабель не подобрался, причина сохраняется и видна на экране
  после перезагрузки.
- Минеральная изоляция и скин-системы пока выдают сообщение «формула не
  реализована».
