# Электрорасчёт: как читать входы и результат

Этот документ для инженера, который задаёт параметры подбора кабеля и проверяет
результат. Он описывает текущую реализацию TLT.

## Что Нужно До Электрорасчёта

Сначала у объекта должны быть посчитаны теплопотери. Без валидного теплорасчёта
кабель подобрать нельзя — программа выдаст ошибку «теплопотери не рассчитаны».

## Минимальный Ввод

Большинство значений программа берёт из объекта и теплорасчёта автоматически.
Инженер обычно задаёт или уточняет:

```text
тип кабеля (ТЛТ, ТТН/ТТВ/ТТХ, ТТ Р1, ТТ Р3)
марку кабеля        — или оставить пустой для автоподбора
число ниток         — или оставить пустым (для ТЛТ/ТТ — автоподбор)
шаг навива          — если кабель кладётся спиралью
напряжение питания  — если отличается от 220 В
```

Для **резервуара** дополнительно обязательны параметры укладки:

```text
форма (цилиндр / параллелепипед)
высота зоны обогрева
шаг укладки (0.1–0.4 м)
```

Для **резистивных** кабелей можно задать:

```text
схему подключения (линия / петля / звезда)
режим: ручной или автоматический (full-version подбор схемы)
температуру продукта (обязательна — для сопротивления)
```

## Как Читать Результат

### Главные поля (есть у всех типов)

| Поле | Как читать |
|---|---|
| `selected_cable` / `cable_mark` | Какой кабель подобрался. |
| `total_power` | Полная мощность обогрева, Вт. |
| `current` | Ток, А. Для резистивных не должен превышать лимит (65 А). |
| `voltage` | Напряжение, по которому считался ток. |
| `cable_length` | Расчётная длина кабеля, м. |
| `order_cable_length` | Длина для заказа (с запасом 10%), м. |
| `num_circuits` | Сколько ниток/контуров применено. |

### Поля количества ниток (ТЛТ)

| Поле | Как читать |
|---|---|
| `requested_number_of_threads` | Что задал пользователь (или пусто). |
| `applied_number_of_threads` | Сколько ниток применил расчёт. |
| `number_of_threads_source` | `auto` — подобрал сам, `manual` — задал пользователь, `default` — взял 1 по умолчанию. |

### Поля мощности

| Поле | Как читать |
|---|---|
| `power_per_meter` | Паспортная мощность одной нитки, Вт/м. |
| `installed_power_per_meter` | Фактическая мощность с навивом и нитками. |

### Поля резистивного подбора (ТТ Р1 / ТТ Р3)

| Поле | Как читать |
|---|---|
| `connection_type` | Выбранная схема подключения. |
| `conductor_cross_section` | Сечение жилы выбранного кабеля. |
| `resistance_ohm_km` | Паспортное сопротивление кабеля. |
| `p2_w_m` / `p3_w_m` | Фактическая и предельная линейная мощность; должно быть `p2 ≤ p3`. |
| `scheme_count` / `scheme_threads` | Число параллельных контуров (M) и ниток в схеме (N). |
| `power_margin_w` | Запас мощности над требуемым, Вт. |

### Поля выбора

| Поле | Как читать |
|---|---|
| `selection_policy` | Какой критерий запрашивался. |
| `applied_selection_policy` | Что реально применилось (может откатиться на технический). |
| `selection_reason` | Объяснение, почему выбран этот кабель. |
| `commercial` | Цена, поставщик, срок, наличие (если есть данные). |
| `warnings` | Предупреждения, например о неполноте коммерческих данных. |

## Быстрые Проверки Результата

1. `total_power` должна быть не меньше требуемой мощности обогрева.
2. Для резистивных: `current` ≤ 65 А и `p2_w_m` ≤ `p3_w_m`.
3. `order_cable_length` всегда больше `cable_length` (на запас 10%).
4. Если подбирали автоматически, проверьте `applied_number_of_threads` —
   возможно, понадобилось несколько ниток.
5. Если задавали марку вручную, в `selection_reason` будет «выбран вручную».

## Частые Ошибки

- Запустили электрорасчёт до теплорасчёта объекта.
- Для резервуара не задали геометрию укладки (форму, высоту, шаг).
- Для резистивного кабеля не задали температуру продукта.
- Задали шаг навива меньше или равный диаметру трубы.
- Превысили максимальный навив для тонкой трубы.
- Ждут результат для минеральной изоляции или скин-системы — они пока не
  считаются.
