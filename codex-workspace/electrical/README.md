Описание фактической реализации подбора греющего кабеля в TLT. Источник
истины — backend-код, а не ТЗ. Дата сверки с кодом: **2026-06-08**.

| `cable_type` | Линейка | Статус |
|---|---|---|
| `self_regulating` | ТЛТ | расчётный |
| `self_regulating_tt` | ТТН/ТТВ/ТТХ | расчётный |
| `single_core` | ТТ Р1 (одножильный) | расчётный |

## Ключевые инварианты (подтверждены кодом)

- `safety_factor` применяется **ровно один раз**. ТЛТ/ТТ: формула домножает
  `required_power_per_meter` (вход без K). Резистивные: целью служит
  `required_heat_loss = total_heat_loss` (K уже внутри).
- Резервуар: `Q/K`, затем деление на длину укладки по периметру
  (`compute_tank_cable_length`).
- Труба: база — `effective_length` (локальные элементы уже учтены).
- Монтажный запас длины: `order_cable_length = installed × 1.1`.
- Навив трубы ограничен cap по диаметру (`<57→1.0 … >108→1.5`).
- Ток/напряжение — по паспорту строки каталога; `supply_voltage` — fallback.
- Резистивный auto: критерий `p2 ≤ p3` и `I ≤ 65 A`; перебор `U/N/M`.
