# Пользовательские истории TLT (подробные)

Детальные user stories программного комплекса теплотехнического и
электротехнического расчёта систем электрообогрева. Формат: история +
приоритет (MoSCoW) + критерии приёмки + статус реализации + связь с
юзер-кейсом (UC) и кодом.

Источники: ТЗ (`ТНП/Приложение_1...pdf`), SRS (`docs/srs/01-user-stories.md`),
действующий код, [`../use-cases/`](../use-cases/README.md),
[`../tnp-source-analysis.md`](../tnp-source-analysis.md). Дата сверки: 2026-06-08.

## Соглашения

- **Формат:** «Как ‹роль›, я хочу ‹действие›, чтобы ‹ценность›».
- **Приоритет:** Must / Should / Could (MoSCoW).
- **ID:** `US-G-NN` (Гость/общие), `US-E-NN` (Сотрудник), `US-A-NN` (Админ),
  `US-TODO-NN` (бэклог полной версии).
- **Статус:** ✅ реализовано · 🟡 needs implementation · 🟠 needs correction ·
  🔵 needs business decision.

## Роли (матрица доступа ТЗ)

- **Пользователь (Гость)** — вход без регистрации, один авто-проект, расчёт,
  предпросмотр/печать отчёта.
- **Сотрудник** — JWT, проводник проектов, внешняя БД, экспорт отчётов в файлы.
- **Администратор** — пользователи, коэффициенты, внешняя БД, ключи шифрования.
