# Спецификация: объяснение для инженера

Этот документ объясняет простым языком, как программа собирает спецификацию.
Он описывает текущую реализацию TLT (базовый режим).

## Что Такое Спецификация

После того как для объектов проекта подобран греющий кабель, программа
формирует список того, что нужно заказать:

```text
греющий кабель (по маркам, с суммарной длиной)
+ базовые аксессуары (муфты, термостаты, УЗО и т.п.)
```

## Кабельные Позиции

В спецификацию попадает кабель только по **успешно рассчитанным** объектам —
там, где есть выбранная марка и нет ошибки расчёта.

- Длины кабеля одной и той же марки складываются в одну строку.
- Берётся длина **для заказа** — то есть с монтажным запасом (плюс кратность
  поставки и минимальный заказ, если они заданы в каталоге), а не «чистая»
  расчётная длина.
- В строке сохраняются марка, артикул, поставщик и цена за метр (если есть).

## Аксессуары

Аксессуары заказываются **на каждый заявленный объект проекта**, а не только на
успешно рассчитанные. Это сделано специально: если для какого-то объекта кабель
будет подобран вручную позже, комплектующие для него всё равно должны быть в
заказе. Иначе заказчик недополучит оборудование.

```text
количество аксессуара = норма на объект × число всех объектов проекта
```

## Как Выглядит Результат

Каждая позиция содержит:

```text
категория   (например «Кабель», «Аксессуары»)
наименование
артикул
единица измерения (м, шт.)
количество
```

Позиции отсортированы по категории, затем по названию.

## Что Важно Помнить

- Кабель — только по успешным расчётам; аксессуары — по всем объектам.
- В количестве кабеля уже учтён монтажный запас (длина заказа, не расчётная).
- Одинаковые марки объединяются в одну строку.
- Это **базовая** спецификация. Расширенный режим сотрудника (внешняя база
  кабелей и аксессуаров, ручные позиции, группировка) работает поверх неё и
  здесь не описан.

## Частые Вопросы

**Почему кабеля в спецификации меньше, чем объектов?**
Потому что строки кабеля строятся только по объектам с успешным подбором.
Объекты с ошибкой расчёта в кабельные позиции не попадают (но их аксессуары —
попадают).

**Почему длина кабеля больше расчётной?**
Потому что в спецификацию идёт длина для заказа — с монтажным запасом и, если
задано, с округлением до кратности поставки.
