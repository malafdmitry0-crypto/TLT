# Теплопотери резервуара: объяснение для инженера

Этот документ объясняет текущий расчет TLT простым инженерным языком. Он
описывает реализованную модель, а не заменяет первичный ТНП-документ.

## Что Считает Система

Система считает стационарные теплопотери резервуара:

```text
сколько ватт уходит через стенку, изоляцию и наружную поверхность
```

Для резервуара результат делится на две ключевые величины:

- `heat_loss_per_m2` - потери с одного квадратного метра поверхности, Вт/м2;
- `total_heat_loss` - полные потери всего резервуара, Вт.

В отличие от трубы, здесь нет `Вт/м` на длину объекта. Резервуар считается по
площади поверхности.

## Базовая Идея

Резервуар представляется как большая плоская стенка:

```text
продукт -> стенка резервуара -> изоляция -> воздух или грунт
```

Каждый слой создает термическое сопротивление. Чем сопротивление больше, тем
меньше тепла уходит.

Для надземного резервуара:

```text
q = (T_продукта - T_среды)
    / (R_стенки + R_изоляции + R_внеш)
```

Где:

- `q` - удельные теплопотери, Вт/м2;
- `R_стенки = толщина стенки / lambda стенки`;
- `R_изоляции = сумма(толщина слоя / lambda слоя)`;
- `R_внеш = 1 / alpha`.

Потом `q` умножается на площадь резервуара:

```text
Q = q * S * K * K_разм + Q_доп
```

## Площадь Резервуара

Система поддерживает три формы.

Цилиндр:

```text
S = боковая поверхность + две крышки
S = pi*d*H + 2*pi*(d/2)^2
```

Параллелепипед:

```text
S = 2*(L*W + L*H + W*H)
```

Сфера:

```text
S = 4*pi*(d/2)^2
```

Для подземного резервуара сферическая форма не поддержана.

## Наружная Теплоотдача

Если инженер вручную задал `alpha_vnesh`, система использует его.

Если `alpha_vnesh` не задан:

```text
в помещении: alpha = 9.0
на улице:    alpha = 11.6 + 7*sqrt(v)
```

`v` - скорость ветра, м/с.

Чем выше ветер, тем выше `alpha`, тем меньше `R_внеш`, тем больше теплопотери.

## Изоляция

Изоляция может быть однослойной или многослойной.

Для каждого слоя:

```text
R_слоя = толщина_слоя / lambda_слоя
```

Если материал справочный, `lambda` берется не как постоянная, а по расчетной
температуре `tm`.

Для зимнего наружного режима:

```text
tm = T_продукта / 2
```

Для помещения, лета, канала, тоннеля, техподполья, чердака и подвала:

```text
tm = (T_продукта + 40) / 2
```

Система также проверяет, что горячая сторона слоя не выходит за допустимый
температурный диапазон материала.

## Стенка Резервуара

Стенка учитывается только когда заданы оба параметра:

```text
толщина стенки
lambda стенки
```

Тогда:

```text
R_стенки = толщина / lambda
```

Для металлической стенки этот вклад обычно мал по сравнению с изоляцией, но в
результате он виден как `wall_resistance`.

## Подземный Резервуар

Если задана `burial_depth > 0`, система считает резервуар раздельно:

- часть над землей отдает тепло в воздух;
- часть под землей отдает тепло в грунт.

Для надземной части:

```text
q_возд = ΔT / (R_стенки + R_изоляции + R_внеш)
```

Для подземной части:

```text
R_грунта = h / lambda_гр
q_гр = ΔT / (R_стенки + R_изоляции + R_грунта)
```

Итог:

```text
Q = (q_возд*S_возд + q_гр*S_гр) * K * K_разм + Q_доп
```

`burial_depth` здесь означает высоту подземной части резервуара `h`.

## Коэффициенты

`K` - коэффициент запаса. Обычно `1.1`, если не задан вручную или через
коэффициенты.

`K_разм` - текущая продуктовая поправка приложения:

```text
помещение -> 0.9
улица     -> 1.0
```

Эта поправка влияет только на полные теплопотери `Q`, но не меняет
`heat_loss_per_m2`.

## Дополнительные Потери

`Q_доп` добавляется в самом конце:

```text
Q = расчетное_Q + Q_доп
```

На `Q_доп` не умножается коэффициент запаса. Это важно для чтения результата:
если добавить `500 Вт`, итоговый `total_heat_loss` вырастет ровно на `500 Вт`.

## Как Читать Результат

Главные поля:

| Поле | Что значит |
|---|---|
| `heat_loss_per_m2` | Потери на 1 м2 без запаса, без поправки размещения и без `Q_доп`. |
| `total_heat_loss` | Полные потери резервуара с запасом, размещением и `Q_доп`. |
| `surface_area` | Площадь поверхности, по которой умножается `q`. |
| `insulation_resistance` | Суммарное сопротивление изоляции. Чем больше, тем лучше держит тепло. |
| `external_resistance` | Сопротивление наружной теплоотдачи. На ветру уменьшается. |
| `alpha_vnesh` | Коэффициент теплоотдачи, который реально применен. |
| `safety_factor` | Коэффициент запаса, который реально применен. |
| `location_factor` | Поправка размещения, которая реально применена. |
| `q_additional` | Дополнительные потери, добавленные к `Q`. |

Для подземного резервуара дополнительно смотреть:

| Поле | Что значит |
|---|---|
| `air_surface_area` | Надземная площадь. |
| `ground_surface_area` | Подземная площадь. |
| `heat_loss_air_per_m2` | Потери надземной части. |
| `heat_loss_ground_per_m2` | Потери подземной части. |
| `ground_resistance` | Сопротивление грунта. |

## Где Модель Упрощает Реальность

- Вся стенка считается плоской; кривизна цилиндра не моделируется как у трубы.
- Крыша, днище, люки, патрубки и опоры не выделяются физически, кроме ручного
  `Q_доп`.
- Нет расчета температуры наружной поверхности.
- Нет нестационарного прогрева, охлаждения, перемешивания продукта или
  стратификации.
- Для подземной части грунт задан одним сопротивлением `h / lambda_гр`.
