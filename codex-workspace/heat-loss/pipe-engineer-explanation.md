# Теплопотери трубопровода: объяснение для инженера

Этот документ объясняет текущий реализованный backend-алгоритм простым языком.
Это не нормативное описание и не сверка с ТЗ. Это ответ на вопрос: как сейчас
программа считает теплопотери трубы.

## Главная Идея

Программа рассматривает трубопровод как цилиндр, через который тепло уходит от
горячего продукта наружу:

```text
продукт -> стенка трубы -> изоляция -> воздух или грунт
```

Каждый слой создает термическое сопротивление. Чем сопротивление больше, тем
меньше теплопотери.

Итоговая логика такая:

```text
разница температур / суммарное сопротивление = теплопотери на метр
теплопотери на метр * расчетная длина * коэффициенты = полные теплопотери
```

## Что Считается

Для трубы backend возвращает два главных числа:

| Показатель | Что означает |
|---|---|
| `heat_loss_per_meter` | Теплопотери одного метра трубы, Вт/м. |
| `total_heat_loss` | Полные теплопотери участка, Вт. |

Важно: `heat_loss_per_meter` считается без коэффициента запаса. Коэффициент
запаса применяется уже к полным теплопотерям.

## Последовательность Расчета

### 1. Разница Температур

Программа берет температуру продукта и температуру окружающей среды:

```text
delta_t = process_temperature - ambient_temperature
```

Если температура продукта не выше температуры среды, расчет не выполняется.

### 2. Стенка Трубы

Если задана толщина стенки, программа учитывает сопротивление металла трубы.

Теплопроводность трубы берется:

```text
pipe_lambda, если задана вручную
иначе справочная lambda материала трубы
```

Если толщина стенки не задана в чистом preview-расчете, сопротивление стенки
равно нулю. В расчете сохраненного объекта толщина по умолчанию добавляется как
`0.004 м`.

### 3. Изоляция

Изоляция может быть одним слоем или несколькими слоями.

Для каждого слоя программа знает:

```text
толщина слоя
материал
lambda слоя
температурный диапазон материала
```

Если материал справочный, lambda берется из справочника по расчетной
температуре изоляции. Если материал `other`, lambda должна быть задана вручную.

Для трубы каждый слой считается как цилиндрический слой, а не как плоская
стенка.

### 4. Наружная Среда

Дальше программа определяет, куда уходит тепло:

```text
если burial_depth > 0 -> в грунт
иначе -> в воздух или помещение
```

То есть фактический switch в формуле идет по `burial_depth`, а не напрямую по
полю `placement`.

### 5. Воздух Или Помещение

Если труба не подземная, используется коэффициент наружной теплоотдачи `alpha`.

Если `alpha_vnesh` задан вручную, программа использует его.

Если не задан:

```text
для помещения: alpha = 9.0
для улицы: alpha = 11.6 + 7 * sqrt(wind_speed)
```

Для улицы alpha ограничивается диапазоном `11.6..52`.

Чем выше скорость ветра, тем выше alpha, тем меньше внешнее сопротивление и тем
больше теплопотери.

### 6. Грунт

Если задана глубина заложения `burial_depth > 0`, программа использует
сопротивление грунта:

```text
R_ground = acosh(burial_depth / outer_radius_after_insulation)
           / (2 * pi * ground_conductivity)
```

Если глубина меньше наружного радиуса трубы с изоляцией, расчет падает: труба
геометрически не помещается в грунт.

### 7. Теплопотери На Метр

Все сопротивления складываются:

```text
R_total = R_wall + R_insulation + R_external
```

Потом:

```text
heat_loss_per_meter = delta_t / R_total
```

Это базовый физический результат для одного метра трубы.

### 8. Эффективная Длина

Программа увеличивает длину трубы на локальные элементы:

```text
effective_length = pipe_length
                 + num_local_elements * local_element_equiv_length
```

В объектном расчете по умолчанию добавляются:

```text
2 клапана + 2 фланца + 2 опоры = 6 локальных элементов
local_element_equiv_length = 1.5 м
```

То есть без ручной правки объект может получить плюс `9 м` к расчетной длине.

### 9. Полные Теплопотери

Итог:

```text
total_heat_loss = heat_loss_per_meter
                * effective_length
                * safety_factor
                * location_factor
```

`location_factor` по умолчанию:

```text
помещение = 0.9
улица = 1.0
```

## Что Сильнее Всего Влияет На Результат

| Параметр | Как влияет |
|---|---|
| Разница температур | Чем больше разница, тем больше теплопотери. |
| Толщина изоляции | Чем толще изоляция, тем меньше теплопотери. |
| Lambda изоляции | Чем выше lambda, тем хуже изоляция и больше теплопотери. |
| Длина трубы | Полные теплопотери растут линейно. |
| Локальные элементы | Увеличивают effective length. |
| Ветер | Повышает alpha и увеличивает потери для наружной трубы. |
| Глубина и lambda грунта | Меняют внешнее сопротивление подземной трубы. |
| Safety factor | Умножает только итоговые полные теплопотери. |

## Практические Замечания

- Если инженер сравнивает `heat_loss_per_meter` с `total_heat_loss`, надо помнить:
  первое число без `K`, второе с `K`.
- Для сохраненного объекта defaults могут менять результат еще до формулы.
- Если включены локальные элементы по умолчанию, `total_heat_loss` будет выше,
  чем простой расчет `q * pipe_length * K`.
- `surface_temperature` сейчас не рассчитывается и возвращается как `null`.
- Для подземной трубы поле `alpha_vnesh` не используется, потому что внешнее
  сопротивление считается через грунт.
